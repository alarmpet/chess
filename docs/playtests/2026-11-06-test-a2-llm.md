# 사람 시험 대기 항목 — LLM 대행 (2026-11-06)

**사람이 아니다.** 사용자 지시로 세 모델(agy 어린이 · grok 초보 어른 · codex 숙련 어른)이 오늘 넣은 기능의 사람 측정을 먼저 했다. 정지 화면과 글자 판만 받았다. 방법·주장별 판정은 [라운드 기록](../research/agent-rounds/2026-11-06-test-a2-llm/README.md). **사람 시험은 여전히 열려 있다.**

| 질문 | 답(세 모델) | 판정 |
| :-- | :-- | :-- |
| 시그니처: 어떤 말이 잡았는지 보였나 | 잡은 동물 맞힘 agy 5/6 · codex 2/6 · grok 0/6, 틀린 것의 절반은 거꾸로 | **정지 화면으로는 약함** — 움직임 포함 사람 시험 필요, 잡는 말 강조 후보 |
| 반격 목표가 기권을 줄이나 | 같은 국면에서 🔥 있음 계속 5/8, 없음 0/9 | **방향은 맞음.** 다만 기권도 같은 도토리 15 를 받는 것이 기권 이유로 나옴 |
| 손과 뇌: 조언자가 도움이 되나 · 스스로 찾나 | 손실 혼자 117/10/20 → 조언자 30/2/8, 가족 판 2. 최선 수를 그대로 둔 비율 9~11/12 | 도움은 큼, **힌트가 수를 거의 정해 줌**(초반) |
| 띠·알림이 많은가 | 셋 다: 가운데 위 알림이 판을 가림, 한 번에 1~2개 | **수렴 — 고칠 것** |
| 번개 판 | 어린이·숙련자: 「한 판 더」, 초보: 「10초는 짧다, 끄고 싶다」, 「17」 단위 모름 | 갈림 — 사람 기보 블런더율로 |
| 💰 표식 | 어린이: 「잡으면 보물」 / 초보·숙련: 뜻 모름·얼굴 가림 | 갈림 — 사람 판 |
