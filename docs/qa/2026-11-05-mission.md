## 확인

- **브라우저(데스크톱 1024×768):** 띠 「🎯 캥거루로 먼저 잡기 · 2수째」(`desktop-strip-waves.jpg`). 수 사건을 보내 「내가 먼저 ✓」·초록 띠·「미션을 먼저 해냈어요! 판이 끝나면 도토리 +8」 확인. 판 끝 사건: 새 마을 30 + 패 15 + 미션 8 = **53**, 같은 판 끝 사건을 한 번 더 보내도 53(두 번 지급 없음).
- **세로 화면(360×744 에뮬레이션):** 판이 위로, 띠는 판 아래 모래·산호 위(`phone-size-strip.jpg`). 처음엔 `left:50%` 때문에 띠가 180px 로 잘려 가운데 정렬 방식을 바꿨다.
- **실기기(Z Flip5):** 상한 1.85 는 앞줄 양끝 말이 잘림(`phone-real-fit185-cropped.jpg`), 2.15 + 7% 올림은 판 전체가 보이고 아래 자리가 남음(`phone-real-board-raised.jpg`). 전(`phone-before.jpg`)과 비교. 띠·파도 움직임은 실기기에서 보지 못했다 — 시험 중 폰에서 다른 앱(VocaRider)이 앞에 나와 있어 사용 중으로 보고 멈췄다.
- **GPU(파도 비용):** 같은 조건 A/B/A, ego-browser 1024×768: 파도 후 20.93 · 전 20.65 · 후 21.46 ms(p95 24.4 / 23.8 / 23.7). 차이 0.3~0.8ms, 로드끼리 흔들림 범위. 처음 한 번은 29.5ms 가 나왔는데 빈 페이지 rAF 도 두 배(41.5ms)라 다른 탭이 GPU 를 같이 쓴 환경값으로 버렸다.
- 테스트 135/135(옛 미션 테스트 4개 → 공유 미션 3개), `tsc` 0, 빌드, `gate:bundle`·`gate:drawcalls`(체스)·`gate:drawcalls:village` 통과.
