## 찾은 것 · 고친 것

- 처음에는 세로 화면에서 목표 칩이 2 + 1 로 줄바꿈됐다 → 셋이 한 줄에 서게.
- 메이트 배너는 「백 승리! 체크메이트로…」와 새 문장이 같은 말을 두 번 했다 → 결과가 있으면 보조 글자를 숨긴다.
- 「채운 목표 1 대 0로」 → 「0으로」(숫자 받침).
- 확인 스크립트의 국면 둘이 틀렸다: 기권은 내 수 10번부터 진 판으로 남는다(그 전에는 그냥 나가기) · 쉬움 AI 는 한 수 메이트(Qh4#)를 놓친다 → 내가 메이트를 거는 줄로 바꿨다.

## 재 보지 않았다 · 남은 것

- **사람이 읽고 이해하는지**는 재지 않았다 — 겹침이 없다는 것과 문장이 맞다는 것만 확인했다.
- 차례 상한·스테일메이트·반복·50수·킹만 남음 종료는 문장 단위 테스트만 있고 화면에서 끝내 보지 않았다.
- 끝난 판을 되돌려 HUD 가 다시 펴지는 길(`resume`)은 코드만 있고 화면에서 확인하지 않았다(끝난 판의 되돌리기 자체가 SC-1 범위 밖).
- 위쪽 차례 글자는 여전히 색 이름이다(「흑 계약 완성」). 영어 문구 없음. 실제 폰에서 보지 않았다.
- 알림이 두 줄로 길어지면(세로 화면 343px 넘는 글) HUD 머리줄에 닿을 수 있다 — 지금 쓰는 알림 글로는 재 보지 않았다.
- `:has()` 를 쓴다(Chrome 105 · Safari 15.4 이상). 그보다 낮은 브라우저에서는 메이트 배너에 두 문장이 함께 보인다.
