## 재 보지 않은 것 · 남은 것

- **데스크톱 가로 화면에서는 판 밑면이 화면 위 밖이다.** 카메라가 42° 로 내려다보아 높이 12.6 의 판이 잘린다. 빛줄기와 거품관이 「위에 무언가 있다」를 대신한다.
- **휴대폰 세로(375×812)에서는 판 밑면이 화면 맨 위에 어두운 흙판으로 걸쳐 보이고 섬을 가리지 않는다**([phone](2026-11-05-atb-phone.jpg)). 같은 화면에서 카메라 쪽 폐허 기둥·아치가 크게 보인다. 120콜. 위쪽 알약·고리 패널이 겹치는 것은 이번 변경 전부터다.
- 사람이 「여기가 체스판 밑이라는 걸 알겠나」는 AT-9(사람 시험)에서.
- 건물 10종은 그대로다(AT-7, 사용자 결정 대기).
