# 공방 WS-1 — 받기 · 진도 · 부품 · 골라 만들기 (2026-11-16)

사용자 요청: 「공방 시작」. 계획: [슬롯 체스·공방 계획](../plans/2026-11-11-slot-chess-village-plan.md) §5.1 · §7.2. 앞선 조각: [입구·보상·음원](2026-11-15-sc2.md).

## 넣은 것

판이 「작업 진도」를 주고, 마을은 곡물로 부품을 만들고, 부품과 도토리로 **갖고 싶은 소품을 골라** 만든다.

| 규칙 | 값 | 근거 |
| :-- | :-- | :-- |
| 받기 | 판을 2번 끝내면 **무료**, 기본 일꾼 1 · 곡물 3 이 같이 온다 | §5.1 「첫 공방은 무료, 기본 일꾼 1명·곡물 3개」 |
| 작업 진도 | 일반 판 1일 · 계약전 0.5일 · 기권한 계약전 0 · 끝 10일 | §7.2 |
| 생산식 | 진도 1일 + 곡물 1 → 부품 2. 곡물이 없으면 진도가 쌓여 기다린다. 부품 끝 24 | §7.2 「최소 생산식」 그대로 |
| 곡물 사기 | 도토리 3 → 곡물 1 | §7.2 「도토리 3/개」. 장터가 2 에 사 가서 되팔아 남지 않는다 |
| 골라 만들기 | 흔함 **🔩4 만** · 고급 🌰10 + 🔩8 · 희귀 🌰25 + 🔩12. 왕관 동상(전설)은 매대에서만 | **내가 정한 값, 시뮬로 두 번 고침**(아래). 매대(15 · 30 · 60)는 무작위, 공방은 고른다 |
| 다음 건물 몫 | 곡물 사기·도토리가 드는 만들기는 매대처럼 다음 건물 값을 남긴다. 부품만 드는 것은 상관없다 | 섬 페이스를 지키려고(`shelfReserve`) |

- **일꾼은 카드가 아니다.** 공방에 기본 일꾼이 딸려 와서 카드를 놓지 않아도 일한다(§5.1 「드문 카드를 기다리지 않아도 일한다」). 주민 직무·숙련(§5.2)은 넣지 않았다.
- 공방은 8채 건물 목록에 넣지 않았다 — 「섬 완성」 조건과 건물 메뉴가 그대로다. 자기 칸(앞줄 e2 부터 빈 곳)을 차지하고, 그 칸에는 건물·소품을 놓지 못한다.
- 밭 바로 뒤에서 곡물을 먼저 쓴다(장터가 팔아 버리기 전에).
- **섬의 모습**: 전용 모델이 없어 집 모델을 작게 쓰고 앞마당에 모루·작업대·주황 불빛·불똥을 코드로 놓았다. 부품이 쌓이면 작업대 위 상자가 0 ~ 4단으로 높아진다. 누르면 공방 창이 열린다.
- **화면**: 마을 머리 줄에 🔨 단추(받을 수 있으면 금빛으로 깜빡임) · 공방 창(진도·곡물·부품 막대, 곡물 사기, 골라 만들기 7종) · 판 끝 소식 줄 「🔨 공방 진도 +1일 · 부품 +2」 · 계약전 결과 상자 「🌰 도토리 +18 · 🔨 공방 진도 +0.5일」.
- 만든 소품은 보관함으로 가고, 곧바로 「놓을 칸을 누르세요」로 이어진다(매대와 같은 길).

## 측정

### 경제 시뮬레이션 — [island_sim.mjs](../../tools/island_sim.mjs) `workshop` 모드

실제 chess.js 판을 두는 봇(강 0.8 · 보통 0.5 · 약 0.25)이 45판 동안 섬을 짓는다. 판 → 카드 → 섬 정산은 게임과 같은 함수다. `decor`(공방 없음, 지금까지의 기준)와 `workshop`(공방을 받고, 다음 건물 몫을 남긴 채 부품이 되는 만큼 가장 비싼 소품부터 만든다 — 매대보다 먼저)을 60회씩. 결과 `docs/research/2026-11-16-workshop/`.

| 값 | 섬 완성(강 · 보통 · 약, 중앙값 / p90) | 20판째 만든 소품(중앙값) | 20판째 꾸밈 점수(강 · 보통 · 약) |
| :-- | :-- | :-- | :-- |
| 공방 없음 | 19 / 21 · 21 / 22 · 22 / 24 | — | 190 · 170 · 155 |
| ① 🌰10·20·40 + 🔩2·4·6 | 20 / 21 · 21 / 23 · 22 / 24 | **0 · 0 · 0** | 185 · 165 · 155 |
| ② 🌰5·12·25 + 🔩3·6·10 | 19 / 21 · 21 / 23 · 23 / 25 | 3 · 0 · 0 | 215 · 165 · 155 |
| **③ 🔩4 · 🌰10+🔩8 · 🌰25+🔩12** | **19 / 21 · 21 / 23 · 22 / 26** | **8 · 8 · 8** | **230 · 205 · 200** |

- **① 에서 아무도 못 만들었다.** 부품은 20판째 끝(24)까지 찼는데, 섬을 짓는 동안 도토리는 늘 다음 건물 몫에 묶인다 — 건물을 시작하자마자 남는 도토리가 몫 아래로 떨어진다. ② 에서도 보통·약한 봇은 0 이었다. 그래서 흔한 소품은 부품만으로 만들게 했다(③).
- ③ 에서 섬 완성 중앙값은 공방 없을 때와 같다. **약한 봇의 p90 은 24 → 26판으로 2판 늦어졌다** — 공방이 곡물을 먼저 가져가 장터 수입이 준 탓으로 보인다(나누어 재지는 않았다). 섬 시뮬이 지켜 온 「20 ~ 26판」 안이지만 끝에 닿았다.
- 부품은 20판에 36개 만들어져 끝(24)에 자주 닿는다. 곡물이 넉넉하면 부품이 남는다는 뜻이다 — 부품의 큰 쓰임처(잡기 연출 부품, §6.1)가 생기면 다시 잰다.
- 봇은 곡물을 사지 않는다. 사람이 곡물을 사면 부품이 더 빨리 생기고 도토리가 준다.

## 재 보지 않았다 · 남은 것

- **사람 시험 없음.** 「부품」이라는 새 재화가 재미를 만드는지(§7.1 「제작이 실제 재미로 확인되지 않으면 새 부품도 넣지 않는다」)는 사람이 해 봐야 안다. 지금은 봇 경제와 화면만 봤다.
- 공방 전용 모델이 없다(집 모델 + 코드 소품). 섬에서 작게 보인다. 캐릭터 파이프라인(Flow 콘셉트 → TRELLIS)으로 만들 수 있다.
- 계획서의 큰 쓰임처 — **말의 잡기 연출 부품(예고·궤적·폭발·소리, §6.1)** — 은 아직이다. 지금 부품은 섬 소품에만 쓴다.
- 주민 직무·숙련·영입(§5.2), 생활 시뮬레이션(§5.3), NPC 주문 시장(§7.3)은 하지 않았다.
- 실제 폰, 영어 문구(공방 창은 한국어만).
