# FN-3 직전 수 · 위기 알림 · 무료 되감기 확인 (2026-11-07)

재미 계획서 §7 단계 3. 완료 조건은 「연습 단계에서 큰 말이 공격받으면 한 줄이 뜸」이다. 연습 단계 = 이번 판 상대가 쉬움(첫 3판 자유 대국, 또는 소풍 나온 미어캣단)인 판이다.

## 바뀐 것

| 장치 | 규칙 | 코드 |
| :-- | :-- | :-- |
| 직전 수 표시 | 방금 둔 수의 출발·도착 칸을 옅은 노란 칸으로 표시. 되감기·이어 하기·새 판에서 심판 기록의 마지막 수로 다시 맞춘다. 인스턴스 2개라 그리기 1번 | `wizardChessEngine.js` `lastMoveMark`, API `setLastMoveMarks`·`debugLastMoveMark` |
| 위기 알림 | 연습 단계에서 상대 수가 내려앉을 때 알린다. 내 호랑이·코뿔소가 **더 싼 말에게 노려지거나, 지켜 주는 말 없이 노려지면** 「호랑이가 노려지고 있어요」 한 줄. 같은 말은 계속 노려져도 다시 말하지 않는다. 수는 알려 주지 않는다 | `src/cards/threatNote.js`, `RivalLadder.tsx` |
| 무료 되감기 | 첫 5판, 그리고 쉬운 상대와 두는 판에서는 판마다 되감기 1번(지금까지는 희귀 카드를 잡아야 생겼다) | `rivalLadder.js` `freeRewind`, `CardLayer.tsx` |

테스트는 `test/threatNote.test.mjs` 5개와 `rivalLadder.test.mjs` 에 1개를 더했다. 전체 182 통과, `tsc` 오류 0, 첫 국면 드로우콜 98/100 통과(표시는 첫 국면에 숨어 있다).

## 봇 측정 — 시끄러운가, 사실인가

`tools/threat_sim.mjs` 로 쟀다. 연습 단계 60판, 약한 플레이어(쉬움 봇) 대 쉬움 상대, 원본은 [threat-sim](../perf/2026-11-07-threat-sim.txt).

- 판당 알림은 평균 3.8 · 중앙값 4 · 최대 12였다. 알림이 0번인 판은 3%였다.
  - 계획서의 「결정적 순간 판당 2~4번」 안이다.
- 알림을 받은 뒤 그 말을 옮긴 비율은 69%였다.
- 안 옮긴 경우, 바로 다음 상대 수가 그 말을 잡은 비율은 21%(15/72)였다.
  - 쉬운 상대는 탐색이 1수라 잡을 수 있어도 자주 놓친다.
  - 「노려진다」는 사실이지만, 반드시 잃는다는 뜻은 아니다.

- **직전 수 표시는 옅다.** 연한 칸은 노르스름하게, 짙은 칸은 올리브빛으로 보인다. 멀리 있는 칸이나 휴대폰 화면에서 잘 보이는지는 재 보지 않았다.
- **위기 알림**은 실제 판에서 상대가 노리는 수를 둬서 뜬 것이 아니다. 판 사건을 직접 보내 확인했다.
- **설정의 켜고 끄기 줄**은 넣지 않았다. 직전 수 표시는 늘 켜짐이고, API 로만 끌 수 있다.
