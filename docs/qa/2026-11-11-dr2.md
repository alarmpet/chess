# DR-2 템포 (2a 미리 두기 · 2b 끌기) — QA (2026-11-11)

방향 계획서 DR-2 의 2a(F3 막지 않기 + 선입력 1수)와 2b(F5 탭-탭·큰 합법 칸·끌기 구제) 가운데 끌기. 2c(마지막 수 확대·판 길이 약속)는 하지 않았다.

## 바꾼 것

| 곳 | 내용 |
| :-- | :-- |
| `src/wizardChessEngine.js` 미리 두기 | AI 가 생각하거나 수가 움직이는 동안(내 수 연출 포함) 내 말을 누르면 **보라색**으로 고르고 후보 칸이 보인다. 후보 칸을 누르면 그 수를 미리 둔다(출발 고리 + 도착 원). **내 차례가 오는 순간** 그 국면에서 합법이면 바로 두고, 아니면 조용히 버린다. 1수만, 승급은 퀸. 같은 말을 다시 누르거나 빈 칸·판 밖을 누르면 취소. 미리 둔 순간 AI 의 0.25초 쉼도 건너뛴다. 후보 칸은 심판 국면(연출보다 먼저 수를 둔다)에서 「내 차례라면」으로 계산 |
| | 새 판·되돌리기·장면 설정·AI 생각 버리기 자리에서 미리 둔 수도 지운다. 판 번호와 「둘 차례의 기록 길이」가 맞을 때만 둔다 |
| | 연출 중에 내 말이 아닌 곳을 누르면 예전처럼 건너뛰기(DR-1c), AI 쉼 중에는 예전처럼 「지금 둬」 |
| 누르기 경로 정리 | `pointerup` 을 「어느 칸인가」(`squareUnderPointer`)와 「누르면 무엇을 하나」(`boardTap`)로 나눔. 시험은 `wizardChess.tapSquare(r, c)` 로 같은 길을 탄다 |
| 끌기 | **내 말에서 시작한 끌기는 카메라를 돌리지 않고 그 말을 옮긴다**(놓은 칸 = 두 번째 누르기, 미리 두기도 같은 길). 판 밖·다른 곳에서 시작한 끌기는 예전처럼 카메라. 끌기 동안만 카메라 조작을 끄고, 그 사이 잡기 장면이 시작됐으면 카메라는 잡기 장면이 돌려준다. 말이 손가락을 따라오지는 않는다(고른 표시만) |
| `src/rules/referee.js` | `colorAt(r, c)` — 심판 국면에서 그 칸 말의 색 |
| `tools/tempo_probe.mjs` | 「입력 닫힘」 표본 추가: 바쁘면서 미리 두기도 안 되는 시간(미리 두기 전에는 막힌 시간과 같다) |

## 찾은 것 · 고친 것

- 새 판을 열어도 미리 둔 수의 표시가 남았다(`resetChessBoard` 는 AI 쉼이 걸려 있을 때만 생각을 버린다) → 새 판·국면 되돌리기에서 늘 지운다. 시험 4 가 잡았다.
- 「빈 칸에서 끌면 카메라」 시험이 실패했는데, 판 위 빈 칸이라도 **앞줄 내 말의 몸이 그 칸을 덮고 있으면** 그 말을 집는다(의도된 규칙) — 시험의 시작점을 판 밖으로 옮겼다. 같은 조건에서 예전 빌드와 지금이 똑같이 카메라를 돌리는 것을 따로 확인했다.
- 작업 중 C: 가 가득 차(여유 0) 헤드리스 Chrome 프로필을 `TEMP=D:/tmp` 로 옮겨 돌렸다. 이 세션이 만든 임시 프로필 10개만 지웠다(876MB). C: 를 채운 주원인은 따로 있다(재 보지 않았다).

## 재 보지 않았다 · 남은 것

- **사람 시험**: 미리 두기를 실제로 쓰는가, 실수로 미리 두는 일(잘못 놓기 횟수)이 있는가. 실제 폰 손가락으로 끌기.
- 폰에서 미리 두기 도착 원이 앞줄 말 몸에 가려 옅다 — 더 진한 표시가 필요할 수 있다.
- 말이 손가락을 따라오는 끌기(지금은 놓을 때 옮김).
- 2c 마지막 수 확대·판 길이 약속. 친구 대전(multi)에는 미리 두기를 넣지 않았다(AI 판만).
