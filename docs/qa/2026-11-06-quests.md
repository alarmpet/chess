# 오늘의 퀘스트 📋 (목표 층 OL-3) — 2026-11-06

근거: [목표 층 계획서](../plans/2026-11-05-objective-layer-plan.md) ④ · 출처 등급 A — Hearthstone 주간 3개·하루 한 번 교체, Duolingo 일일 3개, Chess.com 일일 퍼즐 **48시간 유예**. 반대 사례도 반영: VALORANT 는 특정 행동 일일 임무를 「아무 판이나」 체크포인트로 바꿈 → 우리 쉬움은 아무 판으로 차는 것 위주, Clash Royale 은 퀘스트를 삭제 → **설정에서 끌 수 있게**.

## 규칙

- 하루(기기 날짜, 자정 기준) 3개: 쉬움 · 보통 · 어려움 칸에서 하나씩. 여러 판에 걸쳐 채운다. 보상 도토리 5 / 10 / 15(판 끝에 미션·현상금·도장과 함께).
- **48시간 유예:** 어제 못 끝낸 퀘스트는 진행도를 가진 채 오늘까지 남는다(「어제 것 · 오늘까지」). 그 뒤 같은 칸의 새 퀘스트.
- **바꾸기:** 하루 한 번, 안 끝난 칸 하나를 같은 칸의 다른 퀘스트로.
- 설정 「📋 오늘의 퀘스트」를 끄면 보이지 않고 진행도 멈춘다. 6판째부터(미션·현상금·도장과 같이).
- 표시: 게임 띠 「📋 n/3」, 완료 알림 「✅ 퀘스트 완료: … 판이 끝나면 도토리 +N」, 카드 도감 위쪽 「📋 오늘의 퀘스트」 칸.

| 칸 | 퀘스트 |
| :--- | :--- |
| 쉬움 | 한 판 끝까지 두기 · 말 3마리 잡기 · 체크 1번 |
| 보통 | 캥거루로 2번 잡기 · 판다로 2번 잡기 · 캐슬링 하기 · 공유 미션 먼저 해내기 · 💰 현상금 받기 |
| 어려움 | 말 10마리 잡기 · 체크 3번 · 💰 현상금 2번 받기 |

## 측정 — 봇: 플레이어(백, 쉬움) 대 AI(흑, 보통), 원본 `docs/perf/2026-11-06-quest-sim*.txt`

「하루에 k판 두면 끝내는 비율」.

**1차(120판) — 어려움이 불가능했다:** 「기술 도장 하나」 0 / 0 / 0, 「한 판 이기기」 0 / 0 / 0 (1·2·3판). 약한 플레이어는 강한 AI 에게서 도장(대부분 메이트·포크)도 승리도 못 얻었다 → 어려움 칸을 바꿨다(`-v1.txt`).

- 쉬움은 한 판, 보통은 1~2판, 어려움은 2~3판 — 의도한 하루치 노력. 유예로 하루 더 있고, 막히면 바꾸기 1번.
- 3판 묶음은 20개뿐이라 퍼센트의 흔들림이 크다. 캐슬링(55% 에서 멈춤)은 판에 따라 아예 안 되는 퀘스트라 바꾸기의 대상.
