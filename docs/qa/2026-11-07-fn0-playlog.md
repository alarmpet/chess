# FN-0 기록 보강 확인 (2026-11-07)

재미 계획서 §7 단계 0 「한 판 시작부터 다음 판까지 기록으로 다시 그려짐」. 사람 시험 A 에서 한 사람의 판 기록(`wildcrown.playlog.v1`)을 받아 몇 판 했는지, 어디서 떠났는지, 지고 나서 다음 판을 눌렀는지 보려는 것이다.

## 바뀐 것

| 기록 | 언제 | 내용 | 남기는 곳 |
| :-- | :-- | :-- | :-- |
| `start` (새로 추가) | 판 시작·이어 하기 | `gameId`, `resumed`(이어 하기 반수), `rivalId`, `color`, `handBrain`(off·family·adviser), `blitz` | `src/SessionLog.tsx` |
| `leave` (새로 추가) | 끝나지 않은 판에 수가 있을 때 창 숨김·닫기·새로고침 | `gameId`, `ply` | 같음 |
| `quit` (새로 추가) | 끝나지 않은 판에 수가 있는데 새 판이 시작됨(새 판 단추·이른 기권·진영 바꾸기·라이벌) | `gameId`, `ply` | 같음 |
| `skill` (새로 추가) | 정찰·되감기 단추를 누름 | `kind`, `ply`(되감기는 되감기 전 반수) | `CardLayer.tsx` |
| `game` (보강) | 판 끝 | `gameId`, `rivalId`, `color` 추가 | `CardLayer.tsx` |

- 엔진의 `gamestarted` 사건에 `rivalId`·`color` 를 실었다(`wizardChessEngine.js` 두 곳).
- 묶어 읽기: `src/cards/sessionLog.js` 의 `storyOf(log)`. 판 하나씩 시작 → 창 닫음·이어 하기 → 기술 → 끝 또는 버림 → 다음 판까지 간격을 묶는다. 한 수도 두지 않은 판은 셈에서 뺀다. 「한 판 더」는 판 끝 뒤 600초 안에 다음 판에서 한 수 이상 둔 것으로 센다.
- 도구: `node tools/playlog_story.mjs <playlog.json> [--json]`.
- 테스트: `test/sessionLog.test.mjs` 6개. 전체 `npm test` 171 통과, `tsc --noEmit` 오류 0.

## 실제 게임으로 확인

ego-browser 로 실제 판을 돌렸다([round-02.mjs](2026-11-07-fn0-playlog/round-02.mjs)). 흐름은 다음과 같다.
1. 잡기를 먼저 고르며 6수 두고, 기술 단추가 뜨면 누른다.
2. 새로고침한다.
3. 이어서 둔다.
4. 24반수에서 기권한다.
5. 새 판을 열어 한 수 둔다.
6. 다시 새 판을 연다.

끝에 저장을 비웠다.

[story.txt](2026-11-07-fn0-playlog/story.txt)(기록 [playlog.json](2026-11-07-fn0-playlog/playlog.json)):

```
1. 00:52:21 시작 (백)
   00:52:42 창 닫음 — 12반수
   이어 하기 1번
   정찰 — 16반수
   00:53:20 끝: 패(기권) · 24반수 · 시작부터 60초(카드 기록 38초 — 이어 하기 뒤부터만 잼)
   → 다음 판까지 5초
2. 00:53:25 시작 (백)
   00:53:30 새 판으로 버림 — 2반수

시작 3 · 둔 판 2 · 끝낸 판 1 · 이탈 1 · 새 판으로 버림 1 · 창 닫음 1 · 이어 하기 1 · 기술 1
기권한 판 뒤 다음 판: 1/1
```

- 스크립트가 한 일과 기록이 줄마다 맞는다. 12반수에서 새로고침했고, 24반수에서 기권했고, 다음 판에서 한 수(2반수) 두고 새 판을 열었다. 세 번째로 열린 판은 한 수도 두지 않아 셈에서 빠졌다.
- **되감기**는 희귀 이상 카드가 나와야 단추가 생겨서, 다섯 번 돌린 중 한 번만 떴다([story-rewind.txt](2026-11-07-fn0-playlog/story-rewind.txt)).
  - 그 실행은 고치기 전이라, 되감은 **뒤** 반수(12)를 남겼다.
  - 「되감기 전 반수」로 고친 뒤에는 단추가 뜨지 않아 재 보지 않았다(코드만 바꿈).
- **판 길이**: 카드 기록의 `seconds` 는 새로고침 뒤부터만 잰다(38초). 시작부터는 60초다. 이야기 도구는 둘을 다 보인다.
- **창 닫음**: 실제 휴대폰에서 다른 앱으로 넘어갈 때(`visibilitychange`) 남는지는 재 보지 않았다. 데스크톱 새로고침(`pagehide`)만 확인했다.
- **힌트**: 계획서가 말한 「힌트 사용」은 아직 힌트 기능이 없다(FN-4). 지금은 손과 뇌 조언자 사용을 판 시작 기록의 `handBrain` 으로 남긴다.
- 화면은 바뀌지 않는다. 그래서 캡처 대신 기록과 이야기 출력을 남겼다.
