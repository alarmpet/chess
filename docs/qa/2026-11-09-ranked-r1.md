# LA-R R-1 — 기기 익명 키와 🏆 랭크 방 (2026-11-09)

계획서: [Play 출시 교훈 적용](../plans/2026-11-09-play-launch-lessons-plan.md) §4.2 R-1. 사용자: 「서버랭크 넣어」 → 「R-1 부터 시작」.

## 바꾼 것

- `src/net/identity.js` (새 파일): 첫 실행에 기기 서명 키 쌍(ECDSA P-256, WebCrypto)을 만들어 `localStorage` 의 `wildcrown.identity.v1` 에 둔다.
  - 신분 id 는 공개 키 해시 앞 12바이트(16글자)다. 이름·이메일은 담지 않는다.
  - `sign(text)` 와 `verifySignature(pub, text, sig)` 를 둔다. R-2 에서 판 결과(PGN) 서명에 쓴다.
  - 저장이 막힌 기기는 이번 실행에만 쓰는 신분을 만들고 `kept: false` 로 알린다.
- `src/net/matchCore.js`: `ranked`·`key` 옵션을 더했다.
  - 방장이 정한 `ranked` 가 `state` 로 손님에게 간다. 손님은 혼자서 랭크로 바꿀 수 없다.
  - `hello`·`state` 에 기기 id 를 실어 서로의 키(`peerKey`)를 안다. 형식이 틀린 키는 버린다.
- `src/Online.tsx`: 방 만들기 창에 「🤝 친선 / 🏆 랭크」 고르기를 더했다. 방 막대에 「🏆 랭크」 표시가 붙는다.
  - 랭크 판이 끝나기 전에는 「새 판」(`btn-reset`)이 `disabled` 이고, 눌러도 친구 창이 열리지 않는다.
  - 끝나면(기권·메이트) 다시 풀린다.
- `src/wizardChessEngine.js`: 친구 대전(`gameMode === 'multi'`)에서 「색 바꾸기」를 숨겼다. 「AI 수」 단추도 숨기고 클릭을 무시하게 했다.
  - **정정:** 처음에는 「친구 대전에서 AI 수 단추가 눌린다」고 보고했다. 확인해 보니 `btn-ai-move` 는 지금 화면(`App.tsx`)에 없다. 결함이 아니었다. 엔진 쪽 막는 줄은 해가 없어 남겼다.
  - 되감기·손과 뇌·정찰은 원래부터 친구 대전에서 숨겨져 있었다(`body.online-game`, `takeBackMove` 는 `single` 만).

## 재 보지 않았다

- 브라우저에서 `peerKey` 가 서로 상대 id 와 같은지는 보지 않았다. 화면에 드러나지 않아서다. 단위 테스트로만 확인했다.
- 휴대폰 폭에서 「친선/랭크」 줄과 방 막대가 어떻게 접히는지.
- 점수(Glicko-2)와 서버 기록은 R-2 에서 한다. 지금 랭크 판은 「잠금이 있는 친선 판」이다. 화면에도 「점수 기록은 곧 열려요」라고 적었다.
- 랭크 판 중간에 「나가기」를 누르면 그냥 나가진다. 몰수 처리는 R-4 에서 한다.
