### 3. 고칠 것 (조합별 개선안)

- **`pawn>pawn`**: 다가가기와 카메라 복귀 시간을 줄이고, 한 판 내 연속 폰 잡기(콤보) 발생 시 달리기 모션을 생략하여 제자리 빠른 타격으로 전환 (1.82초 → 1.0초).
- **`rook>pawn`**: 엔드게임 등에서 연달아 폰을 잡을 때 코뿔소의 충격파 차징 모션을 생략하고 즉시 치고 지나가도록 단축 (2.13초 → 1.2초).
- **`knight>pawn`**: 초반 빈번한 잡기이므로 캥거루 도약 및 착지 후 딜레이를 간소화 (2.10초 → 1.3초).
- **`bishop>pawn`**: 판다의 대각선 굴러오기 이동 속도를 배속하고 타격 후 경직을 단축 (2.28초 → 1.3초).
- **`pawn>bishop`**: 판다→캥거루 직후 바로 일어나는 폰 되잡기 수순에서는 카메라 전환 없이 즉시 타격 처리 (2.37초 → 1.2초).
- **`rook>rook`**: 2연속 룩 맞교환 시 두 번째 연출에서는 거울 마주보기 준비 모션을 생략하고 충돌로 즉시 연결 (2.67초 → 1.4초).
- **`queen>queen`**: 거울 대기 모션 시간을 줄이고 할퀴기 후 카메라 복귀를 신속하게 처리 (2.54초 → 1.5초).
- **`bishop>rook`**: 코뿔소가 튕겨나간 후 카메라가 중앙으로 복귀하는 지연 시간 단축 (2.58초 → 1.6초).
- **`rook>queen`**: **그대로 두기**. 21판 중 단 7회(1.6%)만 나온 강력한 역전(룩으로 퀸 포획) 연출로, 긴장감과 하이라이트 쾌감을 주는 핵심 연출이므로 유지 (2.75초 → 2.75초).
- **`bishop>queen`**: **그대로 두기**. 21판 중 6회(1.4%)에 불과한 희귀한 역전 연출로, 극적인 성취감을 유지하기 위해 그대로 둠 (2.58초 → 2.58초).
