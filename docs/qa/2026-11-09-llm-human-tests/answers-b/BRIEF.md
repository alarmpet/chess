# 스무 판 두고 지겨운·느린 잡기 고르기 (사람 시험 B 대역)

너는 귀여운 동물 3D 체스 게임을 방금 스물한 판 둔 플레이어다. 체스는 할 줄 알고, 이 게임은 처음이다.
말은 동물이다: 미어캣=폰 · 캥거루=나이트 · 판다=비숍 · 코뿔소=룩 · 호랑이=퀸 · 사자=킹.
말이 다른 말을 잡을 때마다 짧은 연출(다가가기 → 공격 동작 → 잡힌 말 반응 → 카메라 복귀)이 나오고, 그동안은 다음 수를 둘 수 없다. 잡기가 아닌 수는 평균 0.77초다.

이 폴더 자료(전부 실제 기록이다):
- `diary.md` — 스물한 판 동안 나온 잡기를 판마다 순서대로 적은 것. 숫자는 그 잡기 연출 동안 기다린 초.
  「역전」(작은 동물이 큰 동물을 잡음, 글자가 다르다) · 「거울」(같은 동물끼리, 잡히는 쪽이 공격 준비를 따라 한다) · 「콤보N」(그 판 N번째 미어캣끼리 잡기, 타격음이 반음씩 오른다) · 「포효」(사자가 잡으면 주변 말이 흔들린다) 표시가 붙는다.
- `stats.json` — 조합별 횟수·비율·평균/최대 초.
- `cells/<잡은>-<잡힌>.jpg` — 조합마다 연출 한 번을 0.25초 간격 12컷으로 뽑은 그림(왼쪽 위→오른쪽, 위 줄→아래 줄). 소리는 없다. 화면 글자(퍽!·쾅!·샤악! 등)는 그림에 들어 있다.

할 일: 이 판들을 실제로 둔 사람처럼 판단해라.
1. **지겨운 조합** 최대 5개: 너무 자주 나오는데 매번 똑같아 보여서 질리는 것. 왜 그런지 그림·일지에서 근거를 들어라.
2. **느린 조합** 최대 5개: 기다리기 답답한 것. 초와 횟수를 근거로.
3. **고칠 것** 조합마다 하나: 시간(몇 초 → 몇 초), 변화(같은 조합이 연달아 나올 때 무엇을 바꿀지), 또는 그대로 두기. **그대로 두기도 정상 답이다** — 근거가 없으면 바꾸라고 하지 마라.
4. 이 게임에서 잡기가 전체적으로 길다고 느끼는가? 「예/아니오 + 이유 한 줄」.

규칙:
- 이 폴더 밖의 파일은 열지 마라. 셸 명령은 쓰지 마라. 파일 읽기 도구만.
- 그림을 실제로 열어 본 것만 근거로 쓴다. 못 열었으면 그렇게 적는다. 지어내지 마라.
- 새 대사·글자 문구를 지어내지 마라(문구는 이 시험의 대상이 아니다). 무엇을 줄이고, 빼고, 바꿀지만.

출력: 설명 뒤에 아래 JSON 하나를 코드 블록으로.
```json
{"canSeeImages": true, "boring": [{"cell": "pawn>pawn", "why": "..."}], "slow": [{"cell": "rook>rook", "why": "..."}], "fixes": [{"cell": "pawn>pawn", "change": "...", "fromSec": 1.82, "toSec": 1.5}], "overallLong": {"answer": "아니오", "why": "..."}}
```
cell 은 영어 pawn/knight/bishop/rook/queen/king 으로 `잡은>잡힌`.
