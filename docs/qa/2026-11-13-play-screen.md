# 3차 (2026-11-14) — 잡기 표시 · 위험 표시 · 체크메이트 고리

## 바꾼 것

- **잡을 말 표시를 다시 그렸다.** 2차의 붉은 둥근 고리는 화면에서 보니 **흑 말의 붉은 발판과 겹쳐 보이지 않았다**(2차에서 「보지 못했다」고 적어 둔 자리). 이제 칸을 붉게 물들이고 네 귀퉁이에 흰 테 붉은 꺾쇠를 친다 — 발판이 닿지 않는 귀퉁이에 표시가 있다.
