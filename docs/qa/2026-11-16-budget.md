# 예산 비우기 — 첫 화면 JS · CSS (2026-11-16)

사용자 요청: 「예산 비우기」. 공방까지 넣고 나니 첫 화면 JS gzip 398KB / 400 · CSS gzip 11.72KB / 12 로 바닥에 닿았다([공방 기록](2026-11-16-workshop.md)).

## 한 것

**누를 때만 여는 화면 다섯을 늦게 받게** 했다(`React.lazy`). 한 번 연 뒤에는 닫아도 붙여 둔다 — 닫을 때 도는 정리(마을의 판 그리기 재개 등)가 그대로 돈다.

| 화면 | 받는 때 |
| :-- | :-- |
| 마을(`VillageView` — 공방 창 포함) | 🏝 단추를 누를 때 |
| 외형 · 설정 | 메뉴의 단추를 누를 때 |
| 라이벌 | 라이벌 단추를 누를 때 |
| 친구 대전(`Online`) | 👫 를 누르거나, 초대 링크(`?room=`)로 들어올 때 |

- 친구 대전은 방이 없고 닫혀 있으면 아무것도 그리지 않는다. 다만 열릴 때 랭크 서버에 내 점수를 묻는 일이 **처음 열 때로 미뤄졌다**(전에는 게임을 켤 때 물었다). 친구 창 안에서만 쓰는 값이다.
- **손과 뇌**(꺼진 기능, `HAND_BRAIN_ENABLED = false`)는 화면과 스타일을 빌드에서 통째로 뺐다. 다른 파일에서 플래그를 읽으면 빌드가 분기를 접지 못해, 플래그 파일(`src/cards/teamPlay.js`) 안에 화면을 받는 길(`loadHandBrain`)을 두었다. 스타일은 `src/handBrain.css` 로 옮겼다.
- 쓰지 않는 CSS 규칙 셋(`.hud-divider` 둘 · `.lang-toggle-btn` 둘)을 지웠다. 소스 전체에서 이름을 찾아 안 나오는 것만. 동적으로 만드는 이름(`tier-${n}` 등)은 남겼다.

## 재 보지 않았다 · 남은 것

- 처음 누를 때 조각을 받는 동안의 빈틈(느린 망에서 창이 늦게 뜬다)은 재지 않았다. 지금은 받는 동안 아무것도 안 보인다(`fallback={null}`).
