## 만들다 고친 것

## 알고 넘어간 것

1. **뽑히는 경우는 여전히 둘뿐이다**(미어캣 ×2 또는 ×3, 캥거루·판다는 늘 같다). 기계는 화려해졌지만 몇 판 두면 결과가 뻔하다. 세트를 늘리려면 후보마다 AI 300판으로 길이·선공 편향을 재야 한다 — 다음에 정할 것.
2. 첫 보석까지의 시간이 늘었다(아래 확인 절의 수치). 「너무 짧다」에 대한 답이라 의도한 것이지만, 매 판 레버를 당겨야 한다. 「빠르게」 설정에 묶어 자동으로 돌리는 길은 만들지 않았다.
3. 기계가 떠 있는 동안은 위쪽 메뉴도 가려진다(레버를 당겨야 판으로 간다).
4. 소리는 합성이다. 실제 기기에서 들어 보지 않았다. 실제 GPU · 실제 폰에서의 끊김도 재 보지 않았다(헤드리스만).
5. 내가 흑일 때 AI 첫 수를 기계 뒤로 미루는 길은 코드만 넣고 화면 검증은 하지 않았다(지금 계약전은 늘 백으로 연다).
6. 세로 화면에서 간판 위 왕관이 HUD 안내 글과 겹친다(어두운 막 아래).
7. 사람이 이 기계를 보고 「슬롯」으로 느끼는지, 레버를 찾는지는 재 보지 않았다.

## 알고 넘어간 것 (세트 · 잭팟)

1. **잭팟은 미어캣뿐이다.** 캥거루·판다·코뿔소 셋은 「둘 다 잡기」가 돼 32~62% 가 무승부로 끝나 넣지 않았다. 다른 동물의 잭팟을 넣으려면 규칙이 달라야 한다(예: 「먼저 하나」 — 왕관 보석 둘이라는 틀을 바꿔야 해서 하지 않았다).
2. 잭팟 판의 HUD 는 「미어캣 ×1 · ×2 · ×1」 세 칸으로 보인다(셋째 칸은 쓰이지 않는다). 안내 한 줄이 「3마리」라고 말하지만 칸만 보면 헷갈릴 수 있다.
3. 한 번만 합격한 5개(p2n2b2 · p2n2q · p3br · p3n2b · p3nq)는 뺐다. 「최대」를 더 밀려면 이 다섯을 200판씩 다시 재면 된다.
4. 측정은 「정식」 상대(계약을 다 아는 AI, 보통 단계)끼리다. 입문·초급 상대와 사람은 재 보지 않았다. 코뿔소·호랑이 목표는 쓰임이 25~32% 로 낮은 편이다(합격선 바로 위).
5. 연습 문제(30개)는 여전히 예전 두 세트(p2nb · p3nb)의 국면이다. 새 세트의 문제는 만들지 않았다.
6. 「놓친 왕관」 다시 보기와 금빛 결정타는 잭팟에서 코드상 같은 규칙을 쓰지만 화면 검증은 하지 않았다.
