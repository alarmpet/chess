# IR-2 왕관 보석 — QA (2026-11-13)

[직관성·재플레이 계획](../plans/2026-11-12-intuitive-replay-plan.md) §0.2 ①, §0.3 의 셋째 단계. 계약전(시험 스위치 `?lab=contract`)에서만 돈다.

출발점: 점수가 HUD 의 체크 칸에만 있었다. 「목표 둘을 먼저 채우거나 왕을 제압하면」이라는 두 승리 길이 서로 다른 말로 적혀 있었다.

## 바꾼 것

| 스토리 | 내용 |
| :-- | :-- |
| **왕의 왕관에 보석** | 양쪽 왕 머리 위에 **보석 자리(고리) 둘**이 늘 떠 있다. 목표 하나를 채우면 그 자리에 보석이 선다 — 둘이 차면 왕관 완성(= 계약 승리). 왕이 움직이면 따라간다. 보석 색은 채운 목표의 종류(딱지와 같은 계열) |
| **잡은 말 → 보석 → 왕관** | 목표를 채운 그 잡기의 칸에서 보석이 떠올라 0.85초 동안 포물선으로 날아가 왕관에 박히고 한 번 통 튄다. 이어 하기·되돌리기로 맞춰진 보석은 날지 않고 바로 선다(목록은 늘 기보에서 다시 센다) |
| **HUD 를 보석 문법으로** | 머리줄이 판 위 두 왕관의 거울이다: 「내 왕관 ○○ · 입문 상대 ○○ · 남은 차례 N」. 찬 자리는 색 + 그 목표의 체스 기호. 규칙 한 줄은 「보석 둘로 왕관을 먼저 완성하면 승리! 상대 왕을 제압해도 이겨요.」 종료 배너는 「왕관 완성」, 결과 줄은 「미어캣 ×2 · 판다 보석으로 왕관을 먼저 완성했어요.」, 점수는 채운 순서대로 놓인 보석 |

- 처음 크기(반지름 0.085칸)는 폰 화면에서 고리가 점처럼 보였다 → 0.13칸, 고리 두께와 간격도 키웠다. 캡처로 다시 봤다.

## 재 보지 않았다 · 남은 것

- **사람.** 이 단계의 사람 측정(연습 뒤 이기는 법을 자기 말로 설명 · 폰 1/2 구별)은 하지 않았다. 「왕관 보석」이 「목표 둘」보다 잘 읽힌다는 것은 아직 가설이다.
- 세로 화면에서 **상대 왕의 보석 자리가 목표판 뒤에 반쯤 가린다**(맨 윗줄의 딱지도 같다). HUD 머리줄의 거울이 같은 정보를 보여 주지만, 판 위에서는 덜 보인다.
- 판 위 보석은 수(자리와 보석)로 읽고, 종류는 색으로만 다르다 — 종류 기호는 HUD 에만 있다.
- 목표의 중간 진도(폰 1/2)는 판 위에 없다. 예전처럼 목표판의 체크 칸에만 있다.
- 되돌리기로 보석이 빠지는 것, 상대(AI)가 보석을 얻을 때의 비행, 메이트로 왕이 쓰러질 때 보석 자리의 모습은 화면으로 보지 않았다(단위 테스트는 목록만 본다).
- 소리: 박힐 때 `reelStop` 합성음을 높여 쓴다 — 듣지 못했다.
- 효과 줄이기 설정과 보석 비행의 관계, `p3nb` 세트, 실제 폰, 친구 대전(닿지 않는다).
