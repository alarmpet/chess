# 욕망 설계 라운드 (2026-11-02)

결과 계획서: [욕망 계획서](../../../plans/2026-11-02-desire-plan.md).

사용자 요청: 소유욕·부러움·탐욕·시기·질투·중독성·현금결제까지 갖춘 게임. 자료를 다 모아 LLM 협업으로 계획서를 갱신하라.

## 방법

1. 통합자 쪽 조사 둘을 병렬로 돌렸다. 하나는 법·플랫폼 원문(부록 A, 12건), 하나는 심리 연구와 시장 사례(부록 B, 21건)다. 원문을 열지 못한 것은 "미확인"으로 표시했다.
2. 통합자가 세 모델을 읽기 전에 `r1-claude.md` 를 썼다.
3. 세 모델에 같은 브리핑과 부록을 주었다. 브리핑에는 "넣지 마라만 하는 답은 쓸모없다, 감정을 최대로 일으키는 법을 내고 선을 그어라"를 넣었다.

| 파일 | 내용 |
| :--- | :--- |
| `BRIEF.md` `APPX-A.md` `APPX-B.md` | 공통 지시서와 부록. 모델에는 셋을 이어 붙여 주었다 |
| `r1-claude.md` | 통합자 판정 |
| `r1-agy.md` | agy. 「도구를 쓰지 마라」 첫 줄 + 인라인(15KB) |
| `r1-grok.md` | grok. `--prompt-file`, 계획 모드. 답이 `~/.grok/sessions/.../plan.md` 에 있었다 |
| `r1-codex.md` | codex 읽기 전용. 답이 두 번 출력되어 한 벌만 옮겼다 |

- 브롤스타즈 수치(8.8배, MAU 2.4배, DAU 3.9배, 2023-06~2024-02)는 mobilegamer.biz 원문에서 확인했다. 원문은 「Those features worked」라고 써서 여러 변화의 합이다. 조사 요약의 "Starr Drops 를 되살린 뒤 8.8배"는 과장이다.
- 저장소 주장: grok 의 "외형 단계 전부 열림"(`src/LookPanel.tsx:136`) 참. codex 의 "§12.3 합성 없음 vs 무료 합성" 참. codex 의 줄 인용(`docs/PLAN.md:414`, 재미 계획 신호표) 참.

## 갈린 것

- **돈을 언제 여나:** agy 는 7단계에서 학습·스킨·후원을 바로 판다. grok 은 ♡ 로 수요를 잰 뒤 연다. codex 는 출시 0, 사람 관찰 뒤 소규모 시험. → grok·codex 쪽을 택하고 ♡ 와 사람 질문을 합쳤다.
- **유료 재화:** agy 는 "0종이 가장 약한 결정(전환율)", grok 은 나중에 하나만·교환 불가, codex 는 0종. → 0종으로 시작, 연다면 grok 안.
