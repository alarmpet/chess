# r1-claude — 통합자 독립 판정 (셋을 읽기 전, 2026-10-28)

§14 는 내가 썼으므로 이 문서는 "자기 안을 스스로 깨는 것" 이다. 앵커링을 피하려고 셋을 읽기 전에 적는다.

## 1. 내가 보는 결함 (§14.9 네 가지 밖)
1. **승급 선택 UI 는 기존 코드와 세 군데에서 충돌한다.** `:2498~2503` 은 무조건 퀸. AI 수 `:2148` 도 `'queen'` 고정. 선택 UI 를 넣으면 AI·원격·PGN 경로에 `promotion` 전달이 전부 맞아야 한다. 또 **초읽기 중 선택 화면은 시간을 먹는다** — lichess 는 "자동 퀸" 옵션이 있다고 기억(확인 전). 어린이가 진화 화면을 구경하는 동안 시계가 간다.
2. **네 개의 진행축**: 레이팅 · XP/레벨 · 성장 4단계(배우별) · 상점 등급 C/B/A/S · 훈장. 어린이는커녕 어른도 헷갈린다. 성장 단계와 상점 등급이 둘 다 "외형이 더 멋짐" 이라 **같은 축의 중복**이다. 하나는 빼야 한다 — 성장(공짜·시간) 을 남기고 상점 등급은 "테마(의상 세트)" 로 바꾸는 쪽이 맞을 수 있다.
3. **무기 = 폭력 표현 → 등급분류**. 동물이 검으로 동물을 베는 연출은 전체이용가에서 "만화적 폭력" 으로 다뤄질 텐데 GRAC·IARC 기준을 보지 않았다. 코믹 무기(당근검) 는 괜찮아도 검·활은 등급을 올릴 수 있다. 재 보지 않았다.
4. **혼합 군단 동기화**: 상대가 내 군단을 봐야 하므로 편성(16칸 배우 ID + 장비) 이 Supabase 메시지로 가야 한다. 소유하지 않은 배우를 편성에 넣는 치트 → 서버 소유 검증 필요. 작은 일이지만 §12.1 에 없다.
5. **"포크(식기) 무기" 는 영어 농담**이다. 한국 어린이에게 "나이트 포크" 는 번역이 없으면 안 통한다. 훈장 이름은 한국어 체스 용어("양걸이") 로 다시 지어야 한다.
6. **배우별 성장은 수집을 분산**시킨다 — 폰 3종이면 한 배우를 전설까지 키우는 데 필요한 판 수가 3배. 수치 없이 "N판" 이라 적었다.

## 2. 후보 판정(내 안)
| 후보 | 판정 | 이유 |
| A 캐스팅+승급 진화 | **수정** | 캐스팅은 넣되 승급 선택은 "자동 퀸 기본 + 선택은 설정" 으로. 진화 연출은 자동 승급에도 붙는다 |
| B 무기 4종 | **수정** | 등급분류 확인 전엔 코믹·비접촉 무기(당근검·물총·악기) 먼저. 검·망치는 보류 |
| C 캐슬링 방패벽 | **채택** | 비용 작고 규칙 충돌 없음 |
| D 훈장 3개 | **수정** | 이름을 한국어 용어로. 수치는 5b 실측 |
| K | 아니오 — 캐스팅 하나만이라도 넣는 쪽 | 사용자 요청의 핵심이 "내가 고른다" 다 |

## 3. 가장 약한 결정
"성장 4단계 + 상점 등급 C/B/A/S 를 둘 다 둔다". 재는 법: 테스터 5명에게 두 화면을 보여 "둘이 뭐가 다르냐" 를 묻는다. 셋 이상이 설명 못 하면 하나를 뺀다.
