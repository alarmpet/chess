# 공유 미션 · 판 배치와 게임 띠 · 바다 파도 — 세 모델 설계 라운드 (2026-11-05)

사용자 원문: 미션을 흑백에게 같이 뿌리고 먼저 달성한 쪽에 메리트, 1·2·3개 클리어 사다리는 예시일 뿐 더 좋은 방법을 찾을 것, 판을 위·아래로 옮겨 미션·타이머 같은 게임 요소를 작게 표시, 위쪽 바다가 너무 잔잔하다. LLM 협업 요청.

## 방법

| 모델 | 역할 | 실행 | 입력 |
| :--- | :--- | :--- | :--- |
| agy | 아홉 살 어린이와 부모 | `--mode plan --sandbox --add-dir`(읽기 전용) | 공통 `BRIEF.md` + `role-agy.md` |
| grok | 게임 시스템 설계자(밸런스·공정성) | `--permission-mode plan --allow Read` | 공통 + `role-grok.md` |
| codex (`gpt-6-sol`) | 체스를 오래 둔 어른, 연출 싫어함 | `exec -s read-only -i 캡처 2장` | 공통 + `role-codex.md` |

통합자는 셋을 읽기 전에 `r1-claude.md` 를 썼다. 원문 자료(미션 정의·정산 코드·카메라·바다 셰이더·어두운 패턴 규칙·휴대폰/데스크톱 캡처)를 그대로 주었다. 2라운드는 돌리지 않았다 — 갈린 쟁점을 봇 측정과 실기기 캡처로 끊었다.

## 수렴 — 셋 다 같은 결론, 통합자는 달랐음

| 쟁점 | agy | grok | codex | 통합자(사전) | 채택 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 판당 미션 수 | 1 | 1 | 1 | 3 | **1** — 사다리 없음. 셋 다 「3개·사다리는 기억도 못 하고 체스를 방해」 |
| 고르기 창 | 없앰 | 없앰 | 없앰(자동) | 없앰 | **없앰** — 판 시드로 한 개 |
| AI 가 미션을 쫓나 | 아니오 | 아니오(가산 0, 넣더라도 +40 상한) | 아니오 | 아니오 | **아니오** — 고무줄 금지와 같은 줄 |
| 파도 | 셰이더만 | 셰이더만, 노이즈 호출 0 추가 | 셰이더만 | 정점 변위 128×128 | **셰이더만** |

통합자의 사전안(미션 3개 + 개수 사다리, 정점 변위)은 둘 다 버려졌다.

## 갈림과 끊은 방법

| 쟁점 | 안 | 끊은 것 |
| :--- | :--- | :--- |
| 보상 | agy: 카드 + 도토리 10, 놓치면 부스트 + 도토리 5 · grok: 먼저 한 쪽만 도토리 +4, 카드 없음 · codex: 달성한 쪽마다 도토리 2 | **grok 안**(값만 8). 근거를 저장소에서 확인: 지금 미션 성공은 `pay(..., { floor: 1 })`(`CardLayer.tsx`)로 같은 잡기에 카드가 한 장 더 나오고 최저 등급이 올라간다 — `dark-pattern-rules.md` 「무작위는 공개한다: 드롭표와 보장」과 어긋나는 숨은 표. 놓침 `boost` 도 보장 카운터를 흔든다. 도토리는 카드 경제를 안 탄다. 8 은 승·패 도토리 차 15(`COINS = { win: 30, draw: 20, loss: 15 }`)보다 작아 「미션 하고 지기」가 「이기기」보다 낫지 않다 |

## 통합자 오류

- 사전안 「미션 3개 + 사다리」는 아홉 살 기억 범위·카드 경제를 따지지 않았다. 셋이 독립으로 버렸다.
- 사전안 「정점 변위」는 필요 없었다 — 셰이더만으로 물마루·흰 파도가 보이고 GPU 차이는 측정 흔들림 안(아래 qa).
- 지시서의 경로 치환 `sed` 가 실패해 셋에게 상대 경로 그대로 나갔다. grok 은 그 폴더에서 돌아 문제없었고, agy·codex 도 파일을 찾아 읽었다.
