# 자료 조사 라운드 — 「체스 위 목표 층」 아이디어가 인기 게임에 실제로 있나 (WILD CROWN, 2026-11-05)

너는 세 모델 중 하나다. 서로의 답은 못 본다. 통합자(Claude)가 **네가 낸 주소를 브라우저로 하나씩 열어** 확인하고, 확인된 것만 쓴다.
**저장소 파일은 고치지 마라. 셸 명령은 쓰지 마라.** 웹 검색·웹 읽기 도구와 파일 읽기만 쓴다.

## 배경

귀여운 동물 3D 체스 웹 게임(어린이 사용자 많음). 체스 규칙·승패·AI 강도는 바꾸지 않는다. 판 위에 「할 거리」(목표·경쟁 층)를 얹어 정적인 체스를 익사이팅하게 하려 한다.
통합자가 쓴 계획서 `plan.md`(이 폴더, 원문)에 아이디어 7개가 있다: ① 현상금 말 ② 기술 도장 ③ 반격 목표 ④ 오늘의 퀘스트 3개 ⑤ 숨은 목표 카드 ⑥ 손과 뇌 ⑦ 2주 이벤트 판.
**사용자가 물었다: 「다른 인기 게임에서 가져온 인기 요소가 맞냐, 지어낸 거냐」.** 통합자가 스스로 점검한 결과: ①·③ 은 사실상 통합자 창작(도타 현상금·역전 장치 일반론에서 개념만), ②·④ 는 근거가 약함(장난 서브레딧 댓글, chess.com 포럼 **사용자 제안**, 작은 개인 사이트), ⑤·⑥·⑦ 은 실제 출처가 있음(보드게임, chess.com 의 Hand and Brain 소개, 클래시 로얄 체스 이벤트). 이 점검을 다시 내지 마라 — **새 증거**를 찾아라.

## 할 일

네 영역(역할 파일)에서 **실제로 출시된 인기 게임·앱**의 「판 위 목표·보너스·업적·퀘스트·이벤트·협동」 요소를 **최소 15개** 찾아라. 각 항목:

| 칸 | 내용 |
| :--- | :--- |
| 게임 | 이름, 플랫폼 |
| 인기 근거 | 다운로드·플레이어 수·평점 수·매출 순위 등 숫자와 그 출처 주소. 없으면 「없음」 |
| 요소 이름 | 게임 안에서 부르는 이름 그대로(예: Brawl Stars 「Bounty」) |
| 어떻게 돌아가나 | 2~3줄, 구체적으로 |
| 출처 주소 | 그 요소를 설명하는 **공식 페이지·위키·스토어·패치 노트** 주소. 주소가 없거나 기억으로 쓴 것은 「기억」이라고 표시 — 통합자가 못 찾으면 버린다 |
| 우리 7개와의 관계 | 어느 번호를 뒷받침하나/반박하나, 또는 「새 아이디어」 |
| 체스에 옮길 때 주의 | 어린이·공정성·체스 학습과 부딪히는 점 |

그리고 따로:
1. **반대 증거**: 그런 요소가 실패했거나 삭제됐거나 플레이어 반발을 산 사례(주소와 함께) 3개 이상.
2. **7개 각각에 대한 판정**: 「인기 게임에 같은/비슷한 것이 있다(어디)」 / 「없다(찾아본 범위)」.
3. 네가 보기에 **근거가 가장 강한 새 아이디어 3개**.

**지어내지 마라.** 게임 이름·요소 이름·숫자·주소 중 하나라도 확인 못 하면 그 칸에 「확인 못 함」. 지어낸 주소가 하나라도 나오면 그 모델의 답 전체 신뢰도를 낮춘다. 한국어로 답한다(게임·요소 이름은 원문).
