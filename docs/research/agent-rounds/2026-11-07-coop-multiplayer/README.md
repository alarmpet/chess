## 갈린 쟁점과 끊은 방법

- **매 수 뇌·손 역할 교대(codex·agy) vs 판마다 자리 바꾸기(grok).** grok 의 반대 근거는 「같은 팀이 완전한 수를 번갈아 두자 상대가 약한 사람 차례 직전에 어려운 수를 뒀다」(mrp6gf, 원문 확인). 이것은 **사람 상대·교대 착수** 이고, 뇌·손 역할 교대와는 다른 형식이다. 반대로 「지휘자를 매 턴 강제로 바꾸면 잘 된다」(r/boardgames g2hj7n 댓글)는 역할 교대를 지지한다. → 봇 측정 `tools/coop_sim.mjs` B(40판씩): 매 수 교대 팀 승 48%, 고정 두 방식 38%·38%. 차이는 잡음 범위라 「교대가 나쁘지 않다」까지. 기본값은 교대, 사람 시험에서 다시 본다.
- **통합자만 찾은 것: 돌려 두기.** 커플·가족 글 4개(6ywlvv 50점·1v393pj 49점·mv92wx 35점·1q8s5ps 4점)가 「N 수마다 / 앞서면 판을 돌려 진영을 바꾼다」를 집안 규칙으로 적었다. 세 모델 모두 내지 않았다. → `tools/coop_sim.mjs` A(40판씩): 약한 쪽 승 교대 없음 5% · 8수 15% · 5수 13% · 3수 33%. 방향은 맞고, 레딧의 「5수」는 봇에게 약했다.

## 통합자 예측과 비교

- 맞음: 같은 화면 먼저, 손과 뇌 확장이 가장 싸다, 「한 사람이 다 두기」가 가장 큰 위험, 버그하우스는 규칙이 표준 체스가 아니라 안 맞음.
- 틀림·빠짐: 「정보 비대칭이 있어야 대화가 생긴다」만 보고 **경쟁 속 협동(돌려 두기)** 을 예측하지 못했다. 커뮤니티는 커플이 같은 편이 되는 것보다 「서로 두되 실력 차를 지우는 집안 규칙」을 더 많이 말했다.
- 「공유 섬」은 근거를 찾지 못했다(찾아본 범위: 위 검색어 20개, 스레드 3개). 계획서에 넣지 않는다.
