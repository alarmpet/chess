## 2. 바꿔서 가져올 것

- **오프라인 타이머 성장** → 판이 한 번 끝나면 자라고 수확(섬 §4). `tickVillage`의 4시간 도토리(`economy.js:320`)는 이미 “판 끝 손님”으로 바꾸기로 되어 있다. Garden의 핵심 감정(꺼도 내 것이 자란다)은 남기고, 시계는 체스로 둔다.
- **5분 재입고·RESTOK 카운트다운** → 판 끝 주민 주문 교체(섬 §5). 못 채워도 벌 없음. ACM “deceptive timers”와 §7 한정 판매 규칙을 지킨다.
- **Admin Abuse / 토 접속 강제** → 달력에 적힌 주간 팩. 접속하지 않아도 다음 판에 내용이 있다. 피크를 만드는 장치(한정 접속)는 버린다.
- **날씨 돌연변이 배율** → 판 수·섬 번호로 시드된 **보기용 날** (축제 등불 색). 판매가·드롭에 안 닿음(§5 돈은 카드에 안 닿는다).
- **펫 알 뽑기** → 이미 있는 판 끝 카드 뒤집기(§5). 모양만 “알”로 바꾸지 않는다.
- **시즌 씨앗** → 시즌 작물·섬 소품. 종료일과 재판매 여부를 달력으로만 보임(§7).

## 3. 가져오지 않을 것

유료 알·성장 가속·Robux 재입고, 실시간 썩음·물 주기, 작물/펫 훔치기, 거래·RMT, 푸시·연속 접속 벌, 서버 라이브 스턴트. 이유: 욕망 §7·§8·§9와 1인·무서버 제약. 훔치기는 Garden 커뮤니티가 이미 이탈 원인으로 찍었다(GameRant).

## 4. 틀릴 수 있는 곳 셋

1. **주간 리듬의 무게.** Garden 주간 단위는 씨앗 메시 + 관리자 라이브다. 우리 주간 단위를 캐릭터 GLB로 잡으면 1인이 못 따라간다.
2. **“다음 판에 익어 있음”이 “내일 들어와 있음”을 대체하지 못할 수 있다.** Garden 재방문의 절반은 실시간 성장이다. 체스 한 판의 비용이 더 크다. 시뮬 없이 감각으로 칸 수·작물 가를 정하면 창고가 빨리 찬다(섬 §4가 이미 경고).
3. **과시 경로가 없다.** Garden은 4인 서버 + TikTok 부화가 광고다. 우린 서버가 없고, 아이 계정 섬 공개는 기본 끔(§8). 시각을 키워도 공유가 안 되면 “매주 바뀌는 섬”의 외부 엔진이 없다.

## 5. 가장 약한 결정 하나

**주간 업데이트를 Garden과 같은 성장 엔진으로 보는 것.** 22.3M은 로블록스 발견·한정 접속·Admin War의 합이고, 한 시간 만에 꺼졌다. 1인 웹 체스가 가져갈 수 있는 것은 그 숫자가 아니라, **설명 가능한 밭과 달력으로만 바뀌는 섬**이다. 주간 단위를 JSON 한 덩어리로 못 박지 않으면 이 계획 전체가 캐릭터 파이프라인에 짓눌린다.
