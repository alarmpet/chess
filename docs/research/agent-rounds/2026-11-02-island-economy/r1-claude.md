# r1-claude — 통합자 독립 판정 (세 모델 답을 읽기 전)

1. **중도 이탈:** 찬성하되 "판 주머니"로. 잡은 카드는 판 중 주머니에 들어가고 판이 끝날 때(승·패·무·기권 모두) 도감에 들어간다. 탭을 닫으면 주머니는 사라진다. 대신 **진행 중 대국을 자동 저장해 다시 열면 이어 하기**를 같이 넣어야 우발적 종료가 벌이 되지 않는다. 기권은 끝으로 친다(지는 판을 억지로 끌지 않게). 지금 구조에서 이것만 먼저 하면 이탈이 오히려 손해가 된다.
2. **카드 다양화:** 동물 6종을 늘리기보다 축을 더한다 — ① 판 사건 카드(캐슬링·승급·앙파상·체크메이트 수·연속 잡기) ② 작물·재료 카드(판 끝 보상) ③ 계절·한정 외형(시간 기반 금지 → 판 수 기반 계절). 사건 카드는 체스를 더 읽게 한다.
3. **농장:** 작물 4~6종, 각 작물이 말 영향권 모양을 좋아한다(당근은 L자 캥거루 등). 심기 → 다음 판 끝 수확. 실시간 타이머 없음.
4. **경제:** 사슬 깊이 3까지만. 밭 → 공장(가공) → 상점(판매, 수요가 판마다 바뀜). 백화점은 꾸미기·외형 소모처. 소모처가 없으면 인플레이션 — 도토리는 꾸미기·외형·건물 업그레이드로 빠져야 한다.
5. **가장 약한 결정:** "미니 현실 경제"는 범위가 커서 체스가 메타에 묻힐 위험. 사람 측정 전에 4단계 이상 가지 말 것.
