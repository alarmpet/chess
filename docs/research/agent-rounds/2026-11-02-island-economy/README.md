# 섬 경제 설계 라운드 (2026-11-02)

결과 계획서: [섬 경제 계획서](../../../plans/2026-11-02-island-economy-plan.md).

사용자 요청: 카드 다양화, 판이 끝나기 전에 나가면 카드 없음, 카드로 농장·작물 조작, 상점·공장·백화점이 있는 미니 현실 경제, 더 밀접하고 중독성 있는 판 사이 흐름.

## 방법

| 파일 | 내용 |
| :--- | :--- |
| `BRIEF.md` | 세 모델 공통 지시서. 중점만 갈랐다(agy 카드·이탈, grok 농장, codex 경제) |
| `r1-claude.md` | 통합자 판정. 세 답을 읽기 전에 썼다 |
| `r1-agy.md` | agy. 파일을 읽지 못해 `src/cards/economy.js` 와 `src/village/economy.js` 원문을 프롬프트에 넣었다 |
| `r1-grok.md` | grok. 계획 모드로 돌았고, 답을 세션의 `plan.md` 에 썼다. 그 파일을 옮겼다 |
| `r1-codex.md` | codex 읽기 전용. 저장소를 직접 읽었다. 도구 기록은 빼고 최종 답만 옮겼다 |

실행 제약: 권한 우회 옵션(`--dangerously-skip-permissions`, `bypassPermissions`)은 자동 모드 분류기가 막았다. 80KB 프롬프트는 셸 인자 한계를 넘었다. 그래서 agy 는 27KB 로 줄인 원문과 "도구를 쓰지 마라"를 붙여 돌렸고, grok 은 `--prompt-file` 과 `--permission-mode plan` 으로 돌렸다.

## 거짓이거나 채택하지 않은 주장

| 주장 | 모델 | 판정 |
| :--- | :--- | :--- |
| 멀티플레이에서도 잡기 카드가 바로 저장된다 | grok | 거짓. `reportCapture` 는 싱글이 아니면 돌아간다 |
| 보장이 10판/60판이다 | agy | 거짓. 카드 장수 기준이다 (`RARE_GUARANTEE`, `HERO_GUARANTEE`) |
| 패배 도토리가 `src/village/economy.js:205-208` 에 있다 | agy | 틀린 인용. 6줄 `COINS` 다 |
| 이어 하기 없이 새로고침 때 주머니를 버린다 | agy, grok | 채택 안 함. 휴대폰 탭 종료에서 어린이가 카드를 잃는다 |
| 직무 배지를 35% 확률로 드롭 | agy | 채택 안 함. 판 사이에 고르는 배지로 바꿨다 |
| 장인의 망치로 즉시 완공 | agy | 채택 안 함. 판 끝 개장 페이스를 깬다 |

확인된 주장: 잡는 순간 저장, 기권 버튼 없음, 대국 이어 하기 없음, 건물 합계 750 도토리, 라이벌 방문의 4시간 도토리, 밭 이삭이 곡물 > 0 으로 익음, 같은 건물 두 채 불가.

셋이 모두 "직무 배지"를 냈다. 수렴은 근거가 아니므로 저장소 사실이 아닌 설계 선택으로만 다뤘다.

## 닿지 못한 것

사람 측정은 없다. 수치는 모두 시작값이고, 페이스는 구현 뒤 `island_sim.mjs` 로 다시 잰다.
