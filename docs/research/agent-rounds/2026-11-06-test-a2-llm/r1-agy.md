## 1부 — 누가 잡았나 (sig-1 ~ sig-6)

### sig-1
- **잡은 동물 / 잡힌 동물**: 흑 코뿔소(흑 룩)가 백 미어캣(백 폰)을 잡았어.
- **무엇을 보고 알았나**: 글자(「쾅!」) / 효과(바닥에 퍼지는 노란 충격파 동그라미랑 별) / 말의 모양·자세(위에서 흑 코뿔소가 세게 들이받아서 백 미어캣이 튕겨 날아가고 있어).
- **확신**: 5

### sig-2
- **잡은 동물 / 잡힌 동물**: 흑 캥거루(흑 나이트)가 백 미어캣(백 폰)을 잡았어.
- **무엇을 보고 알았나**: 글자(「뽁!」) / 효과(주황 네모·별 조각) / 말의 모양·자세(분홍 받침의 흑 캥거루가 뛰어내렸고, 노란 받침의 백 미어캣이 뒤로 발라당 넘어져 있어).
- **확신**: 5

### sig-3
- **잡은 동물 / 잡힌 동물**: 백 사자(백 킹)가 흑 판다(흑 비숍)를 잡았어.
- **무엇을 보고 알았나**: 글자(「어흥!」) / 효과(사자 발밑 노란 고리 충격파랑 초록 할퀴기 자국) / 말의 모양·자세(금빛 갈기의 백 사자가 큰 소리로 포효하면서 덤벼든 흑 판다를 쳐냈어).
- **확신**: 5

### sig-4
- **잡은 동물 / 잡힌 동물**: 백 캥거루(백 나이트)가 흑 미어캣(흑 폰)을 잡았어.
- **무엇을 보고 알았나**: 글자(「퍽!」) / 효과(노란 별 폭발) / 말의 모양·자세(투구 쓴 백 캥거루가 펀치를 날려서 흑 미어캣이 맞았어).
- **확신**: 5

### sig-5
- **잡은 동물 / 잡힌 동물**: 백 호랑이(백 퀸)가 흑 미어캣(흑 폰)을 잡았어.
- **무엇을 보고 알았나**: 글자(「샤악!」) / 효과(빛줄기랑 별) / 말의 모양·자세(왕관 쓴 백 호랑이가 빠르게 달려와 앞발로 할퀴고 흑 미어캣이 쓰러져 있어).
- **확신**: 5

### sig-6
- **잡은 동물 / 잡힌 동물**: 백 판다(백 비숍)가 흑 미어캣(흑 폰)을 잡았어.
- **무엇을 보고 알았나**: 글자(「쿵!」) / 효과(초록 대나무 잎이랑 별) / 말의 모양·자세(백 판다가 대나무 잎 날리면서 무겁게 덮쳐서 흑 미어캣을 쿵 눌렀어).
- **확신**: 5

## 2부 — 오늘 들어간 기능 화면 (s01 ~ s10)

### s01-rally-strip
- **무슨 뜻인가**: 가운데에 「반격 목표: 체크 한 번 → 도토리 +5」라고 적혀 있어서, 체크를 성공하면 도토리를 다섯 개 준다는 뜻이야.
- **방해 점수**: 2 (가운데 큰 글씨 알림이 체스판을 가려서 동물 말이 잘 안 보여).
- **켜기/끄기**: 상관없음 (도토리는 좋은데 글자가 너무 많아).
- **바꿀 것**: 가운데 위 알림(「반격 목표: 체크 한 번 → 도토리 +5」)을 화면 맨 위 구석으로 옮기기.

### s02-bounty-marks
- **무슨 뜻인가**: 잘 싸우는 동물 머리 위에 숫자 적힌 노란 주머니가 달렸어. 저 녀석을 잡으면 보물을 더 주나 봐.
- **방해 점수**: 0 (머리 위에 조그맣게 달려 있어서 전혀 안 방해돼).
- **켜기/끄기**: 상관없음
- **바꿀 것**: 없음.

### s03-quests-album
- **무슨 뜻인가**: 「📋 오늘의 퀘스트 2/3」 창인데 체스 숙제를 다 하면 도토리를 준다는 뜻이야.
- **방해 점수**: 1 (도감 창이지만 글자가 너무 빽빽해서 읽기 싫어져).
- **켜기/끄기**: 켜고 싶음 (도토리 많이 모아서 부자 될 거야).
- **바꿀 것**: 맨 아래 「자세히: 확률」 글자 빼기 (어린이는 확률 같은 거 몰라).

### s04-stamps-album
- **무슨 뜻인가**: 멋진 기술을 쓰면 도장을 찍어주는 칸인데, 「캥거루 포크」를 2번 했다고 도장이 찍혀 있어.
- **방해 점수**: 0 (도장 모으는 재미있는 책 같아서 안 방해돼).
- **켜기/끄기**: 상관없음
- **바꿀 것**: 맨 아래 「자세히: 확률」 글자 빼기.

### s05-handbrain-panel
- **무슨 뜻인가**: 「둘이 한 편이 돼요. 뇌가 말 종류를 부르면, 손이 그 말로 둬요.」처럼 엄마나 아빠랑 둘이 한 편이 돼서 두는 거래.
- **방해 점수**: 0 (시작할 때 고르고 닫으면 되니까 안 방해돼).
- **켜기/끄기**: 켜고 싶음 (엄마아빠랑 같이 하면 혼자 안 무서워).
- **바꿀 것**: 「혼자 두기」를 맨 위로 옮기기.

### s06-handbrain-family
- **무슨 뜻인가**: 가족이 캥거루를 불러줘서 「손: 캥거루로 둬요」, 「이번엔 캥거루만 움직여요」라고 알려주는 거야.
- **방해 점수**: 0 (판 아래에 딱 붙어 있어서 전혀 안 방해돼).
- **켜기/끄기**: 켜고 싶음 (무슨 말 움직일지 딱 정해주니까 쉬워).
- **바꿀 것**: 골라준 「캥거루」 버튼을 먼저 보이게 하기.

### s07-handbrain-adviser
- **무슨 뜻인가**: 로봇 조언자가 「조언자: 미어캣으로 둬 봐요」 하면서 도와주는 거야.
- **방해 점수**: 0 (조그만 띠 하나뿐이라 전혀 안 방해돼).
- **켜기/끄기**: 켜고 싶음 (체스 막 배워서 어려운데 힌트 줘서 좋아).
- **바꿀 것**: 없음.

### s08-blitz-setting
- **무슨 뜻인가**: 「⚡ 번개 판」을 켜면 내 차례에 「10초 안에 두면 도토리 1개」를 준다는 약속이야.
- **방해 점수**: 0 (설정 창 안이라 판 둘 때는 안 보여).
- **켜기/끄기**: 켜고 싶음 (빨리 두고 도토리 모으고 싶어).
- **바꿀 것**: 「시간이 다 돼도 잃는 건 없어요. 다음 판부터」 같은 긴 설명 글자 빼기.

### s09-blitz-green
- **무슨 뜻인가**: 오른쪽 위에 초록색 모래시계가 줄어드는데, 다 닳기 전에 빨리 두면 도토리를 받는 거래.
- **방해 점수**: 1 (초록 줄이 자꾸 줄어드니까 마음이 급해져).
- **켜기/끄기**: 켜고 싶음 (도토리 받으려고 더 신나게 둘래).
- **바꿀 것**: 모래시계 밑에 있는 「0/10」 글자 빼기 (초록 막대만 봐도 알아).

### s10-blitz-zoom
- **무슨 뜻인가**: 왼쪽은 10초 안이라 초록색이고, 오른쪽은 10초가 지나서 주황색이 되고 17초가 됐어.
- **방해 점수**: 1 (주황색이 되면 숙제 늦은 것처럼 쫓기는 기분이야).
- **켜기/끄기**: 상관없음 (시간 지나도 안 혼나니까 괜찮아).
- **바꿀 것**: 모래시계 밑에 조그만 「1/10」 글자 빼기.
