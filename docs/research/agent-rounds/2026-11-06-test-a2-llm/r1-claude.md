# 통합자 판정 — 모델 답을 읽기 전에 적음 (2026-11-06)

1. **시그니처(sig-1~6, 누가 잡았나):** 잡은 동물은 6장 중 4장 이상 맞힐 것이다 — 글자(뽁·퍽·쿵·쾅·샤악·어흥)는 동물 이름이 아니라서 글자만으로는 못 맞히고, 잡는 순간 두 말이 한 칸에 겹쳐 있어 「누가 누구를」이 헷갈리는 장이 있을 것(특히 sig-1 코뿔소↔호랑이, sig-5 호랑이↔미어캣). 잡힌 동물은 잡은 동물보다 덜 맞힐 것.
2. **반격 목표(기권 A/B):** 🔥 가 있는 화면에서 「계속」이 더 많을 것. 어린이 역할에서 차이가 가장 크고, 숙련 어른(codex)은 🔥 와 상관없이 국면으로 고를 것(−8, −11 은 새 판).
3. **손과 뇌 판:** 조언자 조건에서 블런더가 혼자보다 적을 것(봇 측정과 같은 방향). 숙련 어른은 차이가 작을 것. 가족 판에서 grok 뇌가 고른 종류에 최선 수가 있는 비율은 절반 남짓.
4. **화면 설문:** 셋 다 띠의 칩이 많다(🎯·🔥·📋·수)고 할 것 — 어린이가 가장 강하게. 번개 판 모래시계는 숙련 어른이 「압박」을, 어린이는 「도토리」를 먼저 말할 것. 손과 뇌 패널은 이해될 것. 현상금 💰 표식은 어린이가 「뭔지 모르겠다」고 할 것.
5. 모델이 지어낸 글자(화면에 없는 문장)를 인용하는 항목이 한두 개 나올 것 — 이미지에 있는 글자만 채택한다.
