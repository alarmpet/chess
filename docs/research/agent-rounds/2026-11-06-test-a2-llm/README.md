# 사람 시험 대기 항목을 세 모델이 먼저 한 라운드 (2026-11-06)

사용자 지시: 「사람 진행은 llm 협업해서 니네가 자료 수집해서 직접 진행해」. 대상은 오늘 넣은 기능의 사람 측정 — 시그니처 잡기(「누가 잡았나」), 반격 목표(기권), 손과 뇌(조언자·가족), 번개 판·퀘스트·도장·현상금 화면.
**이 라운드는 사람 시험을 대체하지 못한다.** 모델은 정지 화면·글자 판만 받았고, 생각 시간·손가락·소리는 없다. 결함과 방향을 찾는 라운드다. AT-9 는 11-05 에 이미 했다.

## ① 누가 잡았나 — 잡은 동물 정답률

| | sig-1 코뿔소→호랑이 | sig-2 미어캣→캥거루 | sig-3 사자→판다 | sig-4 캥거루→미어캣 | sig-5 호랑이→미어캣 | sig-6 판다→미어캣 | 잡은 동물 맞힘 |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| agy | 코뿔소 ✓ | 캥거루 ✗(거꾸로) | 사자 ✓ | 캥거루 ✓(색 반대) | 호랑이 ✓ | 판다 ✓(색 반대) | **5/6** |
| grok | 모름 | 캥거루 ✗(거꾸로) | 판다 ✗(거꾸로) | 미어캣 ✗ | 코뿔소 ✗ | 사자 ✗ | **0/6** |
| codex | 호랑이 ✗(거꾸로) | 캥거루 ✗(거꾸로) | 판다 ✗(거꾸로) | 미어캣 ✗ | 호랑이 ✓ | 판다 ✓ | **2/6** |

- **잡는 순간 정지 화면으로는 누가 잡았는지가 잘 안 읽힌다**(합 7/18). 틀린 것의 절반은 **거꾸로**(잡힌 말을 잡은 말로) — 두 말이 한 칸에 겹친 순간이라 받침 색·위치로는 갈리지 않는다. sig-2(미어캣이 캥거루를 잡음)는 셋 다 거꾸로.
- 글자(뽁·퍽·쿵…)는 동물 이름이 아니어서 단서로 약하다 — grok 은 「뿍」「픽」처럼 글자를 잘못 읽었고, 「어흥」을 호랑이 소리로 읽었다.
- 통합자 예측 1(4장 이상)은 agy 만 맞았다. **움직임(달려오는 말)이 빠진 정지 화면이라는 한계**가 크다 — 사람 시험의 「보였나」는 움직임 포함으로 다시 봐야 한다.
- 개선 후보(문구 아님): 잡는 순간 **잡는 말의 받침만** 잠깐 빛나게(누가 잡는지를 색으로) · 시그니처 효과를 잡는 말 쪽에서 시작하게. 사람 시험 전 결정.

## ③ 반격 목표 — 「계속 / 새 판」

| | 🔥 목표 있음: 계속 | 없음: 계속 |
| :-- | :-- | :-- |
| agy(어린이) | 2/2 (무응답 1) | 0/3 |
| grok(초보 어른) | 2/3 | 0/3 |
| codex(숙련 어른) | 1/3 | 0/3 |
| **합** | **5/8** | **0/9** |

- 같은 국면이라도 🔥 목표가 보이면 계속 두는 쪽이 늘었다. 이유는 「말 하나만 잡으면 도토리 5개」(agy), 「되찾기 목표가 떠서 아직 둘 맛」(grok). 숙련자는 국면이 나쁘면 목표와 상관없이 끝냈다(예측 2 맞음).
- **새로 찾은 것 — 기권해도 끝까지 둔 패배와 같은 도토리(15)를 받는다.** 어린이 역할이 목표 없는 세 국면 모두 「새 판 누르면 도토리 15개를 바로 받으니까」를 이유로 댔다. 코드 확인: 기권은 `reportGameEnd('loss', { resigned: true })` → 정산은 패배와 같은 `COINS.loss`(15). 지는 판을 끝까지 둘 도토리 이유가 반격 목표 +5 뿐이다. 결정 후보: 기권 판은 도토리를 줄이거나(예: 15 → 10) 「끝까지 둔 판 +5」를 둔다 — 벌로 느껴지지 않게(욕망 §7) 사람 시험과 함께 결정.

## ④ 손과 뇌 — 12수, 손실(탐색 2수 기준)

| 손 | 혼자: 평균 손실 · 최선 수 | AI 조언자: 평균 손실 · 최선 수 |
| :-- | :-- | :-- |
| agy(어린이) | **117** · 2/12 (블런더 1: 852) | **30** · 10/12 (블런더 1: 328) |
| grok(초보 어른) | 10 · 5/12 | 2 · 11/12 |
| codex(숙련 어른) | 20 · 5/12 | 8 · 9/12 |
| 가족(grok 부모 뇌 → agy 아이 손) | — | **2** · 8/12, 뇌가 부른 종류에 최선 수가 있던 것 7/12 |

- 조언자는 세 역할 모두의 손실을 크게 줄였다(봇 측정과 같은 방향). 가족 판에서 어린이 손의 평균 손실은 혼자일 때 117 → 2.
- **그런데 「힌트가 수를 대신 두지 않는다」는 약하다:** 조언자 조건에서 손이 최선 수를 그대로 둔 비율이 9~11/12. 봇(쉬움 손)은 43% 였다. 처음 12수는 종류마다 둘 수 있는 수가 적어(미어캣·캥거루 몇 수) 종류만 알려 줘도 거의 수가 정해진다. 결정 후보: 조언자가 「최선 수의 종류」 대신 「좋은 수가 있는 종류 둘」을 부르기, 또는 둘 수 있는 수가 2개 이하면 다른 종류를 섞기 — 사람(어린이) 시험의 「스스로 찾았다는 느낌」으로 정한다.
- 모델 호출 평균 20~97초라 생각 시간은 재지 않았다.

## 이 라운드에서 배운 것

- **cue:** 모델에게 qa 폴더의 옛 캡처를 줄 때. **lesson:** 캡처가 찍힌 뒤 기능이 바뀌었는지 확인하고, 바뀌었으면 다시 찍거나 「옛 화면」이라고 적는다. **evidence:** `s03` 옛 퀘스트 목록에 grok 이 결함을 냄.
- **cue:** 읽기 전용 CLI 를 node `spawnSync` 로 부를 때(Windows). **lesson:** `codex` 는 셸을 거쳐야 실행되고(`shell: true`), agy plan 모드는 명령 도구를 쓰려다 막히면 빈 답을 낸다 → 프롬프트 끝에 「도구 없이 바로 답하라」. **evidence:** 첫 시도 codex 0초 빈 출력, agy 「command permission auto-denied」.
