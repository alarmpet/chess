# 통합자 독립 판정 (세 모델의 답을 읽기 전, 2026-11-05)

AT-9 질문 둘(「여기가 체스판 밑이라는 걸 알겠나」「돔 안이 농장·마을·상점·공장으로 나뉘어 보이나」)과 화면 12장에 대한 내 예측. 모델 답을 읽은 뒤 맞은 것·틀린 것을 README 에 적는다.

1. **판 밑 — 반쯤만 읽힌다.** 잠수 프레임(03~05)은 판 가장자리 흙 단면으로 카메라가 내려가 물막이 덮는다 → 「아래로 내려갔다」는 읽힌다. 그러나 도착 화면(02·07)에는 판이 보이지 않는다(데스크톱에서 판 밑면이 화면 위 밖). 「바다 속 돔」은 읽히지만 「체스판 **밑**」은 연결이 약할 것이다. 휴대폰(11)은 맨 위 어두운 띠가 판 밑면인데 알아볼지 의문.
2. **0.8초 프레임(05)이 이상하게 보일 것이다.** 마을 UI(알약·고리·건물 버튼)는 이미 떴는데 3D 는 아직 체스판(흐린 물막 아래). 「UI 와 장면이 따로 논다」고 볼 모델이 있을 것.
3. **구역은 안 보일 것이다.** 바닥 색 차이(24~30%)는 체커 무늬·길·풀에 묻힌다. 이름 팝업(10)을 본 모델만 「거품 공방」을 말할 것. 「농장·마을·상점·공장」 구분은 건물로 읽을 것이다(밭·빵집·장터) — 구역이 아니라 건물이 구분을 만든다.
4. **휴대폰(11): 세 줄 고리 띠가 도구 버튼 줄을 덮는다.** 어린이 역할이 찾을 것. 이번 변경 전부터 있던 배치 문제다.
5. **첫 시선은 돔 리브와 빛줄기**로 갈 것이다. 리브가 섬을 가린다는 지적이 하나는 나올 것(특히 확대 08).
6. 밤(09)은 가장 「신비롭다」는 평을 받을 것이다.
7. 빈 섬(02) — 새 사람에게 무엇을 할지는 고리(「건물을 지어요」)와 아래 건물 줄로 읽힌다. 「돔이 비어 보인다」가 하나 나올 것.
8. 숙련자(codex)는 전환 0.9초가 길다고 할 것이다.

모델이 지어낼 위험: 이미지를 못 연 모델이 「해파리·거북」 같은 일반 수중 묘사를 지어낼 수 있다 → 각 주장의 위치를 캡처와 대조한다.
