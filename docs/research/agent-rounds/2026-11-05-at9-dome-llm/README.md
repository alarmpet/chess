# AT-9 를 세 모델이 먼저 한 라운드 — 수중 돔 마을 화면 평가 (2026-11-05)

사용자 지시: 「llm 협업해서 먼저 진행해봐」. 근거 계획서: [아틀란티스 수중 마을 계획서 §5 AT-9](../../../plans/2026-11-05-atlantis-village-plan.md).
**이 라운드는 사람 시험을 대체하지 못한다.** 세 모델은 정지 화면 12장과 글자 덤프만 받았다. 움직임·소리·손가락 감각은 판정하지 않았다. 결함을 찾는 라운드다.

## 방법

- 실제 게임을 Claude 내장 브라우저로 돌려 화면 12장을 찍었다(데스크톱 1024×768, 휴대폰 375×812, 커밋 `ec11ce2` + 미커밋 밤 수정 전). 체스판 → 잠수 0.2/0.3/0.8초 → 도착 → 새 사람의 빈 섬 → 완성 섬 낮·밤·확대 → 빈 칸 누름 → 휴대폰 마을·첫 화면.
- 질문은 AT-9 의 둘(「체스판 밑이라는 걸 알겠나」「돔 안이 나뉘어 보이나」) + 잠수 끊김 · 첫 시선 · 신비로움 · 다음 행동 · 바꿀 것 셋 · 역할 질문. 문구는 지어내지 말고 빼기·옮기기·먼저 보이기만(`BRIEF-common.md`).
- 입력을 갈랐다: 공통 8장 + 어린이(agy)는 휴대폰 2장, 초보 어른(grok)은 밤 1장, 숙련 어른(codex)은 확대 1장(`role-*.md`).
- 통합자 판정을 답을 읽기 전에 썼다(`r1-claude.md`).

| 모델 | 역할 | 실행 | 이미지 |
| :-- | :-- | :-- | :-- |
| agy | 체스를 막 배운 여덟 살 | `--mode plan --sandbox --add-dir .reports/consult-at9`(읽기 전용) | 10장 모두 열었다 — 화면 내용과 맞는 묘사 |

**실행 사고:** 처음엔 스킬의 기본 플래그(`--dangerously-skip-permissions`, `bypassPermissions`)로 셋을 함께 돌리려 했다가 **권한 분류기가 막았다**(「Create Unsafe Agents」). 우회하지 않고 세 CLI 의 **읽기 전용 모드**로 바꿔 돌렸고 셋 다 이미지를 열었다. 앞으로 이 저장소의 화면 평가는 이 방식으로 한다. codex 의 설정 모델 `gpt-6.1-sol` 은 ChatGPT 계정에서 400 이라 `-c model=gpt-6-sol` 로 돌렸고, 그 플래그가 설정 파일에 되써지므로 **백업 → 실행 → 복원**했다(설정은 `gpt-6.1-sol` 그대로).

## 남은 것 (판정 보류 + 재는 법)

- **건물 알아보기**(grok 1채, 그것도 틀림): 기본 거리에서 건물이 작다. 후보 — 건물 위 작은 이름표(아이콘), 또는 확대 단계. 재는 법: 같은 화면을 다시 세 모델과 사람에게 「이 건물은?」 8문항.
- **흰 카드 더미**(셋 다): 알림 여러 줄이 돔 왼쪽을 가린다. 후보 — 한 번에 한 줄, 나머지는 접기.
- **돔 뼈대가 새장 같다**(codex·grok): 확대 때 리브를 흐리게, 또는 유리 프레넬을 키워 「유리」가 먼저 보이게.
- **잠수 중 흙 단면**(grok·codex): 판 아래가 바다가 아니라 흙으로 보인다. 체스 장면의 섬 단면은 이번 범위 밖.
- 사람 시험(AT-9 본편)·휴대폰 실기기(AT-10)는 여전히 남는다. 이 라운드의 2/5 가 고친 뒤 몇이 되는지는 같은 브리핑으로 다시 돌려 잰다.
