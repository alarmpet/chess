# 통합자 선판정 — 메타게임(대전·등급·코인·상점·착용) (셋을 읽기 전, 2026-10-28)

사용자 요청: "친구나 다른사람과 대전도 하고 게임많이 하거나 많이 이기거나? 하면 등급업이나 레벨업도 하고 코인? 등도 모아서 예를들어 fifa 같이 막 비숍인데 A 급 비숍도 상점에서 사거나? 아님 막 멋진 아이템 착용하거나?"

기획서 v0.3 에는 이 영역이 없다(Phase 5 "멀티플레이" 한 단어, 결정 #4 커스텀 비용). 아래는 셋의 답을 읽기 전 내 안이다.

## 작업 가정 (사용자 미답 — 라운드에서 반박 가능)
**랭크 대전 = 외형만 다르다. 능력이 다른 기물은 별도 "야생 모드"(캐주얼·AI전·친구 초대전)에만.** 이유: chess.js·Stockfish 가 표준 규칙만 안다(§4.5). 능력 기물을 랭크에 넣으면 규칙 엔진·AI·회귀 테스트가 둘이 된다.

## 내 안

### M1 대전 — 서버 없이 시작, 계정은 선택
- 현재 코드: `/api/rooms/*` 를 치지만 `CLOUD_MP_API_BASE = ''`(`:3824`), 서버 디렉터리 없음 → `mpApiRequest` 가 `null` 을 돌려주고 `localStorage` + `BroadcastChannel` 폴백(`:3831~3866`)으로 **같은 브라우저 탭끼리만** 된다. 로비는 HUD 에서 빠졌다(`test/applet.test.mjs:38-39` 가 `btn-lobby`·`lobby-modal` 금지).
- 1단계(Phase 5 전반): **초대 링크 + WebRTC P2P**(시그널링만 무료 서비스) 또는 **Supabase Realtime 채널**. study-game 에 `@supabase/supabase-js` 2.117 + capgo social-login 이 이미 붙어 있고(`D:\study-game\package.json:52-53`) 법무 페이지(`legal/privacy.html`·`account-deletion.html`)와 Play Data safety 답안이 있다 → **Supabase 재사용이 가장 싸다.** 익명 세션(`signInAnonymously`)으로 시작해 등급을 남기고 싶을 때만 구글·카카오 연결.
- 매칭: 초기 인구가 적으니 자동 매칭은 넣지 않는다. 초대 링크 → 방 코드 → (인구 후) 랭크 매칭.
- 치트: P2P 는 양쪽이 각자 chess.js 로 검증, 결과 보고는 **양쪽 서명 PGN** 을 서버에 올림. 불일치면 무효.

### M2 등급 — 체스 레이팅과 "왕관 등급"을 분리
- **레이팅**: Glicko-2 (lichess 방식, 공개 알고리즘). 랭크 대전에서만 움직인다. 숫자는 숨기고 **등급 뱃지**(새끼→성체→우두머리→왕관 … 동물 테마 5~7단)로 보여준다.
- **레벨(XP)**: 판 수·AI 난이도·일일 과제로 오른다. 지지 않는 보상(참여). 레벨은 **코인 지급과 상점 해금**에만 쓰고 매칭엔 안 쓴다.
- 둘을 섞지 않는 이유: FIFA 식 "많이 하면 강해진다"는 체스에서 성립 안 한다. 많이 하면 **멋있어진다**로 바꾼다.

### M3 코인·상점 — 외형 등급(C/B/A/S), 능력 없음
- 코인 획득: 판 완료(승 > 무 > 패, AI 난이도 가중) · 일일/주간 과제 · 레벨업 · 체크메이트 연출 종류(예: 나이트 메이트 보너스).
- 상점 품목: **기물 스킨**(등급 C/B/A/S = 모델 디테일·이펙트·포효·입장 연출의 차이. §4.3 매니페스트에 `tier` + `vfx` 세트가 등급별로 다름) · **착용 아이템**(왕관·갑옷·목걸이 — 리그의 `Head`·`Spine` 본에 소켓 부착; 매니페스트 `sockets`) · **바이옴·보드** · **감정표현**.
- **확률형(가챠) 없음.** 전부 가격표. 이유: 한국 게임산업법 2024-03-22 확률 표시 의무 + Play 가상화폐 정책 + 어린이 사용자. (grok 이 확인할 것.)
- 실돈: 처음엔 **코인만**(무료). 수익은 §12 app-launch 경로(광고·Play 유료 팩)로 나중에. 코인 실돈 구매를 열면 "자율 심의·결제 고지" 가 따라온다.

### M4 능력 기물 = "야생 모드" (랭크 밖)
- 예: A급 비숍 "사자 눈을 가진 기린" = 한 판에 한 번 1칸 더. 이건 규칙 변경 → **별도 규칙 플러그인**(chess.js 못 씀 → 기존 휴리스틱 엔진 또는 자체 변형 규칙). Phase 6 이후. 출시 범위 밖.

### M5 데이터·법무
- 계정 없이도 코인·스킨은 `localStorage`(기기 귀속). 계정 연결 시 Supabase 로 이관. 되돌릴 수 없는 손실(기기 바꾸면 사라짐)을 첫 화면에 고지.
- 어린이: 채팅 없음(정해진 감정표현만), 닉네임 필터, 친구 = 초대 링크로만.

## 틀릴 수 있는 곳 셋
1. Supabase 무료 티어 Realtime 동시 연결·메시지 한도가 대전에 충분한지 — 재 보지 않았다.
2. WebRTC P2P 가 모바일(Play TWA)에서 NAT 뚫림 비율 — 재 보지 않았다. TURN 없으면 실패하는 경우가 있다.
3. "가챠 없음"이 수익에 치명적인지 — 모른다. 다만 어린이·체스 사용자층엔 맞다고 본다.

## 하지 않을 것
자동 매칭(초기) · 가챠 · 능력 기물의 랭크 진입 · 채팅.

## 가장 약한 결정
M2 의 "레이팅 숫자 숨김". 체스 사용자는 숫자를 원할 수 있다. 토글로 둘 수 있다.
