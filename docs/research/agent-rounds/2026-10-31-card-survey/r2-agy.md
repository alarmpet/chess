8세 어린이와 체스 초보자의 관점에서 '왕관 카드 설계 초안 v2'를 검토한 결과입니다.

---

### 1. 그대로 둘 것 3개

1. **말을 잡을 때 즉시 카드를 주는 드롭 방식 (잡기 대기 약 4.2초 활용)**
   - **이유:** "말을 잡으면 카드가 나온다"는 인과관계가 매우 단순하고 직관적입니다. 8세 아이에게 별도의 텍스트 설명 없이도 행동(잡기)과 보상(카드 획득)이 즉각 연결되어 체스 말 잡는 재미를 극대화합니다.
2. **카드가 체스의 합법 수와 승패 판정을 바꾸지 않는 원칙**
   - **이유:** 초보자와 어린이는 체스 말의 기본 행마를 익히는 것만으로도 두뇌를 많이 씁니다. 카드 효과가 체스 룰(이동 규칙, 체크 판정)을 왜곡하면 체스 학습이 무너집니다(Gambonanza, Passant 사례의 '강화가 체스를 덮는 문제' 방지).
3. **대국 후 100% 성공하는 3장 합성 시스템**
   - **이유:** '3장이 모이면 합쳐서 다음 등급'은 직관적이며 실패 확률이 없어 자원 상실에 취약한 어린이에게 박탈감을 주지 않습니다. 판 도중이 아닌 대국 후 버튼으로 진행하는 점도 체스 집중을 방해하지 않습니다.

### 2. 바꿀 것 4개

#### (1) 대국 시작 전 미션 3장 중 1장 선택
- **무엇을:** 판 시작 시 3장의 미션 중 1장을 고르고 건너뛰는 절차.
- **어떻게:** 처음 5판에는 선택 화면을 완전히 숨기고, 튜토리얼 성격의 단일 목표(예: "폰 1개 잡기")를 자동 부여하거나 아예 미션 UI를 비활성화합니다.
- **왜:** 체스판에 말이 어떻게 깔려 있는지도 낯선 8세 초보가 게임 시작 전 3개의 텍스트 카드를 읽고 유불리를 따져 선택하는 것은 큰 인지 피로를 줍니다.
- **틀릴 조건:** 8세 아동이 글을 읽지 않고 카드를 탭하는 행위 자체를 재미있는 미니게임이나 의식으로 즐긴다는 사용자 테스트 결과가 나올 경우.

#### (2) 대국 중 6종 동물 손패 액티브 스킬 동시 제공
- **무엇을:** 대국 중 최근 3장 손패를 유지하며 6종 동물 고유 능력(정찰, 도토리, 낮잠, 응원, 추천 수, 무르기)을 쓰는 방식.
- **어떻게:** 처음 5판에서는 손패 사용 기능을 숨기고 '카드 수집'에만 집중시킵니다. 이후 해금하더라도 초보에게 필수적인 직관적 보조(사자의 '무르기', 호랑이의 '추천 수') 1~2종만 먼저 열어줍니다.
- **왜:** '도토리 2배', '실수 굴림 1회 더', '이번 판 카드 등급 보정' 등은 확률과 경제 개념을 이해하지 못하는 8세에게는 난해합니다. 초보자는 내 말을 어디로 둘지 고민하느라 손패를 쳐다볼 여유가 없습니다(Chess Chaos의 '수 뒤 선택이 덜 신남' 지적과 일치).
- **틀릴 조건:** 아이들이 체스 수싸움보다 동물 스킬 버튼을 마구 누르며 화면 반응을 보는 것을 게임의 핵심 재미로 소비할 경우.

#### (3) 수치 기반의 확률표 및 천장(10장/60장) 카운트 노출
- **무엇을:** 폰 90/9/0.9/0.1 등의 확률 및 10장·60장 천장 수치.
- **어떻게:** 숫자를 UI 전면에 드러내지 말고, 8세가 직관적으로 알 수 있는 시각 게이지(보석이 채워지거나 상자가 반짝이는 연출)로 대체합니다.
- **왜:** 소수점 확률과 60장 천장 산술은 초등 저학년에게 의미 없는 텍스트 공해이며 시스템을 복잡해 보이게 만듭니다.
- **틀릴 조건:** 8세 단독 플레이가 아니라 체스를 가르치는 보호자가 함께 화면을 보며 확률과 천장 숫자를 전략적으로 계산해 주는 사용 패턴이 주를 이룰 경우.

#### (4) 희귀 5장으로 영웅 합성 시 '빈 영웅 칸이 있을 때만' 조건
- **무엇을:** 일반/고급 합성은 3장인데 영웅 합성만 5장이며, 비어 있는 영웅 칸이 있어야만 동작하는 예외 규칙.
- **어떻게:** 대국 후 합성 화면에서 조건이 안 맞으면 아예 버튼이 비활성화되거나 안내 문구가 나오는 대신, 8세 눈높이에 맞춰 "더 큰 영웅을 부르려면 도감 자리가 필요해요" 식의 명확한 시각적 알림을 주거나, 초기에는 영웅은 드롭/천장으로만 얻도록 단순화합니다.
- **왜:** 이전까지 "3장 모이면 합체"로 배웠던 아이가 5장을 모았는데 합성이 되지 않으면 게임이 멈추거나 버그가 났다고 여깁니다.
- **틀릴 조건:** 영웅 합성 제한을 풀었을 때 24칸 도감이 너무 빨리 완성되어(시뮬레이션 29판 완성) 장기 수집 동기가 조기에 소진되는 문제가 더 치명적일 경우.

### 3. 빠진 것 3개

1. **처음 5판 단계적 온보딩(기능 순차 노출)**
   - 1판: 말 잡기 + 카드 드롭(수집의 기쁨).
   - 2~3판: 대국 후 3장 모아서 합성하기(성장의 기쁨).
   - 4~5판: 무르기/힌트 등 단순 손패 1종 사용.
   - 현재 초안은 1판부터 미션, 손패 6종, 합성, 천장 규칙이 한꺼번에 쏟아져 초기 진입 장벽이 높습니다.
2. **잡은 말과 카드의 1:1 시각적 매핑 연출**
   - 8세는 글자(폰, 나이트)보다 시각적 형태로 사물을 인식합니다. 체스판의 3D 말이 잡혀 쓰러질 때 해당 동물의 카드로 변환되어 화면 하단으로 날아가는 시각적 연출이 명시되어야 규칙 설명 없이도 시스템을 납득합니다.
3. **대국 패배/체크메이트 당했을 때의 위로 보상 설계**
   - 초보자와 어린이는 AI에게 자주 집니다. 초안에는 "잡으면 카드", "체크메이트 시 카드"만 정의되어 있어, 말을 거의 못 잡고 완패했을 때 얻는 카드가 없어 좌절할 위험이 있습니다. 판당 최소 1장의 참가/위로 드롭 기준이 누락되어 있습니다.

### 4. 첫 시제품에 꼭 넣을 것과 뺄 것

- **꼭 넣을 것 (Core Loop):**
  1. 체스 말 잡기 시 즉시 카드 획득 연출 (4.2초 잡기 딜레이 활용).
  2. 동물 6종 × 등급 4종 = 24칸 도감 화면 (미보유 칸 실루엣 노출로 수집욕 유도).
  3. 첫 판 희귀 1장 보장 및 중복 방지 규칙 (초기 성취감 제공).
  4. 대국 종료 후 단일 탭으로 동작하는 '3장 예비 → 다음 등급 100% 합성' 버튼.

- **첫 시제품에서 뺄 것 (Cut for MVP):**
  1. **판 시작 전 미션 3장 선택 시스템:** 게임 흐름을 끊고 읽기를 강요하므로 제외.
  2. **대국 중 손패 6종 동물 액티브 스킬:** 체스 본연의 집중을 흐리고 초보에게 과부하를 주므로 1차 시제품에서는 제외(카드는 순수 수집품으로만 동작).
  3. **별가루 및 마을 장식 시스템:** 24칸 도감이 차기 전까지는 쓸모없는 시스템이므로 초기 검증 범위에서 완전히 제외.
  4. **희귀 5장 영웅 특수 합성:** 예외 룰로 인한 혼란을 방지하기 위해 시제품에서는 영웅을 드롭/천장으로만 획득하도록 제한.
