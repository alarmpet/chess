# 사람 시험 A 를 세 모델이 대신한 라운드 (2026-11-04)

사용자 지시: 참가자 섭외가 안 되니 LLM 협업으로 「사람 시험 A」(재미 계획서 §7 · 섬 경제 §8 · 욕망 §10 · 정원 §7 이 공유하는 관문)를 진행한다.
**이 라운드는 사람 시험을 대체하지 못한다.** 세 모델은 화면·소리를 받지 못했고 글자 덤프와 수치만 받았다. 그래서 「귀여움·소리·동물 그림으로 역할이 읽히나」는 판정하지 않았다. 결함을 찾는 라운드다.

## 방법

- 실제 게임을 실제 브라우저(ego-browser)에서 돌렸다. 개발 서버 `localhost:3000`(이 저장소, 커밋 `361861f`).
- 세 모델이 서로 다른 역할로 매 수를 직접 골랐다(JSON 한 줄). 판마다 앞 8수는 모델, 그 뒤는 하네스의 자동 수(잡기 우선 휴리스틱)로 끝까지. 끝까지 가야 판 끝 개봉·섬·도감이 열리기 때문이다.
- 하네스 `round-01.mjs` 가 시험 A 가 보는 화면의 **보이는 글자**(조상 어느 것도 display:none·opacity 0·visibility hidden 이 아니고 뷰포트 안인 텍스트 노드)만 덤프했다: 첫 화면 · 판 끝 0.5초/4초 · 결과 카드 닫기 · 섬(세 줄 고리 버튼) · 매대 · 표식 · 도감 · 도감 빈 칸(얻는 길) · 외형 단계 · 라이벌 입장식(0.8/2.3/3.8초) · 3판 5수 뒤 「새 판 시작」 확인창 · 3판 6수 뒤 새로고침(이어 하기).
- 모델은 자기 기록만 받아 독립 평가했다(`BRIEF-*.md` → `r1-*.md`). 통합자 판정은 답을 읽기 전에 썼다(`r1-claude.md`).
- 브리핑은 명령줄 인수 길이 제한(약 32KB) 때문에 상단 공통 글자를 빼고 덤프를 900자에서 잘랐다. 자른 곳은 브리핑 안에 적혀 있다(`make_briefs.py`).

## 사고 (통합자 하네스 오류 — 결과 해석에 영향)

1. **codex 모델 400.** `~/.codex/config.toml` 의 `gpt-6.1-sol` 이 ChatGPT 계정에서 거부돼 첫 실행의 codex 22수가 전부 하네스 대체 수였다. `-c model=gpt-6-sol` 로 재실행. 교훈은 스킬에 이미 있다(라운드 전에 config 모델 확인) — 지키지 않았다.
2. **ego-browser 는 환경변수를 넘기지 않는다.** `PLAYERS=codex` 가 무시돼 세 역할이 처음부터 다시 돌며 agy·grok 로그를 덮었다. 기본값을 코드에 적어 해결.
3. **CLI 를 죽여도 브라우저 안 스크립트는 산다.** 잘못 시작된 실행을 `ego-browser.exe` 종료로 멈춘 줄 알았으나 같은 TaskSpace 에서 계속 돌아, 09:55~10:09 동안 codex 재실행과 **같은 페이지를 두 스크립트가 조작**했다. 그 구간 로그는 전부 `logs-contaminated-0955-1009/` 로 치우고 agy·codex 를 혼자 다시 돌렸다. grok 의 브리핑은 오염 전(09:42)에 만든 것이라 유효.
4. **이어 하기 알림을 못 봤다.** 「지난 판을 이어서 둡니다」 토스트는 6초(`CardLayer.tsx:140`)인데 하네스는 로딩 뒤 9초를 기다리고 덤프했다. 두 모델이 「안내가 없다」고 한 것은 **측정 시점 오류**다. 새로고침 뒤 보인 「1」「2」는 오른쪽 아래 카드 주머니 배지(`agy-3-resumed.png`)다.
5. **섬 화면 덤프에 판 화면 글자가 섞였다.** 섬은 전체 화면 오버레이인데 덤프 함수는 가려진 뒤쪽 요소도 「보인다」고 판정해 「체크메이트 — 흑 승리 / 이번 판 주머니 …」가 섬 덤프에 함께 들어갔다. 스크린샷(`agy-1-island.png`(저장소 밖 `C:/Users/petbl/ego/chess-test-a-20261104/shots/`))으로 확인하니 섬 화면은 깨끗하다. 10-31 의 「숨은 패널 글자」 교훈이 다른 모양으로 반복됐다. 모델들이 이것을 결함으로 내지는 않았다.
