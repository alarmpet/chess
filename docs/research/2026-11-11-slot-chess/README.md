# 슬롯 체스 · 공방 경제 조사 기록

조사일: 2026-11-11, 한국 시간. 대상: WILD CROWN. 계획서: [왕관 계약전과 살아 있는 공방](../../plans/2026-11-11-slot-chess-village-plan.md).

## 1. 범위와 증거의 강도

- 사용자가 준 YouTube Shorts의 영상 파일, 한국어 자동 자막, 전 구간 3초 간격 표본 **24장**을 확보하고 화면을 읽었다. 오디오를 별도로 사람처럼 청취해 받아쓴 기록은 아니다.
- `watch`의 자동 추출은 8개 장면 파일을 남겼다. 전 구간을 균일하게 확인하기 위해 `inspect_video.py`로 24장 표본과 연락 시트를 추가 생성했다. 시간 표시는 약 ±1.5초의 표본 위치다.
- `ego-browser`의 하나의 작업 공간(77)에서 사이트 첫 화면, 관련 설명 **8개**, 실행 예제 **4개**를 조사했다. 사이트의 모든 예제를 전수 시험한 것은 아니다. 브라우저 작업은 종료했다.
- 관련 설명: procedural-quest, smart-object, win-chance, game-juice, utility-ai, fire-spread, turn-order, wayfinding. 조작한 예제: 앞의 네 개.
- 저장소의 실제 규칙·마을·미션·AI·통신 코드를 읽었다. 기존 계획서에 적힌 구현 여부보다 현재 코드를 우선했다.
- 새 방식의 재미·유지율·경제 균형은 사람에게 검증하지 않았다. 봇 분석도 새 목표를 이해하지 않는 기존 AI의 기보에 조기 종료 조건을 대입한 **후향 분석**이다.

## 4. 실제 체스 변형의 대조

- [Lichess Three-check](https://lichess.org/variant/threeCheck): 합법적인 체크 3회를 추가 승리 조건으로 사용하고 체크메이트도 인정한다. 이중 체크는 1회다.
- [Lichess King of the Hill](https://lichess.org/variant/kingOfTheHill): 합법적으로 킹이 중앙 네 칸에 도달하면 승리하며 체크메이트도 인정한다.
- 여기서 확인한 것은 **행마를 보존하고 승리 조건을 추가할 수 있다는 선례**다. 이번 슬롯 목표·마을 연결·경제가 성공한다는 증거는 아니다. 킹을 실제 잡도록 바꾸는 규칙과도 다르다.

## 6. 재현 가능한 분석

`node docs/research/2026-11-11-slot-chess/mission-audit.mjs`

쉬움60판·보통60판, 각 판 같은 시작 국면, 고정 난수, 최대160반수. 폰·나이트·룩 / 비숍·퀸·폰 / 폰·나이트·비숍에서 각각 3종 전부와 2종 먼저 포획을 같은 기보에 대입한다. 실제 계약을 겨냥하는 전략, 회피, 인간 생각 시간은 측정하지 않는다. 원시 결과와 요약은 `mission-audit.json`에 남긴다. 160반수 미종료는 완료한 대국과 구분한다.

실행 완료: 쉬움60·보통60, 총120기보. 기보 길이 중앙102·130반수, 160반수에서 잘린 판10·13. `pnr_3` 목표 달성46·57판, 달성판 중앙51·54반수. `pnr_2`는 각각60판 달성·중앙16·20반수, 백 선달성34·35판. `pnb_3`은58·58판 달성·중앙27·29반수로 원안의 경량 조합도 남길 가치가 있다.

이 결과를 보고 추천 초안의 무보정2개 방식에 ‘너무 빠름/쉬운 목표 편중’ 위험을 명시했다. 후속 후보 `폰×2·나이트×1·비숍×1 중2`는 아직 측정하지 않았다. 보통 난이도 `pnr_3`의 백 선달성41/57 등 편향이 커서 단순 도입을 권하지 않는다. 작은 표본·기존 AI의 수 선택에 따른 결과이며, 신규 규칙의 승률 추정이나 신규 AI의 실력 비교가 아니다.

경제 시작값은 계획서의 산술 예제이며 관측 데이터가 아니다. 사람 시험 전에는 ‘노가다 해결’, ‘3분 보장’, ‘공정성 검증 완료’라고 표현하지 않는다.

## 7. 설계 검토

brainstorming 스킬의 구현자 검토1회에서 두 가지 빈틈을 확인해 계획서에 반영했다.

1. 부품이 완주 직접 보상인지 실제 생산인지 모호함 → 공방 일꾼 배치 + 작업1일 + 곡물1 → 부품2로 명시. 초기 곡물3을 지급하고, 구매/밭 생산으로 보급 경로 제공.
2. 48번째 수의 무승부와 점수 판정 우선순위 → 메이트·계약 승리 이후 표준 무승부 사유가 차례 상한 판정보다 우선하도록 명시.

리뷰는 설계의 누락 확인이며 사람 재미 시험이나 독립적인 경제 검증을 대신하지 않는다.
