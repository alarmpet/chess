# Lumen · Ironvale 뜯어보기 (2026-11-19)

사용자: 「이런 그래픽은 깃허브 오픈소스 (Reverse Engineer Anything)로 역공학설계 해서 우리가 참조하고 구현해볼만하지 않아? voca-rider 프로젝트에서 좀전에 설치했는데 확인해보고 같이 공유해서 사용해봐」

## 도구 상태

- **REA**(`rea-agents` 6.7.0, MIT, `D:\tools\rea`)는 전역 MCP 설정(`~/.claude.json` 의 `rea`)과 사용자 스킬(`~/.claude/skills/reverse-engineer-anything`)로 들어 있다. 전역이라 이 프로젝트에도 이미 공유돼 있다 — 따로 설치할 것이 없다.
- 이 세션을 시작할 때 MCP 연결이 30초 제한에 걸려 실패했다. `rea mcp doctor` 는 정상(도구 207개, 3초)이다. 세션을 다시 열면 붙을 것으로 본다(재 보지 않았다).
- CLI 로는 바로 된다. Git Bash 에서는 표준 입력을 닫아야 한다(`< /dev/null`) — 안 닫으면 70초를 기다린다.
- 이번 두 대상은 REA 가 필요 없었다. 둘 다 **소스가 그대로 공개된 한 파일짜리 HTML**이고, 만든 사람이 프롬프트와 기법 목록까지 적어 두었다. 받아서 읽는 것으로 충분했다. REA 는 소스가 없거나 묶여서 읽기 어려운 대상(번들된 사이트 · 앱)에 쓴다.

## Lumen — WebGL 이 아니다

- 83KB 한 파일. 캔버스도 WebGL 도 없다. **SVG 를 자바스크립트로 그린 아이소메트릭 마을**이다(`P=(x,y,z)` 투영 한 줄, 24×24 격자, 30°).
- 건물은 한 색의 세 톤(윗면 가장 밝게 · 왼쪽 중간 · 오른쪽 가장 어둡게)과 가는 남색 외곽선뿐. 그라데이션·광택 없음.
- **낮밤**: 판 전체에 곱하기(multiply) 덧칠 한 장을 크림 → 흰색 → 노을 분홍 → 라벤더로 바꾸고, 켜진 창·가로등·전기 흐름은 **그 덧칠 위에** 그려 노란색만 빛나게 한다. 밤이 검정이 아니라 옅은 라벤더다.
- **전기 흐름**: 전선마다 `stroke-dashoffset` 하나로 노란 점선이 흐른다. 속도와 밀도가 전력량이고, 방향이 바뀌면 0 을 지나 부드럽게 뒤집힌다.
- **입장**: 빈 판 → 구역별로 건물이 25ms 간격으로 통통 튀어 오르고 → 전선이 스스로 이어지고 → 점선이 흐르기 시작. 첫 3초.
- 원본 프롬프트(9.9KB)가 색 여섯 개의 값, 「글로는 노란 창 말고 빛나지 않는다」, 「시그니처 순간」까지 정해 준다. 「VISUAL TECHNIQUES」 목록도 같이 공개돼 있다.

## Ironvale — 후처리 한 번이 그 느낌이다

- three.js r128, 소스 17개 파일(약 46만 자)을 한 파일로 묶음. 모델 데이터 11MB 는 따로 받는다.
- 그 「게임 같은」 화면의 대부분은 `16_post.js`(7.7KB) **후처리 한 번**에서 온다. 장면을 깊이와 함께 텍스처에 그린 뒤 화면 한 장짜리 셰이더로:
  1. **구석 그늘**(깊이 기반 앰비언트 오클루전): 마주 보는 표본 네 쌍. 평평한 땅은 상쇄되고 접힌 곳만 어두워진다.
  2. **공기 원근**: 멀수록 하늘색으로 섞는다(최대 42%).
  3. **블룸**: 황금각 12표본으로 밝은 곳 주변을 번지게. 밤에 더 세게.
  4. **색 보정**: 채도 · 약한 S곡선 · 튀는 초록 누르기 · 밝은 곳 따뜻하게/어두운 곳 차갑게 · 검정 살짝 띄우기 · 필름 입자.
  5. **비네트**, 맞았을 때 가장자리 붉은 번쩍.
  6. 둘째 패스로 **FXAA**(계단 현상 제거).
- 품질 「낮음」이거나 깊이 텍스처가 없으면 통째로 꺼지고 그냥 그린다. 실패하면 스스로 끈다.
- `14_atmos.js`: 낮밤 순환, 날씨(비·폭풍·눈·안개), 별, 밤의 불빛, 바람.
- 나무·바위는 인스턴스(`InstancedMesh` 11곳), 질감은 캔버스로 그린 절차 텍스처.

## 우리 게임에 옮길 것

| 무엇 | 어디서 | 우리 쪽 |
| :--- | :--- | :--- |
| **후처리 한 장**(구석 그늘 · 공기 원근 · 블룸 · 색 보정 · 비네트 + FXAA) | Ironvale | 지금 후처리가 아예 없다. 패스 2개 = 드로우콜 +2. 「낮음」에서 끈다. 내장 그래픽에서 GPU ms 를 먼저 재야 한다 |
| **판 전체 덧칠로 낮밤**, 빛나는 것만 그 위에 | Lumen | WG-4(판의 시간)를 조명을 다 바꾸지 않고 싸게 하는 길. 밤은 검정이 아니라 옅은 라벤더 |
| **통통 튀어 오르는 입장** | Lumen | 판을 열 때 말이 줄줄이 튀어 오른다. 슬롯머신이 내려오기 전 1초 |
| **흐르는 점선** | Lumen | 내 말에서 표적 말로 가는 길(금빛 결정타)을 흐르는 점선으로 |
| **색을 숫자로 정한 프롬프트** | Lumen | 다음 그래픽 작업의 지시문에 색 값 · 「빛나는 것은 무엇뿐」 · 시그니처 순간을 적는다 |

옮기지 않는 것: Ironvale 의 사실 지향 질감과 모델(우리는 장난감 세계), Lumen 의 SVG 렌더링 자체(우리는 3D).

## 재지 않은 것

- 두 작품을 직접 돌려 프레임 시간을 재지 않았다. Ironvale 공개 스크린샷 한 장에 「16 fps」가 찍혀 있다(어떤 기기인지 모른다).
- 후처리 한 장이 이 PC 의 내장 그래픽에서 몇 ms 인지 모른다. 표본이 4쌍 + 12개라 가볍지 않을 수 있다.
