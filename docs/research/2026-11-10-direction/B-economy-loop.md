## 0. 지금 구현된 고리 (`src/village/economy.js`, 565줄)

1. 판이 끝나면 도토리 승 30 · 무 20 · 패 15 (`:7`, `:271-273`). 지면 빼앗지 않는다(`:263`).
2. 도토리 → **기능 건물 8종**(20~240, 합계 750). 종류당 1채, 한 번에 하나만 짓고, 지은 건물은 **다음 판이 끝나야** 열린다(`:22`, `:25-34`, `:290`, `:299-307`).
3. 건물은 카드 주민이 들어가야 일한다(`:196`). 주민은 자기 체스 행마 모양으로 닿는 건물에 +1/+2, 상한 3(`:52-79`) — **인접 보너스는 이미 있다**(주민 기준).
4. 생산은 **판 끝에 한 번** 자동으로 돈다: 밭 곡물(창고 20) → 빵집 빵(10) → 장터가 곡물 2·빵 8 도토리에 판매, 쉼터·온천은 하트(`:194-227`).
5. 실제 시간으로 움직이는 것은 둘뿐: 라이벌 방문 4시간마다 도토리 10(`:11-12`, `:550-565`, `src/VillageView.tsx:77`), 하루 첫 판의 이슬 곡물 +1(`:20`, `:383-386`). **오프라인 누적 생산·상한·「모아 받기」는 없다.**
6. 꾸미기 소품 8종(15~120 도토리, 매대 3칸)을 사서 놓는다(`:428-443`, `:503-525`). **소품은 생산·영향권·점수 어디에도 들어가지 않는다** — `harvest`(`:194-227`)와 `influenceBonus`(`:72-79`)는 `v.built` 만 읽고 `v.decor` 를 읽지 않는다. `marks.js`·`certificate.js`·`roster.js`·`zones.js`·`store.ts` 에도 `decor`/`stash` 참조가 없다(grep 0건).
7. 건물 8채 완성 → 새 섬. 주민·하트·도토리·산 소품은 넘어가고 땅·건물은 처음부터(`:350-369`). 영구 배수는 없다.
8. 하트 → 말 외형 4단계(0/10/30/60, `:10`), 쓰다듬기 하루 10회(`:8`, `:537-547`).

### 사용자가 원하는 것과의 차이

| 사용자 요청 | 지금 | 빠진 것 |
| :-- | :-- | :-- |
| 꾸민 것이 다시 생산한다 | 생산은 기능 건물 8채만. 소품은 도토리가 빠지는 구멍일 뿐 | 소품 → 생산/손님/점수로 가는 선이 **0개** |
| 경제가 순환한다 | 도토리 → 건물 → 곡물·빵 → 도토리는 돈다. 그러나 건물 8채(750)에서 끝나고 레벨은 의뢰로만 3까지(`:18`, `:257`) | 끝나지 않는 쓸 곳(지수 비용), 새 섬의 영구 보상 |
| 방치형 느낌 | 「체스가 시계」(`:22`)라 실시간 생산이 없다. 섬 경제 계획 §7 이 실시간 타이머를 금지했다 | 돌아왔을 때 쌓인 것을 **한 번에 받는 순간**. 수확은 자동이라 손으로 거두는 탭이 없다 |
| 자랑·경쟁심 | 영주 증명서 사진, 깃발, 표식(욕망 계획 D5·D6) | 「내 섬이 얼마나 꾸며졌나」를 나타내는 **수 하나**(꾸밈 점수)와 그것을 친구에게 보이는 자리 |
| 남녀노소 직관 | 재화가 도토리·곡물·빵·하트 4종 + 카드 | 「놓으면 무엇이 생기는지」를 한 번에 보여 주는 규칙 |

**먼저 볼 구멍 하나**: 섬 경제 계획 §5 가 「판 끝 손님으로 바꾼다」고 정한 라이벌 방문 도토리(4시간마다 10)가 코드에는 그대로 있다(`:550-565`). 체스를 두지 않고도 도토리가 들어오는 유일한 길이다. 라이벌이 몇 명 해당하는지는 세지 않았다.

**결정과 부딪히는 곳**: 「방치형」을 실시간 누적으로 읽으면 섬 경제 계획 §7(실시간 타이머 없음)·욕망 계획 §8 과 충돌한다. §9 (나)에 충돌을 피하는 형태(판이 연료, 상한, 썩지 않음)를 적었다. 최종 선택은 사용자 몫이다.

## 2. 설계 글·강연의 원리

**Anthony Pecorella(Kongregate), 「The Math of Idle Games」** [talk/글, 열어 봄]
- 1부(Game Developer 게재 2016-10-13): 방치형의 기본 꼴은 **비용은 지수로, 생산은 선형·다항식으로** 자라게 하는 것. 지수는 결국 다항식을 따라잡아 넘으므로 어느 순간 다음 구매가 멀어진다 — 그 벽을 어디에 세울지가 밸런스다. 다음 값 = 기본값 × 성장률^(보유 수). 예시 성장률은 AdVenture Capitalist 레모네이드 가판 1.07. 환생(prestige)은 생성기·배수 대부분을 리셋하는 「New Game+」 같은 것이고, 환생할 때마다 비용 곡선을 더 멀리까지 가게 된다. 오프라인 수익은 1부에 없다. https://www.gamedeveloper.com/design/the-math-of-idle-games-part-i
- 3부(2017-02-01): 환생 재화는 「누적 수익 기준」과 「리셋 뒤 수익 기준」 두 갈래이고 밸런스가 다르다. 환생 공식은 대개 로그가 아니라 분수 지수(제곱근·세제곱근). **Egg, Inc. 는 오프라인을 2시간으로 묶고**, Clicker Heroes 는 묶지 않는다. 오프라인이 묶인 게임은 환생 구조로 진행을 당겨 준다. https://www.gamedeveloper.com/design/the-math-of-idle-games-part-iii
- 2부: URL 은 열렸으나 본문이 나오지 않았다 [열지 못함].
- GDC 2015 강연 보도(Simon Parkin, Game Developer 2015-03-03) [talk 보도, 열어 봄]: 계속 붙어 있지 않아도 늘 오르는 숫자와 피드백이 있어서 남는다. 대부분의 방치형은 자리를 비워도 진행한다. 잠깐 들러 한 번 손대면 성장 곡선을 한 칸 올릴 수 있다. 돌아올 때마다 축하의 순간이 생긴다. Kongregate 최근 한 달 최다 플레이 10개 중 3개가 방치형. 보존율 수치는 기사에 없다. 이 문서의 유일한 문장 인용:
  > "the longer you're away from the game, the greater your incentive to return" — https://www.gamedeveloper.com/design/the-rise-of-games-you-mostly-don-t-play (2015-03-03) [talk 보도]

- 「Value chains」(2021-12-12, faucet-and-drain 경제의 설계·밸런스 방법) [열어 봄]: ① 사슬의 끝에는 항상 **동기 닻(motivational anchor)** — 플레이어가 실제로 원하는 것 — 이 있어야 한다. ② 넘치게 가진 자원은 한 개 더 얻는 값이 0 에 가까워지고, 그러면 그 자원을 만드는 앞 단계 전체가 당겨지지 않는다. ③ 빠지는 곳(sink)을 들어오는 곳(source)보다 **조금 크게**. ④ 마디마다 sink 를 하나 더 달 수 있다. ⑤ 입력 자원을 하나로 몰면 콘텐츠 큰 덩어리가 무의미해질 수 있어, 복잡한 경제는 구별되는 입력 여러 개가 더 튼튼하다. https://lostgarden.com/2021/12/12/value-chains/

## 3. 「꾸미기가 곧 생산」 사례

| 구조 | 사례 | 놓은 것이 만드는 것 | 위치가 의미 있나 |
| :-- | :-- | :-- | :-- |
| 물건 → 손님 → 선물 | Neko Atsume | 물건 종류·수가 오는 고양이를 정하고, 고양이가 물고기를 남긴다. 물건을 치우면 그때까지 논 만큼 물고기를 남기고 떠난다 | 약하게. 큰 물건은 정해진 칸에만 |
| 좋아하는 가구 → 초대 → 친밀도 | 포켓 캠프 | 특정 가구가 있어야 그 동물을 부른다 → 친밀도 → 플레이어 레벨 → 보상 | 없음(가진 것으로 판정) |
| 장식 점수 → 진행 관문 | 쿠키런: 킹덤 | Decor Point 가 성 승급 조건. 그 밖에는 「다른 플레이어 사이에서의 위치」를 나타내는 수 | 없음 |
| 큰 장식 = 영구 버프 | 쿠키런: 킹덤 랜드마크 | 생산 시간 10% 같은 버프, 높은 장식 점수, 승급 가능 | 없음 |
| 쉼 시설 → 다른 재화 | 고양이와 스프 | 요리 시설은 골드, 쉼 시설은 레시피 점수 | 없음 |
| 테마 완성 → 보상 | 쿠키런: 킹덤 / 동숲 HHA | 한 테마 장식을 처음 다 모으면 크리스탈 / 한 시리즈 11점이면 큰 점수 | HHA 는 **위치도 채점** |
| 배치 자체가 점수 | Islanders | 건물을 놓을 때 「점수 구」 안의 다른 건물에 따라 얻는 점수·잃는 점수가 미리 보인다. 점수가 다음 건물 묶음과 다음 섬을 연다 | **핵심** |
| 맞닿는 변 | Dorfromantik | 놓는 타일의 변이 이웃과 맞는 만큼 점수, 타일 퀘스트(예: 철길 n칸 이상) | **핵심** |
| 순수 장식(반례) | Hay Day | 기능 없음. 장식을 살수록 값이 오른다 | 없음 |

출처: §1 의 위키들 + https://en.wikipedia.org/wiki/Islanders_(video_game) · https://en.wikipedia.org/wiki/Dorfromantik [community, 열어 봄]. Islanders 개발진은 작은 팀의 한계 때문에 **단순함을 택했고**, 절차 생성 섬으로 규칙을 단순하게 둔 채 반복 플레이의 다양함을 얻었다(위키백과 서술).

**우리 쪽 읽기**
- 위치가 의미 있는 규칙은 이미 있다: 주민 영향권(`influenceSquares`)과 그 미리보기. Islanders 의 「놓기 전에 얼마가 되는지 보인다」와 같은 문법이므로, 소품에 같은 미리보기를 붙이면 새 규칙을 가르치지 않아도 된다.
- 「물건 → 손님」은 섬 경제 계획 §3-4(바다 손님 앨범, 이미 만든 바다 생물 11종)과 바로 이어진다. 그 계획은 손님을 「부두를 지은 섬」에 붙였고 부두는 아틀란티스 PR B 에서 삭제됐다 — 손님을 **소품에** 붙이면 빈자리가 채워진다.
- 아틀란티스 계획 결정 5(구역에 맞게 지으면 보너스 → 안 준다)는 건물 얘기다. 소품의 인접 보너스는 그 결정과 겹치지 않지만 같은 정신(강제 없음)을 지켜야 한다: 보너스는 덤이고 없어도 손해가 없어야 한다.

## 7. (가) 「체스 → 도토리 → 꾸미기 → 생산 → 다시 체스」에 옮길 수 있는 장치

**권하는 최소 묶음**: 1 + 2 + 3. 「소품을 놓는다 → 판이 끝나면 손님이 와서 놓고 간다 → 한 번 눌러 받는다 → 꾸밈 점수가 올라 더 좋은 소품이 열린다」. 재화를 늘리지 않고, 실시간을 들이지 않고, 지금 결정 어느 것과도 부딪히지 않는다. 6번은 사용자가 「실시간 방치」를 분명히 원할 때만 얹는다.

## 8. (나) 방치 수익이 체스를 안 두게 만드는 위험, 그리고 체스를 「엔진」으로 두는 법

**위험이 생기는 꼴**
- 방치 수입이 판 수입과 같은 재화로, 상한 없이, 판과 무관하게 들어오면 가장 싼 전략은 「기다리기」가 된다. Pecorella 의 관찰 그대로다: 비운 시간이 길수록 돌아올 이유가 커진다 — 돌아와서 **체스를 둘** 이유가 아니라 **받을** 이유다.
- 지금 코드에도 작은 꼴이 있다: 라이벌 방문 4시간마다 도토리 10(`:550-565`). 판 수입이 15~30 이므로 라이벌 한 명이 하루에 여섯 번 들르면 두세 판 값이다(라이벌 수·실제 빈도는 재지 않았다).
- Lost Garden: 넘치는 자원은 앞 단계를 당기지 않는다. 방치로 도토리가 넘치면 「판을 끝내면 도토리」가 닻 역할을 잃는다.

**막은 사례**

| 사례 | 장치 | 확인 |
| :-- | :-- | :-- |
| Neko Atsume | 먹이가 떨어지면 손님이 안 온다 — 방치의 **연료를 능동 행동이** 채운다 | 위키 Food [열어 봄] |
| Egg, Inc. | 오프라인을 사일로 시간으로 묶는다(2017년 글 기준 2시간, 현재 위키 기준 사일로당 1시간·기본 2개·오프라인 절반 속도) | Pecorella 3부 · 위키 [열어 봄] |
| AFK Arena | 방치 상자의 양이 **캠페인 진행도**로 정해진다 — 능동 플레이가 방치 속도를 올린다 | 위키(Stub) [열어 봄] |
| Clash Royale | 상자는 슬롯이 비어 있어야 받는다. 받는 것은 전투, 여는 것은 시간 | 위키 [열어 봄] (슬롯 수·시간은 읽지 않음) |
| Cookie Clicker | 오프라인은 CpS 의 일부만, 일정 시간 뒤 90% 감소. 올리려면 환생 업그레이드 | 위키 [열어 봄] |
| Royal Match | 메타(꾸미기)가 단순하고 레벨이 중심 — 「꾸미기 재화는 레벨 클리어에서만」은 [원문 확인 못함] | DoF [열어 봄, 일부] |
| 지금 WILD CROWN | 건물은 다음 판이 끝나야 열리고, 수확은 판 끝에만 돈다 — **이미 가장 강한 형태** | `economy.js:22`, `:288-290` |

**체스가 엔진이 되는 조건 (6번 방치 통을 넣는다면 전부)**
1. **연료는 판으로만.** 끝낸 판 하나가 통을 N시간분 채운다. 판을 안 두면 통은 비고 멈춘다. 멈출 뿐 깎이지 않는다(섬 경제 §7 경계 문장 유지).
2. **속도는 체스가 정한다.** 고이는 속도 = 일하는 소품·건물 수 × 지난 판의 결과(끝까지 두기·의뢰 달성). 결제·광고·기다림으로는 못 올린다.
3. **상한은 짧게, 넘쳐도 잃지 않게.** 가득 차면 멈춘다(지금 창고 규칙 `:13` 「nothing is thrown away」와 같게). 하루 한두 번 들르면 가득 차는 길이로 시작하고 사람 시험으로 고친다. 상한 연장을 팔지 않는다.
4. **몫에 뚜껑.** 하루 방치 수입 ≤ 판 한두 번의 수입. 봇으로 「판당 도토리 중 방치 몫」을 재서 뚜껑을 건다(수치는 재지 않았다).
5. **받는 자리가 판 옆.** 모아 받기 버튼 바로 옆에 「다음 판」과 의뢰 한 줄. 받고 나면 통이 비어 있다는 것이 보인다 → 채우려면 한 판.
6. **알림 없음.** 「가득 찼어요」 푸시를 보내지 않는다(욕망 계획 §8).
7. **라이벌 방문 도토리부터 정리.** 계획대로 판 끝 손님으로 바꾸면(섬 경제 §5) 지금 있는 유일한 「체스 없는 수입」이 사라진다.

**실시간을 아예 들이지 않는 대안**: 「방치형 느낌」의 핵심이 **쌓인 것을 한 번에 받는 순간**이라면 1·2·3번(판 끝 손님 + 모아 받기 + 꾸밈 점수)만으로 얻을 수 있다. 시계는 여전히 체스다. 사용자가 「하루 뒤에 들어왔더니 뭔가 쌓여 있다」까지 원하는지 물어볼 한 가지다.
