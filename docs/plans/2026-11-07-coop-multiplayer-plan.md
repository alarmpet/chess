## 0. 한 줄 답

**사람 둘이 같이 두게 하는 것은 서버가 아니라 「실력 차를 지우는 장치」다.**
- 커플 설문(104명)에서 68% 가 한 사람은 게임이 편하고 다른 사람은 어렵다고 답했다.
- 66% 는 상대가 힘들까 봐 게임 제안을 그만둔 적이 있다(r/CoOpGaming, 2026-11).
- 체스 커플 글에서 가장 많이 나온 해결은 두 가지였다.
  - **같은 편에 서기(손과 뇌).** 「Pair up strongest player with weakest」(r/chess).
  - **판을 돌려 진영을 바꾸기(돌려 두기).** 서로 다른 글 4개.

그래서 두 가지를 **같은 기기에서 먼저** 만든다. 원격은 그 뒤에 친구 초대로만 연다.

1. **둘이 한 왕국(둘 대 AI).** 이미 있는 손과 뇌를 「두 사람이 한 색, 상대는 라이벌 AI」로 다듬는다. 역할 잠금·뇌 대기 인계·하이파이브 버튼·역할 교대가 들어간다.
2. **돌려 두기(둘이 맞두기).** 같은 기기에서 둘이 맞두다가 N수마다 진영을 바꾼다(봇 측정: 교대 없으면 약한 쪽 승 5%, 3수마다면 33%). 판이 끝날 때 이긴 색을 쥔 사람이 이긴다. 내가 망친 판을 상대가 물려받는 「남 탓」이 규칙 안에 들어 있다.
3. **원격 초대(나중).** 기획서 §12.1 의 방 코드 위에 자리(뇌·손)를 얹는다. 랜덤 매칭·자유 채팅·카드 지급은 없다.

## 3. 봇 측정 — `tools/coop_sim.mjs`

방식당 40판. 사람 세기는 초보(쉬움 탐색·실수 0.3)와 숙련(보통 탐색·실수 0.1)으로 둔다. AI 상대는 자유 대국 「보통」(쉬움 탐색·실수 0.1)이다. 원본: [coop-sim](../perf/2026-11-07-coop-sim.txt). **40판이라 10%p 안팎의 차이는 잡음 범위다**(승률 50% 근처에서 표준오차 약 8%p).

**A. 돌려 두기 — 초보 대 숙련, 판 끝에 이긴 색을 쥔 사람이 승**

| 교대 간격 | 초보 승 | 무 | 숙련 승 |
| :-- | :-- | :-- | :-- |
| 교대 없음 | 5% | 3% | 93% |
| 8수마다 | 15% | 10% | 75% |
| 5수마다 | 13% | 5% | 83% |
| 3수마다 | **33%** | 0% | 68% |

- 교대가 실력 차를 줄이는 방향은 맞다(5% → 13~33%).
- 레딧 집안 규칙의 「5수마다」는 봇에게는 약하다(13%). 3수마다라야 약한 쪽이 세 판에 한 번 이긴다.
- 반수 수는 거의 같다(105~112). 교대로 판이 길어지지 않는다.
- 봇은 「물려받은 판을 이어 가는 계획」이 없으므로 사람 결과는 다를 수 있다. **기본값은 3수, 사람 시험에서 3·5 를 비교한다.**

**B. 둘 대 AI 손과 뇌 — 팀 기준**

| 방식 | 승 | 무 | 패 |
| :-- | :-- | :-- | :-- |
| 초보 혼자 | 38% | 15% | 48% |
| 숙련 혼자 | 88% | 8% | 5% |
| 숙련 뇌 + 초보 손 | 38% | 3% | 60% |
| 초보 뇌 + 숙련 손 | 38% | 28% | 35% |
| **매 수 역할 교대** | **48%** | 13% | 40% |

- **팀은 숙련 혼자(88%)보다 훨씬 약하다.** 손과 뇌에서는 잘하는 사람이 혼자 판을 끌고 갈 수 없다. 「한 사람이 다 두는 문제」를 규칙이 이미 막는다는 뜻이다(봇 모형 안에서).
- 「강한 쪽이 뇌」(체스닷컴의 오락 관례)는 초보 혼자와 승률이 같고 패가 더 많다(60%). 봇 모형에서는 손의 실력이 더 중요하다.
- 매 수 교대가 가장 높다(48%). 다만 고정 두 방식과의 차이(10%p)는 40판 잡음 범위다. **「교대가 고정보다 나쁘지 않다」까지만 말할 수 있다.**
- 봇의 뇌는 자기 최선 수의 말 종류를 부르고, 손은 그 의도를 모른 채 자기 세기로 둔다. 사람의 대화·눈치는 모형에 없다.
- 이 표의 「초보 혼자 38%」는 FN-2 사다리 측정(약한 봇 대 보통 20%)과 다르다. 시드와 실수 값이 다르고, 둘 다 40판이라 잡음이 크다. **재 보지 않았다:** 같은 시드로 맞춘 비교.

→ 결정(§8): 둘이 한 왕국 기본은 **매 수 역할 교대**로 하고 「판마다 바꾸기」를 설정에 둔다. 돌려 두기 기본은 **3수**로 한다. 둘 다 사람 시험(CO-3)에서 다시 판단한다.

## 4. 설계

### 4.1 둘이 한 왕국 (둘 대 AI, 같은 기기) — 첫 PR

한 기기·한 화면, 한 색에 두 자리. 상대는 지금의 라이벌·자유 대국 AI. 체스 규칙은 그대로(§10-10).

| 장치 | 무엇 | 출처 |
| :--- | :--- | :--- |
| 자리 | 「뇌」는 말 종류 버튼 6개만, 「손」은 그 종류의 말만 집어 둔다(지금 그대로) | 위키·체스닷컴 손과 뇌 |
| 종류 잠금 | 뇌가 부르면 손이 둘 때까지 바꿀 수 없다. 손이 말을 집은 뒤에는 종류 교체를 거부 | grok |
| 역할 교대 | 기본은 **자기 편 수마다 뇌·손 교대**, 설정으로 「판마다 바꾸기」. 측정(§3 B)과 사람 시험으로 기본값을 정한다 | codex·agy · r/boardgames 「force changing Alpha player each turn」 |
| 뇌 대기 인계 | 뇌가 20초 동안 안 부르면 손이 아무 말이나 둘 수 있게 연다. 시간패 없음. 인계 횟수만 기록 | grok · r/northernlion 「the hand gets to take over」 |
| 하이파이브 | 상대 차례·잡기 연출 동안 「우리 실수 😅」「잘했어 🙌」 둘. 둘 다 누르면 동물 하이파이브 한 번. 승패·도토리와 무관, 글자 입력 없음 | grok · 「opportunities to roast each other」 |
| 되감기 | 이미 있는 무료 되감기(FN-3)를 팀 판에 판당 1번. 새 장치 아님 | agy 「작전 타임」을 기존 장치로 |
| 연출 | 팀 판은 `fxSettings().quick` 기본 켬(잡기 카메라 복귀 단축) | grok |
| 설명 | 「어른이 말을 부르고 아이가 둬요」 → 「둘이 한 편. 뇌가 종류를, 손이 칸을」. 「가르쳐 주기」는 따로 | grok |
| 보상 | 지금의 가족 퀘스트(주 1개, 도토리 +20)만. 카드·섬 정산은 지금 싱글과 같다(같은 기기 대 AI 이므로) | 경제 계획 44행 |

하지 않는 것: 비공개 개인 과제(agy — 근거 인용이 원문에 없었고, 공유 미션과 겹친다), 발바닥 핑(하이파이브로 대신), 교대 착수(완전한 수를 번갈아 두기).

### 4.2 돌려 두기 (둘이 맞두기, 같은 기기) — 둘째 PR

- 같은 기기에서 둘이 맞둔다. 지금 엔진에는 **같은 기기 2인 모드가 없다**(`gameMode` 는 `single`(대 AI)·`multi`(옛 방)뿐). AI 를 끈 「둘이 두기」를 새로 만든다.
- 진영 바꾸기 간격 N 은 고를 수 있다(측정 §3 A 로 기본값). 바꿀 때 카메라가 반대편으로 돌고 「자리 바꿔요!」 한 줄.
- 승패: 판이 끝날 때 이긴 색을 쥔 사람. 화면에 「누가 어느 쪽인지」 이름표(1P 🦁 / 2P 🐯 같은 표식, 이름 입력 없음).
- 카드·도토리: 같은 기기 두 사람 판은 **카드 없음**, 기록 `game` 에 모드만 남긴다(누구 도감에 넣을지 정할 수 없음).
- 하지 않는 것: 사람 상대 교대 착수, 시간 핸디캡 시계(번개 판과 겹침), 기물 핸디캡(규칙 변경 아님이지만 화면·카드 연출이 많이 얽힘 — 사람 시험 뒤).

### 4.3 원격 초대 — 사람 시험 뒤

- 기획서 §12.1 의 Supabase 방 코드 위에 `seat: brain | hand | white | black` 을 얹는다. 뇌 메시지는 종류 한 글자뿐(칸 정보가 네트워크에 없으니 원격에서는 「칸을 말로 지시」가 구조적으로 줄어든다 — grok).
- **랜덤 매칭 없음, 자유 채팅 없음**(프리셋 하이파이브만), 원격 판 카드·도토리 없음(경제 계획 44행).
- 옛 전송층(`CLOUD_MP_API_BASE`·`BroadcastChannel`, `wizardChessEngine.js:5158-5174`)은 쓰지 않는다. 수신 큐는 **적용에 성공한 뒤에만 순번을 올리고**, 빠진 수·순서 어긋남을 감지하면 서버 수 목록으로 다시 맞춘다(codex).
- 첫 수 60초 무효(§12.1)는 1:1 랭크용. 팀 판은 뇌·손 각각의 첫 입력 규칙을 따로 정한다(grok).

## 9. 이 라운드에서 배운 것

- **세 모델이 모두 놓친 답이 통합자의 원문 읽기에서 나왔다.** 셋은 「같은 편」 질문에 「같은 편」 답만 냈다. 커뮤니티는 「서로 두되 실력 차를 지우는 집안 규칙」을 더 많이 말했다. 근거: 돌려 두기 글 4개, 2026-11-07.
- **「검색 요약만 봄」은 인용이 아니다.** agy 의 인용 10개는 모두 원문에 없었고, 수상 사실만 맞았다. grok 은 발췌를 스스로 표시했고 48개가 모두 맞았다.
- **레딧이 막히면 공개 기록 저장소(arctic-shift API)로 같은 글을 받아 대조할 수 있다.** 다만 댓글이 빠진 글이 있다(mrp6gf 등 3개). 그 3개는 레딧이 풀린 뒤 화면에서 다시 확인했다.
