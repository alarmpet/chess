# 왕관 카드 계획서 v2 — 잡으면 카드, 셋 모으면 합성, 도감을 채운다

**시제품 상태 (2026-10-31):** 1~3단계를 구현했다. 판 안 능력, 미션, 별가루, 영웅 합성, 측정 로그는 아직 없다. 그림은 모델 렌더다.

작성일 2026-10-31. 근거: [1차 라운드](../research/agent-rounds/2026-10-31-capture-cards/README.md), [대규모 조사](../research/agent-rounds/2026-10-31-card-survey/README.md).
확률과 수치는 시제품 시작값이다. 사람이 해 본 적이 없다. 재미는 시제품으로 잰다.

## 1. 고리

1. 말을 잡으면 그 동물의 카드가 나온다. 대국은 멈추지 않는다.
2. 판이 끝나면 이번 판 카드를 보고, 같은 카드 셋을 합성한다.
3. 도감의 빈칸이 다음 판의 목표가 된다.

## 2. 절대 원칙

- 카드는 합법 수와 승패 판정을 바꾸지 않는다. `src/rules/` 는 카드를 모른다.
- 합성은 100% 성공하고 대국 뒤에만 한다. 규칙은 공개하고 결과만 뒤집어 보여 준다.
- 유료 팩, 유료 재굴림, 숨은 확률, 접속 재촉은 없다.
- 카드를 강제로 태우게 하지 않는다. 소모 재료를 고르게 하는 구조는 조사에서 불만이 컸다.

## 3. 카드와 등급

동물 6종 × 등급 4 = 도감 24칸. 그림은 말의 4단계 외형을 쓰고 등급 재질을 입힌다.

| 잡은 말 | 일반 | 고급 | 희귀 | 영웅 |
| :--- | :---: | :---: | :---: | :---: |
| 폰 · 미어캣 | 90% | 9% | 0.9% | 0.1% |
| 나이트 · 캥거루, 비숍 · 판다 | 50% | 40% | 9.5% | 0.5% |
| 룩 · 코뿔소 | 40% | 40% | 18% | 2% |
| 퀸 · 호랑이 | 20% | 40% | 35% | 5% |
| 체크메이트 · 사자 | 0% | 50% | 40% | 10% |

킹은 잡히지 않으므로 체크메이트 보상이 사자 카드가 된다.

## 4. 보장 규칙

처리 순서: 기본 굴림 → 첫 카드 보장 → 희귀 보장 → 영웅 보장.

- **첫 카드:** 처음 받는 카드는 희귀 이상이다. 카드가 없는 판은 다음 카드로 넘어간다.
- **희귀 보장:** 희귀 이상 없이 9장이 지나면 10장째는 희귀 이상이다.
- **영웅 보장:** 영웅 없이 59장이 지나면 60장째는 영웅이다. 잡은 동물의 영웅을 이미 가졌으면 **아직 없는 영웅 칸의 동물로 바뀐다.** 이것이 유일한 동물 변경이다.
- 잡기, 체크메이트, 위로 카드가 장수에 들어간다. 합성은 넣지 않는다.
- 영웅이 나오면 두 보장을 모두 처음으로 돌린다.
- **위로 카드:** 카드를 한 장도 못 받고 끝난 판은 일반 카드 1장을 준다. 어린이는 자주 진다.

표시는 기본적으로 별 게이지다. 숫자 확률은 도감의 `자세히` 안에 공개한다.

## 5. 합성

- 같은 동물·같은 등급 **예비 3장 → 다음 등급 1장.** 일반→고급, 고급→희귀.
- 첫 장은 도감 칸을 채우고, 그다음부터 예비가 된다.
- 영웅은 시제품에서 드롭과 보장으로만 얻는다. 무료 영웅 합성은 희소성을 무너뜨린다.
- 후속 후보: 같은 동물의 희귀 예비 5장으로 그 동물의 빈 영웅 칸을 채운다. 사람 측정 뒤 정한다.
- 판 끝 화면에서 바로 뒤집는다. 건너뛸 수 있고 `모두 합성` 이 있다.

## 6. 연출

| 등급 | 잡을 때 | 멈춤 |
| :--- | :--- | :--- |
| 일반 | 작은 카드가 잡힌 자리에서 카드통으로 날아감 | 없음 |
| 고급 | 은빛 | 없음 |
| 희귀 | 크게 뒤집힘, 무지개 | 없음 |
| 영웅 | 화면 가운데 금빛, 잡기 대기 안에서 | 추가 없음 |

새 카드에는 `NEW`, 겹친 카드에는 예비 점을 표시한다. 3칸이 찰 때 합성 표시가 켜진다.
Triple Town 사례처럼 혼자 하는 게임은 남이 못 보므로, 후속으로 마을 벽 전시가 필요하다.

## 7. 재질

| 등급 | 그림 | 재질 |
| :--- | :--- | :--- |
| 일반 | 밝은 스티커 | 무광 |
| 고급 | 파스텔 | 은박 테두리, 지나가는 빛 |
| 희귀 | 네온 윤곽과 별 | 무지개 홀로, 포인터 반응 |
| 영웅 | 깊은 우주와 왕관 | 금박, 움직이는 별 |

사용자 이미지 폴더는 참조만 한다. 재질은 CSS 혼합으로 직접 쓴다. `pokemon-cards-css` 는 GPL 이라 원리만 참고하고 코드는 쓰지 않는다. `kongyo2/cards-css` 는 GPL 코드와 겹쳐 쓰지 않는다.
시제품 그림은 게임 모델 렌더다. 일러스트는 재미를 확인한 뒤 Flow 로 만든다.

## 8. 구현 구조

- `src/cards/`: 순수 코어와 화면. 엔진은 `piececaptured` 사건만 보낸다.
- 굴림은 `hash(게임 시드, 종류, 수 번호)` 로 정한다. 카드를 켜고 꺼도 AI 난수를 건드리지 않는다.
- 저장은 판마다가 아니라 받는 즉시 한다. 판 ID 와 지급한 최고 수 번호로 무르기 재지급을 막는다.
- 버전 번호를 둔 저장 형식. ID 만 저장한다.

## 9. 단계

| 단계 | 내용 | 상태 |
| :--- | :--- | :--- |
| 1 | 굴림, 보장, 합성, 저장, 테스트 | 시제품 |
| 2 | 카드 날아감, 카드통, 판 끝 화면 | 시제품 |
| 3 | 재질, 도감, 합성 화면 | 시제품 |
| 4 | 사람 측정 로그: 잡기, 건너뛰기, 재방문 | 다음 |
| 5 | 별가루와 전시: 넘치는 예비를 자동 전환 | 다음 |
| 6 | 판 안 능력 카드 1~2종 | 측정 뒤 |
| 7 | 시작 미션, 6판째부터 | 측정 뒤 |
| 8 | 일러스트 24장 | 재미 확인 뒤 |

판 안 능력 카드와 미션은 세 모델 모두 첫 시제품에서 빼라고 했다. 처음 5판은 잡기와 합성만 보여 준다.
사용자가 원한 "먼저 비숍을 잡아라" 미션은 취소가 아니라 7단계로 옮겼다. 설계는 1차 라운드 기록에 남긴다.

## 10. 틀릴 수 있는 곳

1. 판당 잡기 수를 사람으로 재지 않았다. 합성 속도와 도감 완료 시점 전부가 달라진다.
2. 판 안 효과가 없으면 체스와 카드가 따로 논다고 느낄 수 있다.
3. 폰이 많아 미어캣 카드가 넘치고 호랑이 카드가 모자랄 수 있다.
4. 도감이 끝난 뒤 목표가 없다.
5. 모델 렌더 그림은 카드 맛이 약할 수 있다.
6. 상용 수치 다수는 공식 자료가 아니다.

## 11. 사용자가 정할 것

1. 영웅 보장이 다른 동물로 바뀌는 규칙을 받아들일지.
2. 시제품을 해 본 뒤 판 안 능력 카드를 넣을지.
3. 일러스트를 언제 만들지.
