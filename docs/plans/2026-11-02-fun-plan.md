## 1. 오늘 고친 것 (요청 1~3)

### 말 구분

- 받침: 내 편(백) 상아색에 금색 띠, 상대(흑) 남색에 빨간 띠. 띠를 두 배로 굵게 했다(`public/packs/legend/pack.json` 의 `pedestal`).
- 판 위 고리: 말마다 발밑 칸에 진영 색 고리를 깔았다. 높은 기본 시점에서는 받침이 동물에 가려지지만 고리는 보인다(`makePedestal`, `src/wizardChessEngine.js`).
- 이 고리가 잡기 번쩍임 코드와 부딪혀 매 프레임 오류가 났다. 번쩍임이 빛을 받지 않는 재질은 건너뛰게 고쳤다(`src/fx/impactFx.js`).

### 승부가 나는 AI

봇끼리 둔 측정이다([ai_sim.mjs](../research/agent-rounds/2026-11-02-fun/ai_sim.mjs), 300반수 제한). 사람과의 판은 재지 않았다.

| 대결 | 결과 | 중앙 수(반수) | 한 수 최대 생각 |
| :--- | :--- | ---: | ---: |
| 예전 AI 대 예전 AI, 20판 | 백 2 · 흑 4 · **무승부 14** | 61 | 0초 |
| 새 보통 대 예전 AI, 10판 | 새 AI 10승 | 37 | 0.36초 |
| 예전 AI 대 새 보통, 10판 | 새 AI 10승 | 48 | — |
| 새 쉬움 대 새 쉬움, 10판 | 백 7 · 흑 2 · 무승부 1 | 67 | 0.07초 |
| 새 보통 대 새 쉬움, 10판 | 보통 10승 | 103 | 0.22초 |
| 새 어려움 대 새 보통, 4판 | 어려움 4승 | 145 | **2.66초** |
| 새 보통 대 새 보통, 12판 | 백 7 · 흑 4 · 무승부 1 | 100 | 0.31초 |

- 예전 AI 는 한 수만 봤다. 자기 말이 공격받는지, 끝내기를 몰랐다. 그래서 둘 다 버티기만 하다 무승부가 났다.
- 새 AI(`src/rules/ai.js`)는 알파베타 탐색과 잡기 끝까지 보기를 한다. 앞선 쪽이 상대 킹을 구석으로 몰고, 앞설 때 같은 자리를 되풀이하지 않는다.
- chess.js 공개 함수는 수마다 기보를 써서 느렸다(보통 단계 한 수 최대 6초). 내부 수 생성(`_moves`, `_makeMove`)을 써서 0.36초로 줄였다. 고른 수는 공개 함수로 다시 확인한다.
- 단계: 라이벌 없음은 보통, 소풍 나온 미어캣단(실수 40%)은 쉬움, 나머지는 보통에 라이벌의 실수율을 쓴다. 실수는 두세 번째 후보 중에서 고르고, 퀸을 공짜로 주는 수는 고르지 않는다.
- 어려움은 한 수에 최대 2.7초 걸려 화면이 멈춘다. 작업자 스레드로 옮기기 전에는 쓰지 않는다.
- 테스트 5개: 공짜 퀸 잡기, 한 수 메이트, 공격받는 퀸 피하기, 모든 단계 합법 수, 킹+퀸으로 메이트까지(`test/ai.test.mjs`).
- **2026-11-03 고침:** 킹+퀸 테스트가 가끔 실패했다. 60판을 재 보니 17판(28%)이 메이트를 못 하고 반복 무승부였다. 킹 위치표가 중반용(구석이 +16~24, 가운데가 -50)이라 끝내기에서 내 킹이 다가가지 않았다. 남은 큰 말이 적으면(퀸·룩·경기물 합 1800 이하) 킹 위치표를 빼자 60판 모두 메이트.

### 상단 정리

- 상단에는 🃏 카드 · 🏡 마을 · 🏆 라이벌 · ☰ 메뉴만 둔다. 휴대폰에서는 글자를 빼고 아이콘만, 로고도 숨긴다.
- 메뉴 판: 이번 판(새 판, 기권, 흑으로 두기) · 보기(시점 넷) · 더 보기(외형, 설정, 언어, UI 숨기기). 데스크톱은 오른쪽 위에서 떨어지고 휴대폰은 아래에서 올라온다. Esc 로 닫힌다.
- 뺀 것: **AI 수 두기**(AI 가 내 수를 대신 둠). 판의 주인공은 사람이 두는 수라는 세 모델의 공통 지적을 따랐다. 코드에서는 남아 있다.

## 2. 재미의 기준

세 모델의 정의를 합쳤다. 이 게임에서 재미있다는 것은 넷이다.

1. **지금 무슨 일이 일어나는지 안다.** 내 말과 상대 말, 누구 차례인지, 방금 상대가 뭘 했는지.
2. **내 수가 결과를 바꾼다.** 내가 찾은 한 수로 큰 말을 잡거나 위기를 넘긴다.
3. **판이 끝난다.** 버티기 무승부가 아니라 이기거나 지고, 한 판이 이야기로 남는다.
4. **져도 다음 판을 누르고 싶다.** 카드와 섬이 자라고, 다음에 해 볼 것이 보인다.

승률은 재미 지표로 쓰지 않는다. 승률을 맞추려다 몰래 봐주는 AI 로 가기 쉽다.

| 신호 | 재는 법 | 첫 목표 (추정) |
| :--- | :--- | :--- |
| 판이 끝나는 비율 | 메이트·기권·무승부·이탈 기록 | 승패로 끝남 70% 이상 |
| 한 판 길이 | 반수, 실제 시간 | 사람 측정 뒤 정한다. 모델 셋의 추정은 5~20분으로 갈렸다 |
| 첫 잡기까지 | 반수 | 판의 절반이 12반수 안 |
| 결정적 순간 | 큰 말 잡기, 체크, 내 말 위기 | 판당 2~4번 |
| 패배 뒤 다음 판 시작률 | 끝난 뒤 60초 안 새 판 | 승리 뒤의 60% 이상 |
| 10수 안 이탈 | 이탈·기권 기록 | 15% 미만 |
| 봐줬다고 느낌 | 사람 시험 질문 | 숙련자 다수가 "아니다" |

지금 기록(`logGame`)은 판 끝의 시간·수·잡기·카드 능력 사용을 남긴다. 다음 판 시작과 도중 이탈은 남기지 않으므로 0단계에서 더한다.

## 3. 역전 찬스를 넣나 — 넣는다, 규칙 안에서

세 모델 모두 찬성했고, 모두 기본 대국의 체스 규칙은 그대로 두자고 했다. 갈린 것은 **AI 를 몰래 느슨하게 하는 고무줄**이다.

| 모델 | 고무줄 |
| :--- | :--- |
| agy | 찬성. 지면 실수율을 10%에서 35~40%로 올리되, 공격하다 빈틈을 내는 실수로. "공정한 결투" 끄기 옵션 |
| grok | 라이벌 성격으로 공개할 때만. 처음 강도는 0 |
| codex | 반대. 숨긴 보정은 어린이 학습과 숙련자 신뢰를 둘 다 깬다 |

**결정: 숨긴 고무줄은 넣지 않는다.** 판 중에 AI 강도가 바뀌지 않는다. 대신 아래 장치로 지고 있는 사람에게 할 일을 준다.

| 장치 | 규칙 | 상태 |
| :--- | :--- | :--- |
| 되감기 | 연습 단계와 첫 5판은 판마다 1번 무료. 지금은 5판 뒤 카드로만 열린다 | 바꿈 |
| 위기 알림 | 내 큰 말(호랑이·코뿔소)이 공격받으면 "호랑이가 노려지고 있어요" 한 줄. 사실만 말한다 | 신규 |
| 힌트 | 요청할 때 한 수를 빛으로 보여 주고 이유 한 줄. 판당 횟수 제한 | 신규 |
| 라이벌 성격 | 쉬운 라이벌은 늘 공격적으로 덤비다 빈틈을 내는 성격으로 고정 공개. 판 상황에 따라 바뀌지 않는다 | 신규 |
| 판 밖 회복 | 패배 화면에 "이번 판 잘한 수 하나"와 잡은 카드. 위로 카드는 이미 있다 | 신규 |
| 쉬운 상대 제안 | 세 판 연속 지면 "더 쉬운 라이벌과 둬 볼까요?"를 묻는다. 몰래 바꾸지 않는다 | 신규 |
| 파티 모드 | 말 부활, 두 번 두기 같은 규칙 변형. 기본과 기록·보상을 나눈다 | 사람 시험 B 뒤 검토 |

## 4. AI 의 성격과 난이도

- **난이도 = 라이벌.** 새 숫자를 만들지 않고 라이벌을 고르면 단계가 정해진다. 라이벌 카드에 한 줄로 보여 준다: "덤비다 자주 놓쳐요", "맞수를 둬요", "끝까지 몰아요".
- **기본 상대:** 처음 판은 쉬움으로 시작하고, 이기면 다음 라이벌을 권한다. 지금은 라이벌 없음이 보통이라 어린이에게 셀 수 있다(새 보통은 예전 AI 를 10판 모두 이겼다).
- **어려움:** 탐색을 작업자 스레드로 옮긴 뒤 연다. 그 전에는 화면이 2초 넘게 멈춘다.
- **표정:** 큰 말을 잃으면 상대 킹이 놀라고, 앞서면 우쭐한다. 생각 중에는 말풍선. 연출만 바뀌고 수는 같다.

## 9. 틀릴 수 있는 곳

1. 판이 길게 느껴진 원인이 AI 가 아니라 잡기 연출 대기일 수 있다. 사람 시험에서 실제 시간을 함께 잰다.
