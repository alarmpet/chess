# 플레이 테스트 후속 계획서

작성일 2026-10-31. 근거는 [플레이 테스트 라운드](../research/agent-rounds/2026-10-31-playtest/README.md). 세 모델이 9판을 플레이했고 모든 주장을 대조했다. 재미와 소리는 사람이 해 봐야 한다.

**상태 (2026-10-31):** 1~5절을 구현했다. 체크 뛰기, 승급, 캐슬링, 무승부 카드, 체크메이트 카드, 모자는 화면으로 확인했다. 예비 동작과 어지러운 별, `메이트!` 글자는 화면으로 확인하지 못했다. 잡기 대기 중앙값은 기본 약 4.2초, 빠른 대국 약 3.4초다. 재미와 소리는 아직 사람이 확인해야 한다.

## 1. 먼저 고칠 결함

1. 무승부에도 종료 카드를 띄운다.
2. 체크메이트 카드를 밝고 귀여운 모양으로 바꾸고 옛 문구를 지운다.
3. 게임 이름을 WILD CROWN 으로 통일한다(제목, 로딩, 메타, 언어 파일). `성당 전경` 은 `전체 보기` 로 바꾼다.
4. 마을: `💗 오늘` 을 `쓰다듬기` 로 구분, 말 이름을 좌표 없이 표기, 조사 오류 수정, 다시 열면 고른 건물을 비운다.
5. 밀짚모자가 눈을 가리지 않게 맞추고 얼룩을 확인한다.

## 2. 대국 속도

잡기 한 번이 약 2.8초를 늘린다.

- 기본 대국: 잡기 뒤 카메라 복귀를 1.18~1.60초에서 0.70~0.90초로 줄인다.
- 빠른 대국 모드: 잡기 카메라를 쓰지 않고 복귀도 없앤다. 기본은 끔이다(사용자가 정할 수 있음).

목표는 기본에서 잡기 대기 중앙값 약 4.3초, 빠른 모드에서 약 3.3초다. 시작값이며 다시 잰다.

## 3. 특별한 수

전부 대국 시간을 늘리지 않는다.

- **캐슬링:** 착지 때 손뼉 소리, 별, `짝!`.
- **승급:** 별이 크게 터지고 `승급!`.
- **체크:** 체크당한 킹이 짧게 펄쩍 뛰고 `체크!`. 멈춤이 없어 연속돼도 흐름을 막지 않는다.
- **체크메이트:** 쓰러진 킹 위로 큰 별 터짐과 `메이트!`.

## 4. 타격감 마무리

- 공격자 예비 동작: 공격 직전에 살짝 웅크린다.
- 어지러운 별: 잡힌 말이 튕겨 나갈 때 머리 위로 별이 돈다.

## 5. 설정

위쪽 메뉴에 설정 창 하나를 두고 소리, 화면 흔들림, 빠른 대국을 모은다. 버튼을 더 늘리지 않는다.

## 6. 미룬 것

새 애니메이션(미어캣 두리번, 사자 포효, 동물별 잡기, 하품)은 미룬다. 세 모델의 우선순위가 가장 낮았고 뼈대를 다시 입혀야 해서 비용이 크다. 사람이 직접 해 본 뒤 정한다.

## 7. 확인

- 테스트: 연출과 모드를 바꿔도 기보와 판정이 같다.
- 재측정: 같은 하네스로 잡기 대기 시간을 다시 잰다. 조기 종료 값은 빼고, 보이는 글자만 덤프한다.
- 렌더: 무승부 카드, 체크메이트 카드, 모자, 특별한 수 스크린샷.
