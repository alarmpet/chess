## 0. 한 줄 답

영상이 말한 성공 요인은 둘이다. 하나는 「꺼도 자라는 밭」, 다른 하나는 「매주 새 이벤트」다.

- **운영자 본인은 앞의 것을 더 크게 봤다.** Splitting Point 의 Janzen Madsen 은 「the whole idea of the garden growing offline, the persistent world」가 성장 이유라고 말했다(GamesBeat 인터뷰).
- 우리는 「판이 시계」라는 섬 원칙을 지킨다. 그 위에 **하루 한 번 「밤사이 이슬」**로 「꺼도 기다려진다」만 가져온다.
- 「매주」는 서버 없이 **달력으로 돌아가는 JSON 한 덩어리**로 가져온다.
- 돈 쪽(유료 알 뽑기, 성장 가속, 재입고 결제)은 하나도 가져오지 않는다.

## 4. 가져오지 않을 것

유료 알, 성장 가속 판매, 재입고 결제, 작물·펫 훔치기, 거래, 푸시 알림, 접속해야만 받는 한정품, 관리자 라이브 이벤트.

- 근거는 욕망 계획 §7·§8·§9 다.
- 서버가 없는 1인 개발이라는 조건에도 맞지 않는다.

## 5. 「매주」 운영 절차 (codex 안을 저장소 구조로)

1. **월요일 — 가설 정하기.** 한 줄로 쓴다. 예: 「이슬을 보면 그날 한 판을 더 둔다」.
2. **변경 준비.** 새 필드는 읽을 때 기본값을 채운다. 저장 버전(`wildcrown.village.v1` 안의 `v`)을 올리고, 옮기기 함수를 둔다. **새 버전이 쓴 저장을 직전 코드가 읽을 수 있는지** 확인한다.
3. **배포 전 검사.** `npm test` · `npm run build` 를 통과시킨다. 옛 저장과 새 저장에서 각각 한 판을 끝내고 새로고침해 본다.
4. **배포.** 문제가 생기면 직전 빌드로 되돌린다.
5. **주말 — 기록.** 「가설 · 본 것 · 다음 주」 세 줄을 남긴다. 기록은 기기 안과 사람 시험 메모뿐이다. 유지율 같은 큰 주장은 하지 않는다.

**주간 단위는 JSON 이다.** 문장·팔레트·주문·들르는 라이벌로 만든다. 캐릭터 GLB 를 주간 단위로 잡으면 1인이 따라갈 수 없다(grok).

## 6. 우리 홍보 쇼츠에 쓰기

영상의 형식은 그대로 빌려 쓸 수 있다. 어두운 바탕, 보라 강조, 장 번호, 아래 비네트에 게임 화면, 노래방식 자막, 마지막 두 버튼 질문이다.

- **주제 예:** 「혼자 만든 동물 체스, 매주 한 가지씩 고친다」 — 1주 차: 섬 마을이 체스판처럼 바다에 뜨다(오늘 한 디테일 8단계).
- **숫자는 같은 빌드의 실제 플레이에서만** 가져온다(codex). 예정 기능은 「만드는 중」으로 표시한다.
- 남의 게임 화면은 쓰지 않는다. 남의 숫자를 우리 성과처럼 쓰지 않는다.
- 제작은 기존 쇼츠 도구(ffmpeg-skill)로 한다. 음량은 프로젝트 규칙을 따른다.

### G3 결과 (2026-11-04)
- **설계 근거:** [역공학 보고서 2판](../research/2026-11-04-farm-oss-rea/README.md)의 G3 표. harvest-hollow 주간 게시판(`folk.js`)과 달력(`calendar.js`)을 직접 읽고 옮겼다.
  - 「8주분 순환 표」는 원본에 없는 안이라 버렸다. 대신 후보 묶음에서 카운터 열쇠로 고른다.
- **규칙** (`src/village/economy.js`: `dayIndex` · `weekIndex` · `weekDue` · `rollWeek` · `weekPick`)
  - 주는 월요일에 시작한다.
  - 저장의 주가 달력보다 **뒤처졌을 때만** 새로 고른다. 시계를 되돌리면 아무 일도 없다.
  - 몇 주를 건너뛰어도 새로 고르는 것은 한 번이다.
  - 고르기는 섬 시드와 카운터로 정한다. 시드는 섬이 처음 필요할 때 한 번 만든다.
- **판정 시점:** 섬을 열 때와 판이 끝날 때. 원본은 서버가 부팅할 때와 타이머로 돈다.
- **콘텐츠:** `pack.json` 의 `weekly` 8개. 항목마다 손님 라이벌 하나와 문장 한 줄이 있다. 팩 검사기가 id 중복, 없는 라이벌, 빠진 한국어 문장을 막는다. `weekly` 가 없는 팩은 주가 돌지 않고 나머지는 그대로다.
- **화면:** 새 주를 고른 그 순간에만 섬 카드에 「📅 새 주가 왔어요. 이번 주 손님은 …」 한 줄이 뜬다. 마감과 남은 시간은 없다.
- **확인:**
  - 테스트 4개(주차 경계·연말·윤년 / 되돌린 시계·밀린 주 / 카운터 순서·저장 / 팩 검사). 전체 129개 통과.
  - 브라우저: 첫 열기에서 한 줄이 나오고 `w=2966`, `n=1` 이었다. 같은 주에 다시 열면 아무것도 나오지 않았다. 지난 주로 되돌린 저장을 열면 새 손님이 나오고 `n=2` 였다. 휴대폰 폭에서도 줄이 맞게 접혔다. 저장은 시험 전으로 되돌렸다.
- **아직:** 손님이 섬에 깃발로 오거나 주문을 내는 일은 섬 경제 7단계(라이벌 방문을 판 기준으로)와 함께 한다.
