# 왕관 섬 계획서 — 내가 둔 체스가 섬이 되고, 잡은 동물이 주민이 된다

작성일 2026-10-31. 근거: [마을 조사 라운드](../research/agent-rounds/2026-10-31-town-survey/README.md). 시안: `docs/concepts/town/`.
[왕관 마을 계획서](2026-10-30-crown-village-plan.md)의 다음 단계이고, [왕관 카드 계획서](2026-10-31-capture-card-plan.md)의 미션을 의뢰판으로 바꾼다.
수치는 전부 시작값이다. 사람이 해 본 적이 없다.

## 1. 한 문장과 고리

체스 한 판의 사건이 섬의 땅이 되고, 잡아서 얻은 동물 카드가 그 섬의 주민이 되어 농사를 짓고 불을 밝힌다.

1. **판 전 10초:** 의뢰판을 본다. 제분소 주민이 "오늘 나이트를 잡아 주세요" 라고 부탁한다.
2. **대국:** 체스는 규칙 그대로다. 잡을 때마다 카드가 나온다.
3. **섬으로:** 말이 걸은 길이 굳고, 잡은 자리에 나무가 선다. 건물이 판 끝 수확을 내놓는다.
4. **1~3분:** 건물 하나를 놓거나 주민을 옮긴다. 다음 판으로 간다.

## 2. 이 게임만의 장치 셋

세 모델이 각각 낸 장치가 서로 맞물린다.

**사건 문법 (체스가 땅을 만든다).** 수가 곧 좌표라서 추가 입력 없이 섬이 자란다.

| 체스 사건 | 섬에 남는 것 | 상태 |
| :--- | :--- | :--- |
| 말이 지나간 칸 | 길 | 있음 |
| 잡기 | 그 동물의 나무 | 있음 |
| 캐슬링 | 성문 | 기록 있음, 표시 필요 |
| 승급 | 2층 집 | 기록 있음, 표시 필요 |
| 체크메이트 | 그 칸의 깃발 | 신규 |

**주민 입주 (잡은 동물이 산다).** 카드를 건물에 넣으면 그 동물이 마을을 걸어 다니며 일한다. 카드는 사라지지 않고 언제든 옮길 수 있다. 조사에서 가장 많은 요구가 생기였고, 움직이는 동물은 이미 있다.

**말 모양 영향권 (마을이 체스를 가르친다).** 주민의 영향이 그 말의 이동 모양으로 퍼진다. 놓기 전에 칸이 미리 보인다. 생산이 조금 늘 뿐 벌은 없다.

| 주민 | 영향권 |
| :--- | :--- |
| 미어캣 | 앞 칸 |
| 캥거루 | L자 |
| 판다 | 대각선 |
| 코뿔소 | 십자 |
| 호랑이 | 십자와 대각선 |
| 사자 | 주변 8칸 |

이 조합을 가진 게임은 찾지 못했다. 재미는 시제품으로 재야 한다.

## 3. 사용자 아이디어를 어떻게 살렸나

"일반카드로 농장, 작물, 돈, 발전소, 고급카드" 를 그대로 쓰되, 조사에서 나온 함정 셋을 피했다.

| 원안 | 위험 | 바꾼 것 |
| :--- | :--- | :--- |
| 일반 카드로 농장 | 카드를 태우면 반발이 크다 | 일반 카드 주민이 농사를 짓는다. 사라지지 않는다 |
| 발전소에 고급 카드 | 특정 재료에 막히는 것이 가장 큰 불만이다 | **아무 동물의 고급 이상 주민** 이면 열린다 |
| 전력 관리 | 실패 상태는 힐링을 깬다 | 전력 부족이 없다. 켜면 섬에 밤이 생긴다 |

## 4. 건물과 사슬

사슬 깊이는 2다. 재화는 도토리, 곡물, 빵 셋이다. 쓸모없는 자원을 만들지 않는다. 시안의 건물을 기준으로 잡았다.

| 건물 | 도토리 | 주민 조건 | 판 끝 효과 |
| :--- | ---: | :--- | :--- |
| 밭 | 20 | 일반 이상 | 곡물 |
| 숲 쉼터 | 30 | 일반 이상 | 잡기 나무에서 하트 |
| 풍차 | 40 | 일반 이상 | 곡물 → 밀가루 표시, 빵집 효율 |
| 장터 | 60 | 일반 이상 | 남는 곡물·빵 → 도토리 |
| 빵집 | 80 | 고급 이상 | 곡물 → 빵 |
| 반딧불 발전소 | 120 | 고급 이상 | 밤 팔레트, 창문 불빛, 판 끝 모든 건물 +1 |
| 온천 | 160 | 고급 이상 | 빵 → 말 하트, 외형 단계로 이어짐 |
| 축제 무대 | 240 | 희귀 이상 | 의뢰 성공마다 그 동물의 축제 |

- 건설과 수확은 판 끝에 된다. 실시간 타이머는 없앤다. 쉬어도 손해가 없고 체스가 곧 시계다.
- 빵은 쓸 곳이 둘이다. 도토리로 팔거나 온천에서 하트가 된다.
- 넘치면 생산이 멈출 뿐 버려지지 않는다. 창고 벽은 없다.
- 영웅은 어떤 건물의 조건도 아니다. 들어가면 그 건물이 상징물이 되고 전용 동작이 열린다.

## 5. 페이스

Royal Match 계열의 "한 판 = 눈에 보이는 변화 하나" 를 기준으로 했다. 시뮬레이션은 실제 드롭표를 쓰고 사람 잡기 수는 가정이다(`town_sim.py`).

| 조건 | 건물 4개 | 고급 조건 건물 | 8개 완성 | 20판까지 건물 |
| :--- | ---: | ---: | ---: | ---: |
| 어른 가정 | 7판 | 10판 | 24판 | 7.0 |
| 약한 어린이 가정 | 8판 | 12판 | 26판 | 6.8 |

고급 조건이 약한 플레이어를 막지 않았다. 사이사이 빈 판은 길, 나무, 작은 소품이 채운다. 소품을 건물보다 먼저 늘린다.

**섬 완성:** 8개가 차면 섬을 사진으로 남기고 앨범에 넣은 뒤 새 섬을 연다. 끝없는 성장은 금방 지루해진다는 조사 결과를 따랐다. 주민과 카드는 이어진다.

## 6. 의뢰판

카드 계획서의 미션 카드 대신 마을 주민의 부탁으로 바꾼다. 체스와 마을을 잇는 고리다.

- 건물 주민이 잡기 하나를 부탁한다. 처음 5판은 숨긴다.
- 해내면 그 건물이 바로 한 번 자란다. 못 해도 벌이 없다.
- 먼저 잡기 레이스는 축제 무대 뒤의 큰 의뢰로 쓴다.
- 나쁜 수를 강요하는지 관찰한다. 강요하면 의뢰를 넓힌다.

## 8. 카드 화풍

**결정: 코믹 잉크.** 시안 6종이 `docs/concepts/town/ink-all.jpg` 에 있다.

- 등급은 틀 재질, 보석 모양, 틀을 뚫는 정도로 나눈다. 일반 나무, 고급 은, 희귀 보라 금 홀로, 영웅 풀아트 무지개.
- 자세와 표정이 등급마다 달라 합성 보상이 그림으로 보인다.
- 작은 크기에서 잘 읽힌다. 마을의 부드러운 3D 와는 얇은 외곽선으로 잇는다.
- 한 장에 네 등급을 그려 자르는 방식으로 만든다. 누끼는 시험으로 확인했다.

세 모델 모두 잉크를 골랐지만 브리핑의 설명이 잉크에 유리했으므로 근거로 쓰지 않았다. 판단 근거는 시안을 직접 본 비교다. 사자·판다 비교에서 글로시는 고무 인형, 페인팅은 사자 얼굴이 뭉개졌다.

고칠 것: 호랑이·코뿔소 시트의 일부 영웅 틀, 워터마크 제거, 이름판 한글을 코드로 얹기.

## 9. 카드 역할 정리

| 등급 | 마을에서 | 소모 |
| :--- | :--- | :--- |
| 일반 | 기본 주민, 영향권 | 없음 |
| 고급 | 고급 건물 주민, 강화 영향권 | 없음 |
| 희귀 | 축제 무대, 영향권 교차 광장 | 없음 |
| 영웅 | 상징물과 전용 동작 | 없음 |

합성과 예비는 그대로다. 주민 수는 도감 칸이 아니라 보유 장수로 센다. 구현 전 사람 측정으로 정한다.

## 10. 체스가 좋아지는 이유

Dawnmaker 개발자는 메타가 코어를 낫게 하지 못했다고 회고했다. 그래서 마을은 체스 실력을 높여 주지 않는 대신 체스를 더 읽게 만든다.

- 영향권을 놓으며 말 이동을 반복해서 본다.
- 의뢰가 한 판에 작은 목표를 준다.
- 경로가 땅으로 남아 지난 판을 돌아보게 된다.
- 돌본 말이 다음 판에 달라진 외형으로 나온다.

## 11. 만드는 순서

| 단계 | 내용 | 끝나는 조건 |
| :--- | :--- | :--- |
| 0 | 미커밋 카드 기능 정리, 잉크 카드 24장 적용 | 완료, 커밋 전 |
| 1 | 섬 그래픽: 팔레트, 물, 카메라, 외곽선 | 시안 1에 가깝게 |
| 2 | 저장 v2 이주, 판 끝 수확, 사슬 3개(밭·풍차·장터) | 분할 불변 테스트 통과 |
| 3 | 주민 입주와 걷기 | 카드가 건물에서 일함 |
| 4 | 말 모양 영향권 미리보기 | 재미 판정 |
| 5 | 의뢰판, 나머지 건물 5개 | 8개 완성 플레이 |
| 6 | 사건 문법 나머지, 밤, 섬 사진과 새 섬 | 첫 섬 완성 |

**1차 재미 판정은 4단계 뒤에 한다.** 대국 뒤 마을에서 스스로 주민을 옮기고 다음 판을 시작하는지 본다. 드물면 5단계로 가지 않고 배치 반응부터 고친다.

## 12. 넣지 않는 것

실시간 타이머, 작물 썩음, 수리, 창고 벽, 전력 부족, 파산, 특정 카드 요구, 카드 소모 건설, 약탈, 접속 재촉, 유료 재화.

## 13. 틀릴 수 있는 곳

1. 말 모양 영향권은 전례가 없다. 초보에게 어렵거나 8×8 에서 답이 뻔할 수 있다.
2. 체스의 긴장과 섬의 느림이 같은 게임으로 느껴지지 않을 수 있다.
3. 타이머를 없애면 복귀 동기가 약해질 수 있다. 조사로는 어느 쪽도 증명되지 않았다.
4. 판당 카드와 대국 시간을 재지 않았다.
5. 8개 건물은 얇을 수 있다. 8×8 도 금방 찰 수 있다.
6. 범위가 크다. Dawnmaker 는 메타가 2인 프로젝트를 부풀렸다.
7. 상용 수치 다수는 공식 자료가 아니다.

## 14. 사용자가 정할 것

1. 실시간 타이머를 없앨지. 추천은 제거다.
2. 영웅을 조건 없는 꾸미기로 둘지. 추천은 그대로다.
3. 섬 완성 뒤 새 섬으로 넘어갈지. 추천은 그대로다.
