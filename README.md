# 🏰 성소의 정원: 아케인 팜 (Sanctuary Garden: Chess & Farm)

> **3D 고딕 대성당 체스 전투 × 아늑한 3D 성소 정원 가꾸기의 완벽한 결합!**  
> 체스 대국에서 기물을 쓰러뜨려 골드 코인을 모으고, 햇살 쏟아지는 안뜰 정원에서 신비한 마법 작물을 재배하여 체스 마법을 강화하는 하이브리드 3D 전략 파밍 게임입니다.

---

## 🌾 핵심 게임플레이 순환 루프 (The Core Loop)

```
[1. 성당 체스 대국 (전투 & 긴장)]
  - 기물 처치 시 골드 획득 (폰 +15G, 나이트/비숍 +35G, 룩 +60G, 퀸 +100G)
  - 체크메이트 승리 시 +250 Gold, +3 Gems, 전설 씨앗 획득
  - 체스를 1수 둘 때마다 모든 작물 25% 고속 성장!
        ▼ (코인 & 전리품 공급)
[2. 3D 성소 안뜰 정원 (힐링 & 육성)]
  - 원클릭 뷰 전환 (`[🌱 성소 정원] ⇄ [⚔️ 체스 대국장]`)
  - 3x3 3D 밭 타일: 씨앗 심기 ➔ 물주기 ➔ 실시간 3D 성장 ➔ 수확
  - 천사 분수대(자동 관수), 마법 벌통(성장 가속), 허수아비 건설
        ▼ (수확물 가공 & 버프)
[3. 체스 전투력 강화 (영구 피드백)]
  - 🍇 마나 포도 수확 ➔ 체스 시작 마나 +1 영구 증가 (최대 5마나)
  - 🌾 황금 밀 수확 ➔ 대국 코인 획득량 1.5배 증가
  - 🌶️ 불꽃 고추 수확 ➔ 메테오 마법 피해가 십자형(Cross) 범위로 확장
  - 🌿 성스러운 생명초 ➔ 킹이 잡혀도 1회 되살아나는 부활의 영약 활성화
```

## ✨ 주요 특징 (Features)

### 1. 3D 절차적 마법 작물 5종
* 🍇 **아케인 마나 포도 (Mana Grape)**: 수확 시 체스 시작 마나 +1 영구 증가.
* 🌾 **태양의 황금 밀 (Golden Wheat)**: 빠른 성장 및 판매 시 높은 골드 환급.
* 🌶️ **화로 불꽃 고추 (Flame Pepper)**: 메테오 마법의 폭발 범위 확대.
* 🌿 **성스러운 생명초 (Sacred Herb)**: 킹 치명상 1회 방어 부활 영약.
* 🎃 **자수정 보석 호박 (Amethyst Gourd)**: 고가 판매용 작물 (+180 Gold).

### 2. 🏛️ 정원 시설 및 자동화 건설
* ⛲ **성스러운 천사 분수대 (250G)**: 모든 밭에 성수를 공급하여 물주기 노동 생략.
* 🐝 **마법 꿀벌 벌통 (200G)**: 황금빛 꿀벌들이 꽃가루를 날리며 성장 속도 1.5배 가속.
* 🗿 **체스 석상 허수아비 (150G)**: 고딕 나이트 석상. 수확 시 25% 확률로 2배 수확.

### 3. 🔊 Web Audio 무지연 절차적 사운드
* 골드 짤랑이는 동전 소리, 흙 파는 소리, 시원한 물주기 소리, 하프 팡파르 수확음이 실시간 합성 재생됩니다.
* 상단 헤더의 `[🔊 / 🔇]` 버튼으로 사운드 켜기/끄기 지원.

### 4. 🎴 5종 아케인 마법 카드 & 돌 파편 물리
* ⚡ **심판의 번개**: 적 기물 1턴 석화(스턴)
* 🌀 **차원 도약**: 아군 기물 2칸 내 순간이동
* 🛡️ **성소의 가호**: 1회 피격 무효화 황금 회전 보호막
* 🔥 **화로의 겁화**: 메테오 폭격으로 적 기물 산산조각 파괴
* ♟️ **폰의 각성**: 폰을 그 자리에서 즉시 여왕(Queen)으로 승급

## 🕹️ 조작법 가이드 (Controls)

| 환경 | 동작 | 설명 |
| :--- | :--- | :--- |
| **공통** | **[🌱 정원] ⇄ [⚔️ 체스장]** | 상단 버튼으로 카메라를 체스판과 3D 정원 사이로 부드럽게 전환 |
| **정원 모드** | **3D 밭 클릭** | 빈 밭 클릭 시 선택된 씨앗 심기, 마른 밭은 물주기, 익은 작물은 수확 |
| **정원 모드** | **하단 씨앗 선택** | 원하는 작물 씨앗을 클릭해 선택 후 밭을 클릭 |
| **정원 모드** | **[🛒 상점] / [🎒 창고]** | 씨앗 및 시설 구매, 수확물 판매 및 버프 현황 확인 |
| **체스 모드** | **말 선택 및 이동** | 아군 기물을 클릭 후 이동 가능한 칸(초록 룬)을 눌러 이동 |
| **PC** | **마우스 좌클릭 드래그** | 3D 공간 카메라 궤도 회전 (Orbit) |
| **PC** | **마우스 우클릭 드래그** | 화면 평행 이동 (Pan) |
| **PC** | **마우스 휠 스크롤** | 줌 인 / 줌 아웃 (Zoom In / Out) |
| **PC** | **WASD + R/F** | 3D 공간 자유 비행 이동 (R: 상승, F: 하강) |
| **PC** | **키보드 H** | UI 숨기기/보이기 토글 (시네마틱 관람 모드) |

## 🚀 빠른 시작 (Quick Start)

Node.js (v18 이상 권장) 환경에서 바로 실행 가능합니다:

```bash
# 1. 저장소 클론
git clone https://github.com/alarmpet/chess.git
cd chess

# 2. 패키지 설치
npm install

# 3. 로컬 게임 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 시 즉시 플레이할 수 있습니다.

### 테스트 및 프로덕션 빌드
```bash
npm test       # 단위 테스트 (3D 바이너리 + 아케인 마법 + 정원 파밍 엔진)
npm run build  # 프로덕션 번들링
npm run preview
```

## 🛠️ 기술 스택 (Tech Stack)

* **프론트엔드**: React 19, TypeScript, Vite 8
* **3D 그래픽스 & 씬 전환**: Three.js (r170), OrbitControls, Procedural Low-Poly Crop Meshes
* **오디오 엔진**: Web Audio API (Procedural Real-Time Audio Synthesizer)
* **저장 시스템**: LocalStorage 기반 영구 농장 데이터 저장 (골드, 작물 성장도, 시설 배치)
