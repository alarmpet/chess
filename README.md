# 🏰 성소의 정원: 아케인 팜 (Sanctuary Garden: Chess & Farm)

> **3D 고딕 대성당 체스 전투 × 아늑한 3D 성소 정원 가꾸기의 완벽한 결합!**  
> 체스 대국에서 기물을 쓰러뜨려 골드 코인을 모으고, 햇살 쏟아지는 안뜰 정원에서 신비한 마법 작물을 재배하여 체스 마법을 강화하는 하이브리드 3D 전략 파밍 게임입니다.

---

## 🌾 핵심 게임플레이 순환 루프 (The Core Loop)

```
[1. 성당 체스 대국 (전투 & 긴장)]
  - 기물 처치 시 골드 획득 (폰 +15G, 나이트/비숍 +35G, 룩 +60G, 퀸 +100G)
  - 체크메이트 승리 시 +250 Gold, +3 Gems, 전설 씨앗 획득
  - 체스를 1수 둘 때마다 모든 작물 25% 고속 성장!
        ▼ (코인 & 전리품 공급)
[2. 3D 성소 안뜰 정원 (힐링 & 육성)]
  - 원클릭 뷰 전환 (`[🌱 성소 정원] ⇄ [⚔️ 체스 대국장]`)
  - 3x3 3D 밭 타일: 씨앗 심기 ➔ 물주기 ➔ 실시간 3D 성장 ➔ 수확
  - 천사 분수대(자동 관수), 마법 벌통(성장 가속), 허수아비 건설
        ▼ (수확물 가공 & 버프)
[3. 체스 전투력 강화 (영구 피드백)]
  - 🍇 마나 포도 수확 ➔ 체스 시작 마나 +1 영구 증가 (최대 5마나)
  - 🌾 황금 밀 수확 ➔ 대국 코인 획득량 1.5배 증가
  - 🌶️ 불꽃 고추 수확 ➔ 메테오 마법 피해가 십자형(Cross) 범위로 확장
  - 🌿 성스러운 생명초 ➔ 킹이 잡혀도 1회 되살아나는 부활의 영약 활성화
```

## ✨ 주요 특징 (Features)

### 1. 3D 절차적 마법 작물 5종
* 🍇 **아케인 마나 포도 (Mana Grape)**: 수확 시 체스 시작 마나 +1 영구 증가.
* 🌾 **태양의 황금 밀 (Golden Wheat)**: 빠른 성장 및 판매 시 높은 골드 환급.
* 🌶️ **화로 불꽃 고추 (Flame Pepper)**: 메테오 마법의 폭발 범위 확대.
* 🌿 **성스러운 생명초 (Sacred Herb)**: 킹 치명상 1회 방어 부활 영약.
* 🎃 **자수정 보석 호박 (Amethyst Gourd)**: 고가 판매용 작물 (+180 Gold).

### 2. 🏛️ 정원 시설 및 자동화 건설
* ⛲ **성스러운 천사 분수대 (250G)**: 모든 밭에 성수를 공급하여 물주기 노동 생략.
* 🐝 **마법 꿀벌 벌통 (200G)**: 황금빛 꿀벌들이 꽃가루를 날리며 성장 속도 1.5배 가속.
* 🗿 **체스 석상 허수아비 (150G)**: 고딕 나이트 석상. 수확 시 25% 확률로 2배 수확.

### 3. 🔊 Web Audio 무지연 절차적 사운드
* 골드 짤랑이는 동전 소리, 흙 파는 소리, 시원한 물주기 소리, 하프 팡파르 수확음이 실시간 합성 재생됩니다.
* 상단 헤더의 `[🔊 / 🔇]` 버튼으로 사운드 켜기/끄기 지원.

### 4. 🎴 5종 아케인 마법 카드 & 돌 파편 물리
* ⚡ **심판의 번개**: 적 기물 1턴 석화(스턴)
* 🌀 **차원 도약**: 아군 기물 2칸 내 순간이동
* 🛡️ **성소의 가호**: 1회 피격 무효화 황금 회전 보호막
* 🔥 **화로의 겁화**: 메테오 폭격으로 적 기물 산산조각 파괴
* ♟️ **폰의 각성**: 폰을 그 자리에서 즉시 여왕(Queen)으로 승급

## 🚀 빠른 시작 (Quick Start)

Node.js (v18 이상 권장) 환경에서 바로 실행 가능합니다:

```bash
# 1. 저장소 클론
git clone https://github.com/alarmpet/chess.git
cd chess

# 2. 패키지 설치
npm install

# 3. 로컬 게임 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 시 즉시 플레이할 수 있습니다.

### 테스트 및 프로덕션 빌드
```bash
npm test       # 단위 테스트 (3D 바이너리 + 아케인 마법 + 정원 파밍 엔진)
npm run build  # 프로덕션 번들링
npm run preview
```

## 🛠️ 기술 스택 (Tech Stack)

* **프론트엔드**: React 19, TypeScript, Vite
* **3D 그래픽스 & 씬 전환**: Three.js (r170), OrbitControls, Procedural Low-Poly Crop Meshes
* **오디오 엔진**: Web Audio API (Procedural Real-Time Audio Synthesizer)
* **저장 시스템**: LocalStorage 기반 영구 농장 데이터 저장 (골드, 작물 성장도, 시설 배치)
* **3D 그래픽스 & 애니메이션**: Three.js (r170), GLTFLoader, SkeletonUtils, OrbitControls
* **셰이더 & 이펙트**: Custom GLSL (Brazier Fire & Charred Embers, Procedural Stone Noise)
* **에셋 파이프라인**: 3D 바이너리 모델 스트리밍 (`.glb.gz.b64` ➔ `DecompressionStream('gzip')`)
* **규칙 심판**: [chess.js](https://github.com/jhlywa/chess.js) 1.4.0 (`src/rules/referee.js`) 이 합법수·체크·메이트·무승부(3회 반복·50수·기물 부족)·앙파상·캐슬링·승급·FEN/PGN 의 단일 기준. 3D 엔진의 `boardState` 는 그림이고 심판이 진실 — 원격·스크립트 수도 심판이 거부하면 두지 않는다. `window.wizardChess.getFen()`/`getPgn()`.
* **팩 매니페스트** (`public/packs/<id>/pack.json`): 기물 모델(색별 가능)·역할→클립 매핑(`idle`·`move`·`attack`·`shatter` 필수, `charge`·`hit`·`victory`·`kneel`·`bored` 선택)·`attackSync` 타이밍·`standoff`·`keepMaterials`·`fitHeight`·`yawOffset`, 그리고 환경(`model` GLB 또는 `type: "procedural"` 바이옴)·`board` 색·`teamTint` 를 팩 단위로 선언. `?pack=<id>` 로 선택. 검증기는 `src/packs/packManifest.js`, 테스트는 `npm test` (`test/pack.test.mjs` 가 선언된 클립이 GLB 안에 실제로 있는지 대조). 동물 왕국 설계는 `docs/PLAN.md` §4.3.
  * `legend` (**기본**): 두 발로 선 의인화 동물 — **최종 캐스팅 6종**(사자 킹·호랑이 퀸·코뿔소 룩·판다 비숍·캥거루 나이트·미어캣 폰), 전부 `tools/comfy_concept.py`(로컬 ComfyUI 콘셉트) → `tools/make_biped.py`(로컬 TRELLIS → Blender 굽기·두 발 리깅 → 압축 → 클립) 로 자체 제작. 진영은 모델 텍스처로 구분(해의 왕국 금색 띠 / 달의 왕국 어두운 털·보라 띠, `tools/kingdom_variant.py`). **외형 단계 4개**(아기·자람·의젓함·별빛 털)와 **비무기 장식 4개**(리본·꽃핀·밀짚모자·방울, 뼈 소켓 부착)를 HUD "🎨 외형" 에서 고른다 — 외형만, 수는 같음(`docs/PLAN.md` §2.2.2). 동작은 Idle·Walk·Run·Sit·Cheer 에 `tools/legend_add_clips.py` 가 **Attack·Hit·Kneel** 을 더한 8개. 잡기 = Attack(접촉 0.40 s), 잡힘 = Hit → Kneel 뒤 가라앉음. 절차 생성 초원 바이옴.
  * `savanna`: 네 발 동물 — 사바나(늑대·여우·소·말·알파카·사슴) vs 밀림(수사슴·허스키·소·말·당나귀·시바), Quaternius Animated Animal Pack **CC0** (`?pack=savanna`). 잡힌 동물은 `Death` 클립 뒤 가라앉는다.
  * `cathedral`: 원래의 대성당 석상 버전 (`?pack=cathedral`).
