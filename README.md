# 🧙‍♂️ 아케인 체스: 영혼의 성소 (Arcane Chess: Sanctuary of Souls)

> **3D 고딕 대성당 위저드 체스 × 아케인 마법 카드 덱빌딩의 결합!**  
> 체스의 냉철한 두뇌 싸움에 마법 카드의 전술적 파괴력과 시네마틱 타격감, 실시간 무지연 절차적 사운드를 더한 하이브리드 전략 3D 웹 배틀러입니다.

---

## ✨ 혁신적인 게임플레이 (Core Features)

### 1. 🎴 듀얼 페이즈 마법 카드 시스템 (Arcane Grimoire)
플레이어는 매 턴 **3개의 아케인 마나(Mana Crystals)**와 마법 카드를 공급받습니다. 체스 말을 움직이기 전, 마나를 소모하여 전장의 룰을 왜곡하는 마법을 발동할 수 있습니다:

* **⚡ 심판의 번개 (Lightning Judgment)** [마나 2]: 적 기물 1개에 하늘에서 벼락을 내리꽂아 **1턴간 석화(Stun/Petrified)**시킵니다. 석화된 적은 움직이거나 공격할 수 없으며 체크를 걸지 못합니다.
* **🌀 차원 도약 (Dimensional Rift)** [마나 1]: 아군 기물 1개를 반경 2칸 내의 빈 타일로 즉시 순간이동시킵니다. 핀(Pin)에 걸린 기물을 구출하거나 기습 포지션을 잡을 때 유용합니다.
* **🛡️ 성소의 가호 (Divine Shield)** [마나 2]: 아군 기물(킹 포함)에 황금 룬 회전 보호막을 부여합니다. 적의 다음 공격을 1회 완벽하게 무효화합니다.
* **🔥 화로의 겁화 (Brazier Cataclysm)** [마나 3]: 대성당 화로에서 불타는 메테오를 소환하여 적 기물 1개(킹 제외)를 불꽃으로 산산조각 파괴합니다.
* **♟️ 폰의 각성 (Pawn Ascendancy)** [마나 2]: 아군 폰(Pawn)을 그 자리에서 즉시 장엄한 **여왕(Queen)**으로 승급시킵니다.

### 2. 🔊 Web Audio API 무지연 절차적 사운드 엔진
* 외부 mp3/wav 파일 다운로드 없이 브라우저 자체 오디오 신시사이저를 통해 번개 천둥, 포탈 스윕, 크리스탈 보호막 공명, 폭발음, 승급 팡파르를 실시간 합성하여 0초 레이턴시로 재생합니다.
* 상단 헤더의 **[🔊 / 🔇]** 버튼으로 언제든 음소거 및 볼륨 제어가 가능합니다.

### 3. 웅장한 3D 고딕 성당 & 물리 파괴 연출
* 고딕 아치 천장, 실시간 스테인드글라스 광원, 3중 볼륨 화로 불꽃 커스텀 GLSL 셰이더.
* 기물 처치 시 32개의 3D 돌 파편이 사방으로 튀는 물리 시뮬레이션 (`spawnStoneShatter`).
* 체크메이트 시 패배한 진영의 킹이 바닥으로 쓰러지는 시네마틱 슬로우 모션 연출.

### 4. 4종 카메라 프리셋 & 자유 비행 모드
* 플레이어 1인칭 체감 시점, 탑다운 수직 전술 시점, 측면 시점, 대성당 전경 시점.
* PC 전용 `WASD + R/F` 자유 비행 모드 (성당 벽 뚫기 방지 클램핑 탑재).
* `H` 키를 누르면 모든 UI가 사라지는 시네마틱 관람 모드 지원.

## 🕹️ 조작법 가이드 (Controls)

| 환경 | 동작 | 설명 |
| :--- | :--- | :--- |
| **공통** | **카드 클릭 ➔ 대상 클릭** | 하단 마법 카드를 선택하고 체스판 위 대상 기물/타일을 클릭하여 마법 발동 |
| **공통** | **주문 취소** | 마우스 우클릭 또는 `ESC` 키 입력 시 선택한 주문 취소 |
| **공통** | **체스 기물 이동** | 아군 기물을 클릭 후 이동 가능한 칸(초록 룬)을 눌러 이동 |
| **PC** | **마우스 좌클릭 드래그** | 체스판 주변 카메라 궤도 회전 (Orbit) |
| **PC** | **마우스 우클릭 드래그** | 화면 평행 이동 (Pan) |
| **PC** | **마우스 휠 스크롤** | 줌 인 / 줌 아웃 (Zoom In / Out) |
| **PC** | **WASD + R/F** | 3D 공간 자유 비행 이동 (R: 상승, F: 하강) |
| **PC** | **키보드 H** | UI 숨기기/보이기 토글 (시네마틱 관전 모드) |
| **모바일** | **1손가락 / 2손가락 / 핀치** | 회전, 이동, 화면 확대/축소 제스처 완벽 지원 |

## 🚀 빠른 시작 (Quick Start)

Node.js (v18 이상 권장) 환경에서 바로 실행 가능합니다:

```bash
# 1. 저장소 클론
git clone https://github.com/alarmpet/chess.git
cd chess

# 2. 패키지 설치
npm install

# 3. 로컬 게임 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 시 즉시 플레이할 수 있습니다.

### 테스트 및 프로덕션 빌드
```bash
npm test       # 단위 테스트 (3D 바이너리 무결성 + 아케인 엔진 검증)
npm run build  # 프로덕션 번들링
npm run preview
```

## 🛠️ 기술 스택 (Tech Stack)

* **프론트엔드**: React 19, TypeScript, Vite 8
* **3D 그래픽스 & 애니메이션**: Three.js (r170), GLTFLoader, SkeletonUtils, OrbitControls
* **오디오 엔진**: Web Audio API (Procedural Real-Time Audio Synthesizer)
* **셰이더 & 이펙트**: Custom GLSL (Brazier Fire & Charred Embers, Procedural Stone Noise)
* **에셋 파이프라인**: 3D 바이너리 모델 스트리밍 (`.glb.gz.b64` ➔ `DecompressionStream('gzip')`)
